# 自定义滤镜八项微调

Feature ID: 012-native24-parameters
Status: IMPLEMENTED_OFFLINE
Mode: implement
Created: 2026-11-03

用户已授权实现八项调参：微调按配方身份独立保存，相同配方重新导入保留，新配方使用自身默认值，不改原始BIN；完成后以QEMU真实菜单验证截图，不连接相机。

| Requirement | Acceptance | Verification |
|---|---|---|
| REQ-001 八项编辑 | AC-001 附加滤镜从原创意外观进入原调参页，显示并编辑对比度、高光、阴影、褪色、饱和度、锐度、精细度和清晰度，范围及重置有界；原厂外观读写保持 | 实际AP回放、原注册及QEMU实际按键／原帧 |
| REQ-002 身份与保存 | AC-002 用色彩内容SHA256识别配方，排除名称和槽号；独立机内记录保存初始／工作值，相同配方重导入／换槽／改名保留，新内容不继承旧槽值；原BIN逐字节保持 | 真实导入／重建运行态与文件服务回放、同名不同配方 |
| REQ-003 真实参数通路 | AC-003 八项值经生产AP原生完整参数包／单属性包接入原CP参数路径；不以滑块或Python改CP内存冒充参数生效；不写原厂参数数组 | AP打包机器码、原CP任务分派及上下文构造／消费回放 |
| REQ-004 事务保护 | AC-004 当前事务使用固定参数快照；连续调节合并最后目标，失败恢复旧已提交参数；保存失败与不确定发布可见，未确认不报已应用；不重复排入在途E4 | 时序、丢包、保存故障、迟到E4及启动回归 |
| REQ-005 交付 | AC-005 新候选固定身份、源码／组件及验证回执对应；QEMU实际编辑八项、原厂往返、菜单重入并截图，原帧核对和正常退出；旧011归档／DAT保持 | 相关CPU回归、独立QEMU及归档门禁 |

现有BIN只有色彩配方，没有八项默认标量。新配方以原厂基准的八项值建立独立初始状态，初始值不从前一款自定义滤镜读取；重置恢复该初始状态。原厂基准只读，独立状态不写回原厂数组。BIN不新增字段、不重新编码。

UI编辑可以形成独立的待应用工作值；后台在原E4未确认时不再写成像状态，截图须明确区分工作值与实际已应用结果。整机／成像和真实介质仍需实机验收，当前明确禁止设备操作。
