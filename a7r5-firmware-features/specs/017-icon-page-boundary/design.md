# 设计与证据边界

旧4.13现场两次Abort已定位到F01选中态的5600字节0F块。4.14仅改成一个F0块，解压后仍为5600字节。用户报告4.14同位置重启，但没有本次异常栈，不能将旧栈当作新栈。

原厂两份资源共7022份载荷均以4096字节输出块组织，末块允许不足4096。同尺寸70×35、stride80的图标为4096＋1504；4.14新增图标则是单块5600。libObj生成两页输出请求，驱动将页数写入LDEC寄存器。这些证据支持“缺失4KiB块边界”为当前首要原因，尚未建立完整硬件模型。

编码器按4096字节分段后独立编码，每块重置回看字典、控制组和结束符。保留原编号、尺寸、像素、对齐和原资源逆还原门禁。派生构建同时重命名递归引用，防止生成工具出现未定义函数。

验证使用冻结fwtool逐块解码，独立于新增编码器。QEMU新增显式页面校验入口，原通用解码入口保留；实际图像观察器使用严格入口，防止软件可解码再次掩盖超长块。新实验单独固定四组件、BIN、CPIO、源码与编译收据，不修改旧实验及历史证据。
