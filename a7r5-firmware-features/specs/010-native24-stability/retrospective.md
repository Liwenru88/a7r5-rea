# 本轮实施复盘

初版新增代码被64KiB AP RX门禁拦住，保留失败目录。已取消的私有滤镜页仍占代码和对象池；用原厂构造委派替代后回收空间，零／非零加载基址验证保持原厂参数与返回值，没有放宽映射边界。

启动恢复需要同时处理E4尚未就绪和显式UI输入。后台自动事务持有提交权，最后输入在UI排队；目标与回退都未就绪时只做受控协调，并保留整体预算和未知终态。原E4构造后等待超时并不等于取消，新增独立原对象在途记录防止累积刷新对象。

LLVM合并BSS的内部偏移发生变化，旧观察器的部分数值不可信。修正为从本次目标文件的局部符号和链接节解析地址，记录原对象及解析布局，重新跑实际Qt与原帧。早期现场保持，最终采用ekfna2tl。

故障夹具也需遵守真实边界：修改配方名字必须保持合法UTF-8；模拟异步就绪使用队列回调，避免重入Unicorn覆盖外层指令预算；C的uint32返回值按低32位比较。夹具问题单独修正，不作为固件缺陷。

归档的PNG校验依赖Pillow，根环境未安装该依赖，改用QEMU已有环境完成，没有安装或调整全局依赖。最终组件、源码、完整回归、真实帧与归档重新读取验证完成；剩余工作是硬件门禁，不能通过扩大模拟堆、释放未知读者或伪造成像就绪来代替。
