# 二十四槽稳定性优化需求

Feature ID: 010-native24-stability
Status: IMPLEMENTED_OFFLINE
Mode: implement
Created: 2026-11-03

用户已授权实施上轮稳定性审查全部优化。本轮完成可离线实施的修复、保护、构建和验证；不连接设备，不迁移真实用户数据，不覆盖009候选、冻结上游、历史DAT或证据，不承诺绝对稳定。实际堆、介质耐久性、原E4完整初始化、成像及安装验收继续单列。

| Requirement | Acceptance | Verification |
|---|---|---|
| REQ-001 失败协调 | AC-001 发送后丢ACK、E4失败、回退CP／E4／保存失败后，区分已恢复和需恢复；需恢复时禁止原厂调参和自定义提交，允许通过ST受控恢复，不假报旧状态一致 | 新AP／CP机器码故障交错回放 |
| REQ-002 保存与恢复 | AC-002 选择保存保留发布前／发布不确定状态，回退保存错误可见；保留最后已提交记录的恢复日志；新24字节R5SEL6绑定库身份，读取旧R5SEL4／5；重启优先处理有效恢复记录 | 发布中断、文件错误、旧格式及干净重建运行态 |
| REQ-003 启动与导入 | AC-003 合法短读完整导入24槽，超长／错误失败回退；零字节不清空；相同有效库不重写；双卡优先卡槽1，有限等待后回退；相同库恢复选择，库身份改变解除旧关联并在UI所有者中委派原厂ST | 真实工作线程、双卡时序及文件服务夹具 |
| REQ-004 启动终态 | AC-004 自动恢复有总体预算、有限退避及明确失败终态，手动选择可重试；不可见的持续pending被消除；暂停／恢复不跨epoch冒报成功 | 时钟／E4／电源事件定向回放 |
| REQ-005 资源保护 | AC-005 保持不可变CP读者寿命；新库不足尝试旧机内备份并给明确结果；原厂网格资源失败不得当应用成功；共用工作线程大缓冲，检查嵌套栈和段边界；诊断不依赖SD写入 | 堆拒绝／缓存诊断／栈预算和构建门禁 |
| REQ-006 可追踪交付 | AC-006 集中容量与布局合同、精确派生匹配次数、连续账本、工具链与组件清单；新候选本地四项、统一入口／最后目标合并保留；独立离线组件包可核对，未完成实机门禁不输出可安装声明 | 构建前像与逆还原、相关回归、固定身份QEMU及归档 |

具体行为决策沿用审查建议：0字节视为无效，显式有效空配置仍可表达清空；同库保持选择，库身份变化回到原厂ST；双卡优先槽1并给槽2有限回退窗口。新选择文件采用独立版本，旧固件不保证读取；仅在新研究候选中写出，回退旧固件前需要配套文件处理，本轮不操作设备。
