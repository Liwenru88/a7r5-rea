# LUT转换核心：参考模型、原厂格式与误差边界

- Feature ID: `001-fixed-custom-filters`
- Updated: `2026-10-26`
- Status: `OFFLINE_NATIVE_GRID_CONVERTER_VERIFIED`

## 本轮实现

已实现可在AP的AArch64指令集中执行的CUBE到1215字节原生网格转换核心：有界预测、拟合、七位量化、取消和独立留出误差评估。新网格的打包已与当前修改4.06原CP的完整函数逐字节对照。该核心目前没有接入机内SD菜单、持久化路径或实际成像应用；不能说完整导入功能已完成。

沿用原厂成像是目标：选中原厂基底后，新增槽只提供需要的参数/表，最后交给原厂通路消费。本轮先保留基底原曲线/矩阵，近似拟合一张附加网格，没有实现新的取景/JPG渲染器，也没有替换原厂银行/帧管理。

## 参考项目实际采用的内容

固定[Hearts-Ace提交8b563d46](https://github.com/Hearts-Ace/sony-a7r5-custom-firmware/tree/8b563d46f800679abd3f215950cb541fc81da2a6)，读取`R5ColorLab/compilers/custom_filter_v4.py`、`scripts/residual_grid.py`、`web/grid_distillation.py`、`web/paired_response.py`及公开v2模型。

上游BIN v4包含CC1、block13、129点Gamma和七位网格，采用独立12配置。当前任务是32槽及机内转换，不能直接套上游BIN/槽位/AP或CP前像。本轮借鉴数据布局与成对响应路线，独立C实现预测和矩阵无关的有界投影优化，不移植SciPy/Web依赖。许可与来源见[参考说明](../../custom-filters/REFERENCE.md)。

公开v2模型SHA为`8879499fbd9b24899dcbd8fee4135b806fdcba1fd18a677b090b7af212b85a45`，包含3×4仿射坐标及随RGB变化的3×3响应。它来自11对图像，训练坐标只覆盖42/256单元；原模型实拍留出RGB8 RMSE约3.696。未覆盖区域为外推，不是唯一恢复的原厂ISP，不能直接保证当前4.06机内效果。测试夹具保守限定ST，FL2/FL3等其余基底不自动使用该模型。

**2026-10-27更正（E-223）**：上段“保守限定ST”是第十八批的错误准入判断，现已撤回。11对原捕获均为PT且绑定固定非网格参数，当前API不能绑定这些完整条件，原始捕获摘要在ST和PT均拒绝。默认模型关闭，另摘要夹具只用于明确标记的数学实验；本页历史拟合数值继续作为该数学模型内结果，不是当前机身LUT资格或误差保证。详见[integration-28.md](integration-28.md)及[来源审查](../../../.local/continuation28-color/grid-scope/README.md)。

## C接口与资源

[af_grid.h](../../custom-filters/native/af_grid.h)、[预测与打包](../../custom-filters/native/af_grid.c)、[拟合与误差](../../custom-filters/native/af_grid_fit.c)：

| 接口 | 契约 |
|---|---|
| `af_grid_row/predict` | 检查模型和RGB，计算8个三线性节点及响应；平面顺序明确，输出裁剪到0～1 |
| `af_grid_fit` | 调用者提供模型、基底、已解析CUBE、训练样本与独立工作区；只接受模型允许的基底；训练与留出评估分开 |
| `af_grid_pack` | 检查完整405项排列及系数范围，按原CP“源写目标”排列，模拟1～8级整数缩放，打包为405个u32 |
| `af_grid_report` | 对独立样本评估量化后的整数网格，报告RGB RMSE、平均/P95/最大/灰阶/肤色样本组ΔE76及裁剪 |

最多4096训练或评估样本、256迭代，当前工作区499436字节，由调用者提供；无C内存分配、文件或设备访问，也不依赖目标libm。取消回调在初始与各迭代检查，失败/取消不发布网格和结果。量化按最近偶数处理，系数限定−64～63；量化训练误差劣于零网格时退回零网格并报告。迭代有上限，不承诺全局最优或预算内必然收敛。

工作区不包括源CUBE文本/样本存储/调用者数据、真实任务栈和整机服务。解析最大维度33和本轮输入预算不等于机身已测资源上限。AP任务、进度UI、文件加载和真实耗时仍需后续接入与测量。

指标明确采用显示sRGB、D65、8位半入取整后的**ΔE76**，不是ΔE00或场景色度测量；P95使用最近秩。肤色和灰阶是输入样本标签，不能用少量合成色组代替实际场景验收。参考项目采用的其他指标不能直接与本指标混比。

## 原CP兼容证据

从同一锁定CP读取排列文件偏移`0xd841d8`，405个u16恰为0～404的排列；在`CpMachine`执行原`0x231654`完整函数。三通道平面各405个有符号系数，按强度缩放后取七位，写入u32的22/12/2位。

1～8级边界模式及AArch64拟合的实际非零网格共9组，与独立Python期待及新AArch64打包输出逐字节一致；输出保护区和源网格保持。实际AArch64拟合网格SHA为`34a00f6f0958928aa971099ab353d4ef93ab58f5f3d3f7402d50e2d883a2bfe9`。

这里仅证明格式、排列、符号和整数打包。像素上传、真实LUT应用、照片模式消费者与最后图像帧没有执行。原厂已有打包函数能消费该布局，不等于新槽已能驱动该函数。

## 独立误差与数值对照

在只读固定源码上仅执行上游`PairedModel`和`stencil`数学定义，与新C预测器对照10000个非零网格随机颜色：最大通道差`5.3891×10⁻⁷`、RMSE `5.7014×10⁻⁸`；零表恒等逐值一致。没有启动上游Web服务、SciPy拟合器或相机工具。

本项目C拟合使用582训练颜色、180次迭代预算；评估使用另1135个留出颜色，含129个灰阶与6个肤色样本组。全部按最终1215字节整数网格计算：

| 合成LUT案例 | RGB8 RMSE | 平均ΔE76 | P95ΔE76 | 最大ΔE76 | 限幅系数数/1215 |
|---|---:|---:|---:|---:|---:|
| 恒等 | 0 | 0 | 0 | 0 | 0 |
| 温和暖色仿射 | 1.369 | 0.757 | 3.005 | 5.204 | 0 |
| 17³非线性曲线 | 2.367 | 1.277 | 5.042 | 7.271 | 12 |
| 反转压力案例 | 96.410 | 84.851 | 169.625 | 219.367 | 661 |

反转案例还出现30个裁剪样本，说明单网格不能准确表示任意LUT。表中是**研究响应模型内误差**；模型自身原实拍误差是另一层证据，不能与上述指标直接相加或当成本机成像保证。真实照片、不同基底/参数、肤色场景和完整误差准入阈值均未验收。

回执和全部来源/候选摘要见[数值与拟合报告](../../../.local/fixed-custom-filters/reference-fit-18.json)，当前目标和原CP联验见[完整同包审计](../../../.local/fixed-custom-filters/cp-ui-access-406-18.json)。

## 下一步接线

1. 优先查清原厂整组外观应用/快照入口，将新增槽位和转换网格接入原厂消费；不预设替换所有银行管理。
2. 核对当前基底、原厂曲线/矩阵及网格效果；需要时加入CC1/block13/Gamma拟合，补齐其他基底模型。
3. 将转换器接入AP导入任务、候选预览/取消，再连接机内完整副本、保存/另存及SD菜单。

上述仍是离线接入工作；实际机内路径、原厂完整画面、动态切换/图像寿命和设备验收继续单列。完整批次状态与复算见[第十八批交付](continuation-18.md)。
