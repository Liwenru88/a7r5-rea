# Gamma 构造到影子区的版本传递

日期：2026-11-01。沿T03f2推进，基线仍为现有修改版4.06；不操作相机、不执行目标指令、不做硬件模拟。**本批接通了主Gamma到原厂影子参数区的按值身份传递，尚未开启第二Gamma域，也未完成EVF/JPG成像闭环。**

## 已落代码的链路

```text
845700 原构造BL
  → 永久phase gate → 原AACB16/AA6710，调用一次、保留原r0
  → 原AA7EA4/AA81CA/AA8F74生成主formatter
  → 实际id2主Gamma core：同票据私有变换后保存tone/输入版本/来源epoch
AA6978 原84B memcpy
  → 原厂复制一次 → 复制前后代号及实际字节一致才发布shadow伴随身份
```

实际source头为`1F6A088`、主formatter为`1F6A08C`；实际shadow头为`1F6A43C`、shadow formatter为`1F6A440`。不是从当前选中槽、相同九值、函数名称或全局最新版本推断身份。

`af_cp_components406`新增的记录仅包含三项tone、输入version、source/input/snapshot epoch、槽位和原任务ticket；84B原formatter像用于复制校验。构造入口前后必须是同一个实际id2视图，之后的Gamma core还要与这次构造的票据、版本、来源epoch及tone完全匹配；没有构造视图或构造后换代不能发布。没有保存asset指针、延长完整配方租约或建立图像帧owner。原厂分组发布及失败回退不改。

`AACA82`原初始化BL另有永久gate：进入原`AA6412`之前撤销source/shadow资格，原输入指针完整传入，原初始化只调用一次。常规构造只撤销source资格；旧shadow在原厂实际复制发生前仍保有其旧版本，不能提前替换为新LUT。

小记录使用有界非阻塞标记锁，原构造、初始化及memcpy均在锁外执行。构造在途、复制期间重建或reset、字节不匹配、重入、标记争用及代号耗尽均拒绝伴随身份；原厂调用仍执行。重入、写者争用和耗尽会粘性关闭本次启动的Gamma伴随资格，不通过清零或重试猜测恢复；不关闭原厂成像，也不把回退称为私有成像成功。

## EVF/JPG与第二域来源进展

原厂Capture对象`A`的`B=A+BD0`，第二Gamma输入是`G=B+1D8=A+DA8`。正常生产链`AEBDC2→875922→335AB8→AA7094`从上述shadow逆格式化写到`B+250`；这不是12D8 shot的直接字段复制，也不是JPG句柄区。历史非正式推导`R+59CC`已撤销。

原厂照片阶段表`1112CB4`证明阶段3 Capture到阶段15 JPG存在保持同一`task+0` CamCore owner的迁移路径。JPG实际提交为`472D58→466174→506914→5069C4`，回调存于请求`+C`，不是`+138/+13C`。本批另核`456CF8`完整任务执行CFG：回调结果可重排、返回或清理；清理调用owner虚表`+C`并把task归还`18F7138`池。**该退役只是任务owner释放，不是所有图像消费者最后引用。**

EVF实际端点为`9059081A`，其48B输出配置缓存为`11CC100`。这是尺寸/裁切配置，不能作为像素源、颜色银行或配方版本。主/第二Gamma原`755BA4`同步CPU复制边界也不能替代最终EVF/JPG像素证据。
