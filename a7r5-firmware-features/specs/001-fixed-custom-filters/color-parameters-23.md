## 本批推进的关键链路

本批将矩阵/CC1证据从“原函数之后的半字加法窗口”推进到完整原构造函数，再进入原CC1两级插值函数。新增`native/af_color406.h/.c`可从已确认的原输入重建参数，并复现整数截位、增量顺序和最终舍入；`a7filters/cp_color406.py`同时执行原CP、独立数值参考和AArch64新实现核对。

结果补齐T08b2d2限定范围。它处理参数，不处理RAW/取景/JPG像素；真实sRGB桥、完整组件组合预测、全部校准分支和实际成像应用仍未完成。

## 矩阵：来源、校准和端点顺序

每次输出3个端点×9项。每端点的6项源`a,b,c,d,e,f`展开为：

```text
calR+a+b, -a,       -b
-c,        calG+c+d, -d
-e,        -f,       calB+e+f
```

三个校准对角值来自调用上下文的校准对象`+0x1a0/+0x1a2/+0x1a4`，不能固定写成1024。本批用互不相同的1056、992、1107验证每行与每个端点；逐行低16位之和保持对应校准值。

原运行期属性基址`0x16b3414`。profile≤51通过`+0x196+profile`选择bank；bank>55回退0。bank<32按`+0x1e0 + bank*768 + endpoint*192 + sector*12`读取；bank32～55使用`+0x61e0 + (bank-32)*48 + endpoint*12`，不按sector变化。sector>15回退0。

当前包profile54～57进入内嵌表`0x1a3a000+(profile-54)*576+sector*36`，布局是扇区内连续三个端点。该表从当前CP锁定的5872字节载荷显式映射到匿名影子RAM，系数是本包原值；这不是原引导复制执行。其他profile的属性与校准是显式数值夹具，不称为机身真实运行设置。共186组覆盖逐扇区、统一bank、内嵌表及两种索引回退。

原代码使用`ldrh/strh`，最终保留低16位。新C显式实现该行为，避免依赖超范围有符号转换。精确复现截断不等于确认了硬件系数的可接受范围；联合模型仍需做自己的可行性校验。

## CC1：修正、差分和第二域限制

主域24项源数据的第一组8项是绝对值，后两组分别是相对第一组的差分。若原修正器给出`adjust[i]`：

```text
endpoint0[i] = raw0[i] + adjust[i]
endpoint1[i] = endpoint0[i] + raw1[i]
endpoint2[i] = endpoint0[i] + raw2[i]
```

全部按原低16位存储。这个8项修正是内部颜色系数，**不是创意外观的八个用户滑块**。

profile0～51从`0x16b0f14`属性映射读取64字节bank中的前48字节；bank>39回退0。profile53读原固定记录`0xe8d502`；54～57读当前CP内嵌记录`0xbef3ec+(profile-54)*48`。profile52和>57的主域完整返回但不写输出；不能把调用方预先清零的输出当作原函数生成了零参数。

原修正器在`0x16afd14+0xc`的bit3置位时跳过修正。常规全局回退的前4项来自`0x195effc+0x34..37`有符号字节，后4项来自`+0x30..33`无符号字节。本批分别使用负数和大于127的正数覆盖符号解释；另验证关闭修正。动态校准分支`state+0x1e0=1 → 0x73e654`仍未执行，不把全局回退当成所有校准路径。

第二域合法profile为0～51、53，mode为0/1。输出前8项是第一端点加修正；后8项是属性`+0xf00+mode*16`的元数据，不能叠加滤镜增量。其他profile到达诊断号0x257，非法mode到达0x258；本批停在原诊断入口，保留输出未写和未完整返回状态。未执行诊断服务的后续副作用。

66组主域均完整返回，其中62组写入。134组第二域中112组合法完整返回，22组在诊断入口停止，二者分别计数。

## 原CC1两级插值与整数舍入

只构造24项端点还不能预测原厂最终使用的8项系数。本批继续执行原`0x71b8a0`，以明确的6参数调用约定传入root/pipeline，并核对原颜色元数据和状态字段写入范围。

常规路径先形成两组8项系数，再合成最终结果。新`af_color406_blend`接收原上下文确认的4个Q8权重：主路径端点1权重、次路径端点1/2权重、两路径混合权重。范围0～256，次路径两权重和≤256。

第一层采用原向下截位，并在每组中间结果保留低16位；不能用一次浮点三端点加权替代。最后一层采用带符号的半入、远离0舍入，正负半整数边界分别处理。权重本身的推导仍由原上下文决定，新C不猜测它与色温、曝光或像素的关系。

180组完整原插值覆盖profile0/3、内嵌54/55与旧六款，6个数值参数和最终权重0/128/256。原分段阈值用明确数值设置，主/次权重与独立公式一致；最终输出与独立整数参考及新AArch64逐字节一致。写入只允许输出、原权重元数据、声明的状态字段和栈，保护区保持。这里验证参数插值，不证明这些合成阈值对应实际拍摄环境。

## 旧六款和候选接入约束

现有标记249～254、来源flag0/1时，原包装器在完整构造之后增加矩阵27项、主域24项和第二域前8项；flag2跳过。18组身份/门控各执行3个矩阵扇区、1个主域、2个第二域，共108次完整调用；第二域元数据保持。

这个顺序决定新增槽应用应按“原基底/校准构造→候选增量→原条件下的端点插值”接线。将CC1增量直接写入相对端点原记录，会让第一端点的改动再次传播到后两个端点；不得将这种改法当作等价实现。最终Gamma仍须遵守第二十一批已发现的完整曲线/旧tone区别。

新C函数现在提供真实格式重建和整数消费算子，尚未安装为20槽解析器、CP上传器或缓存失效入口，也没有改变研究配方的`research_only`语义。矩阵/CC1算子、Gamma域和原网格打包逐步具备，并不意味着完整联合像素模型已经成立。
