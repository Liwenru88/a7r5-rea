# Gamma、矩阵、CC1和网格联合求解：整数核心与模型边界

- Feature ID: `001-fixed-custom-filters`
- Updated: `2026-10-26`
- Status: `OFFLINE_JOINT_CORE_VERIFIED_FULL_MODEL_PENDING`

## 目标与本轮实现

完整转换目标已明确为四类组件联合拟合。第十八批网格结果继续作为阶段证据；不能将保持其他组件不变的单网格近似当作完整方案验收。

本批实现[联合数据契约](../../custom-filters/native/af_joint.h)、[整数组件](../../custom-filters/native/af_joint.c)和[联合求解驱动](../../custom-filters/native/af_joint_fit.c)：显式原生整数候选由Gamma、矩阵、CC1和网格共同组成，每次修改一个组件组，用同一个完整预测后端计算整个组合的训练目标；任何取消或模型错误均不发布候选与结果。

完整CP像素后端尚未实现。本批用合成耦合后端验证求解器，并执行当前CP的整数运算窗口核对格式；这两类证据不能合并为“本机LUT联合转换已完成”。T08b2b/T08b2c限定范围完成，T08b2d及T08b2/T08整体继续未完成。

## 当前包与参考项目的组件区别

固定[参考提交8b563d46](https://github.com/Hearts-Ace/sony-a7r5-custom-firmware/tree/8b563d46f800679abd3f215950cb541fc81da2a6)，继续读取其原生拟合、整数模型和转换器，未执行上游服务/优化器或移植源码。具体来源见[参考说明](../../custom-filters/REFERENCE.md)。

| 组件 | 当前4.06已有通路与本批契约 | 不可直接套用的内容 |
|---|---|---|
| Gamma | 129个u32，0～0x3ffff，576字节记录；零起点、单调、非零末点；保留附属字段，仅同步+0x220末点 | 对方BIN限定0～131071；本包不能无依据缩成17位，也不能假定采样轴均匀 |
| 矩阵 | 每个端点6项增量，三端点18项；展开成27个int16，逐行和为零 | 对方block13为3×16×6，另含色相边界、归一化和标定；27项端点增量不等于完整block13 |
| CC1/色度 | 三端点各8项增量；本包原包装器按有符号增量加到原半字输出 | 对方导出还存在通道重排/量化；原半字低16位存储相同不证明绝对系数和像素效果有效 |
| 网格 | 1215个signed7系数，三个平面，各5×9×9；沿用原打包布局 | 成对网格响应模型没有观测Gamma/矩阵/CC1变化，不能冒充完整预测模型 |

`AfJointRecipe`在本次目标ABI为1816字节，包含129点Gamma、18项矩阵、24项CC1和1215字节网格；这是内存结构，不直接落盘为原生载荷。矩阵/CC1增量限制−1024～1024，网格−64～63。绝对端点范围、实际基底/光源权重和标定由后续完整后端校验，不以结构合法作为应用许可。

Gamma整数生成严格保留本包算术次序：先按原末点求Q12位置，再逐乘法及算术右移叠加gain/toe/shoulder，裁剪到18位。负数采用显式向负无穷的移位模拟。失败不发布记录，成功仅写129点及+0x220末点；全零或非单调曲线拒绝，输入不能与输出重叠。

## 联合求解器的可执行契约

`AfJointModel`声明当前CP摘要、模型摘要、基底掩码、完整四组件能力及显示sRGB输入域，并提供组合预测函数。原网格模型单独不能满足接口；只有声明四组件也不能证明后端准确，后端仍须T08b2d取证。调用期间模型和输入由唯一拥有者保持稳定。

`af_joint_fit`先由已有CUBE求值生成训练目标，再交替探索Gamma、矩阵、CC1和网格的整数候选。Gamma支持三种全曲线方向及逐点修改，矩阵保留行和约束，所有候选均按边界校验。以完整组合的8位RGB加权MSE选优，不逐组件使用互不相干的指标；等价或变差候选不替换当前解。它是有限预算整数搜索，不承诺全局最优、全部坐标被访问或给定LUT可表达。

最多512个训练样本、16384次候选评估，工作区11824字节，无动态分配或设备/文件访问。模型可将不可行组合标为SKIP；其他错误或非有限预测中止。工作区与模型、源CUBE/样本、种子、输出及结果必须独立；进度回调在候选之间及每64样本检查取消。最终只在完整成功后发布，输出明确`research_only=1`。

当前目标是训练阶段整体8位RGB误差。独立留出ΔE76、灰阶/肤色/裁剪必须对完整真实后端另行测量；单网格的旧误差不能转挂到联合结果。未绑定完整后端前，不输出“联合误差已保证”的报告，也不批准实际ISP schema。

## 原CP整数证据

从本包文件偏移`0xcc4a0c`读取ST曲线，129点与固定参考公开数值相同；576字节原记录SHA为`f4e9f31bce38b4c705721a501c7597705852e671bc39baf60b02dac8b88f95ac`。在隔离CP执行原`0xbef948..0xbef9ae`窗口：

- 当前ST的零增量、混合正负增量、负gain和高gain共4组，加18位上界合成源1组，与新AArch64生成器逐字节相同，源记录附属字段和保护区符合契约。
- 原矩阵`0xbef762..0xbef772`执行27个半字增量，原CC1 `0xbef7c2..0xbef7d2`执行24个半字增量；含符号及低16位存储边界，对照独立字节期待通过。

后两组的原厂基值是显式合成半字，Gamma入口寄存器/栈是显式夹具。未执行完整原生产器、端点选择、校准、上传或ISP像素，因此报告`original_functions_complete=false`。新增[a7filters.native_joint](../../custom-filters/a7filters/native_joint.py)将这些窗口与AArch64搜索联验接入`--joint-adapter`，不会安装AP/CP挂钩。

## 求解器证据与下一落点

合成目标包含共同亮度、通道混合、独立色度变化和颜色乘积项，目标CUBE由独立公式构造。65次评估中四组件均接受过改进，训练量化MSE从`6.0233244×10⁻⁵`到0；AArch64执行1871项断言，含完整候选/结果取消保留与网格单独能力拒绝。该零误差只针对合成训练任务，不能当作真实LUT、独立留出或相机像素结果。

下一步必须补齐：基底显示sRGB到原生处理域的映射、CP实际组件顺序、Gamma采样轴、矩阵/CC1端点与标定选择、其他固定色度步骤和网格响应坐标。参考Edit模型输入是后SSCS/矩阵前整数RGB，输出是受限色彩子链，直接接入会混淆输入域；本批没有采用这种替代。

绑定后再对完整整数组合做独立留出/真实样片误差，与单网格结果比较，随后连接实际用户槽应用和导入菜单。复算、模块摘要及全部验证回执见[第二十批交付](continuation-20.md)。
