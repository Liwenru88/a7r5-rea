# 完整预设与保存事务

- Feature ID: `001-fixed-custom-filters`
- Tasks: `T04b2a`, `T05a`, `T07a`
- Status: `IMPLEMENTED_OFFLINE_NATIVE_CORE`

## 完整载荷

外层沿用A7F1记录和CRC。内层AFD1使用256字节小端头，随后是非空UTF-8名称（最多63字节，无NUL/控制符）和完整成像载荷（离线研究预算最多256KiB）。不序列化C填充、不保存SD路径。纯参数滤镜没有成像字节；LUT滤镜包含全部字节并校验SHA-256。预算不是机内空间结论。

头布局：0魔数；4版本u16=1；6头长u16=256；8成像schema；12转换版本；16名称字节数；20成像字节数；24误差采样数；28裁剪样本数；32/36/40/44/48分别为平均、P95、最大、灰阶最大、肤色最大色差（百万分之一单位）；52报告范围（0无，1模型）；56模型SHA-256（32字节）；88初始预设（74字节）；162保存预设（74字节）；236存在标记u32；240～255保留为0。

每个74字节预设显式编码base、kind、八个有符号参数、成像SHA-256及原LUT SHA-256。初始/保存预设必须绑定同一基底、kind和摘要；调参不修改既有拟合报告的基准范围。报告仅对初始参数有效，工作或保存参数变化后不能当作当前效果误差保证。实际ΔE计算、ISP模型及实拍报告仍待T08b。

原生`af_document_report_applies`对完整基底/kind/摘要/八项值与initial逐一比较，任一改变即返回不适用。报告值以百万分之一单位保存；实际指标定义、采样集和ISP域必须与模型清单摘要绑定后才可分配机身schema，当前仅测试非批准schema。

清空采用同代数机制的墓碑记录：存在标记0，其余业务字段全零，仍需完整外层CRC。禁止用删除最新文件实现清空，避免正常重启复活旧副本；若最新墓碑损坏或被外部移除，仍可能按双副本规则恢复较旧的完整版本。未知版本/schema拒绝自动回退；当前schema的坏数据可退回另一完整副本。schema是显式读取契约，当前没有为A7R5实际ISP格式分配已批准ID。

## 保存事务及恢复

调用方单线程持有同一槽位。每次提交前重新读取两个副本并比对上次代号/内容，防止过期目录覆盖；不声称跨进程锁。流程为完整编码→暂存写入→文件同步并关闭→原子发布到非当前副本→目录同步→重新读取并逐字节校验→发布成功。所有阶段错误保留，短写需循环，EINTR可重试。输入/输出缓冲须独立且由调用方提供，禁止动态扩大预算。

发布前失败保留旧版本；发布已尝试后出现任何错误均返回UNCERTAIN，并冻结该槽位继续写入，必须重新恢复。不能把这种结果当成“新版本未写入”自动重试。重启按完整可解码副本选择最新代号；两份都坏不自动清空或初始化，同代不同内容拒绝，未知未来版本阻止降级。

本地POSIX适配器只接受调用者提供的普通目录文件描述符，固定C01～C20及A/B名称，不跟随符号链接，不接受设备路径，不自行打开SD或内部路径。测试只在新建临时目录运行。残留暂存文件拒绝覆盖，由调用方明确处理；不会为了恢复自动删除证据。目录fsync只是本机系统调用证据，不等同机身文件系统的断电耐久保证。

## 不可变版本核心

固定三个银行，由调用者提供各自独立缓冲。准备完整字节版本，取得带代数令牌的待应用请求，只有匹配的成功回执才切换活动版本。失败保留上一活动版。在用银行有引用时不能覆写；释放必须匹配银行、版本和独立引用令牌，重复/过期释放拒绝。不将主机核心的回执伪装成实际CP确认；真实消息、线程、内存屏障、逐帧/JPG接入继续待T03/T07。

令牌只在一次初始化生命周期有效。禁止引用未释放时重初始化；进程/机身重启需额外会话握手，当前不接收真实跨核回执。核心没有跨线程锁，调用者须在同一拥有者线程串行应用与释放。

## 编辑目录联动

`af_persist_load`在完整记录成功后恢复initial/saved，working从saved开始；显式恢复会丢弃当前未保存调整。`af_persist_save`捕获请求快照，真实事务成功才调用`af_finish_save(...,1)`；失败清除该请求但保留工作值。写入期间继续`af_edit`不会被旧快照完成覆盖。`af_persist_copy`保持源不变，目标另存保留源initial及误差基准，保存源working。替换/清空需串行独占，后端不得重入目录操作；清空确认后才从目录移除。

`tests/test_native_persistence.py`编译实际C核心并操作新建临时普通目录；`tests/test_native_versions.py`验证银行/引用；`tests/test_native_pipeline.py`把同一C链路交叉编译至AArch64和ARMv7，分别完成20槽调参、保存/重载、失败、另存、墓碑和引用检查。验证证据E-096～E-101，整体机身功能仍未完成。
