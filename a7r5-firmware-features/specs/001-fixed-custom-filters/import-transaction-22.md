# 联合转换候选与滤镜管理事务

- Feature ID: `001-fixed-custom-filters`
- Updated: `2026-10-26`
- Status: `OFFLINE_IMPORT_TRANSACTION_VERIFIED_REAL_INTEGRATION_PENDING`

## 已接通的范围

本批将原生C模块连成一条可执行的离线事务：CUBE字节 → 四组件整数拟合 → 独立留出误差 → 自包含候选 → 完整AFD1记录 → 显式替换用户槽 → 八项编辑、保存/重命名/导出/另存/清空 → 新目录恢复。完整预测由调用方显式传入；测试中的合成后端仅验证接口、数值聚合和事务，不充当当前4.06的真实ISP模型。

`af_import_cube`本身不读文件、不选SD路径、不改目录或显示。成功只发布候选；用户确认目标和覆盖后，管理调用方才可使用`af_import_document`取得视图，并通过原有`af_persist_replace`提交。存储回执和成像回执仍然独立，没有以保存成功冒充取景或JPG生效。

## 原生接口与资源边界

| 接口 | 输入/输出与约束 |
|---|---|
| `af_import_cube` | 输入CUBE、UTF-8名称、纯参数参考预设、seed、显式完整模型、训练/留出样本和预算；成功返回自包含`AfImportCandidate` |
| `af_joint_report` | 同一完整量化配方与单独样本；失败/取消不发布报告 |
| `af_joint_asset_encode/decode` | 1943字节显式小端研究配方；核对当前CP、基底、模型、最终Gamma语义、整数范围及整份摘要 |
| `af_import_document` | 验证候选统计与载荷一致，返回借用其名称/图像的完整文档；候选在消费完前保持不可变 |
| `af_import_asset` | 从完整恢复的AFD1再次校验载荷、模型、基底和摘要，输出研究配方；不是CP应用许可 |
| `af_persist_rename` | 保留初始/保存/工作值，只提交新名称，并使目录保存代号跟随存储代号 |
| `af_persist_export` | 显式选择已保存或工作参数，返回自包含AFD1字节，不写外部介质；导出不是重新生成原始`.cube` |

上限为4MiB源文本、33³节点、512训练色、4096留出色、16384次搜索评估和63字节UTF-8名称。转换工作区146948字节；最大CUBE暂存107811个float，即431244字节；候选2236字节。三者合计580428字节，另需模型context、调用栈、文件读取和保存缓冲。工作区预算是当前编译ABI的实际结果，未测机身内存占用或耗时。

导入模型必须声明四组件、当前CP、sRGB输入域和本次唯一基底；后端须绑定参考八项值及seed，并在任务期间保持稳定。声明只校验输入契约，不能替代模型标定。本批没有内置可冒充真实后端的默认模型。`.cube`文本本身不能可靠声明sRGB或Log；今后SD菜单必须限定来源/声明，不能以解析成功自动认证色彩空间。

训练和留出使用不同缓冲，逐色核对不重合；留出自身不能重复，须包含灰阶和肤色标签。标签由调用方提供，不是肤色识别器。要求至少9次预算，确保四组件都获得尝试；最优解可以保留部分基底组件，但不能以单网格声明通过联合导入。

取消回调覆盖搜索、每个留出样本和最后封装边界。总进度单位为`evaluations + validation_count + 2`，表示工作计数，不是实测时间比例。真实AP异步任务、线程安全取消及菜单进度呈现仍待接入。

| 偏移 | 字节 | 内容 |
|---|---:|---|
| 0 | 8 | `AJR1`、小端版本1、头长128 |
| 8 | 4 | 正文1815字节 |
| 12 | 4 | flags=3：最终Gamma曲线＋仅研究 |
| 16 | 4 | 项目基底选择值0～9、17、18，区别于CP线号19/20 |
| 20 | 12 | sRGB模型域1、四组件mask15、保留0 |
| 32 | 32 | 固定当前4.06 CP摘要 |
| 64 | 32 | 模型摘要 |
| 96 | 32 | 摘要区清零后整份1943字节的SHA-256 |
| 128 | 516 | 129个18位范围的u32 Gamma纵轴值 |
| 644 | 36 | 3端点×6项有符号矩阵增量 |
| 680 | 48 | 3端点×8项有符号CC1增量 |
| 728 | 1215 | 三平面5×9×9七位有符号网格 |

格式无C结构填充；头字段和正文损坏均受摘要覆盖，SHA不提供来源认证。`AF_JOINT_ASSET_SCHEMA=0x314a4641`只用于离线研究记录，尚未获机身ISP批准。Gamma为最终曲线，后续适配器必须区别于旧六款tone增量；当前CP不读取这份格式，标志尚未安装为实际防重复处理分支。7列Gamma的真实模式语义、完整参数变化与sRGB桥仍须补证。

AFD1继续保存名称、初始/保存八项参数、原始LUT摘要、载荷摘要、转换版本和模型误差。最长名称时，每份记录为32+256+63+1943=2294字节，20槽双副本91760字节；不含文件系统元数据、旧格式兼容和其他运行缓冲，不能据此认定机身已有可用空间。

## 误差范围

`af_grid_color_report`复用既有sRGB/D65 Lab数学，按最终夹取及8位量化后的颜色计算平均/P95/最大/灰阶均值/肤色均值ΔE76，以及量化RGB RMSE。P95使用最近秩`ceil(.95*n)-1`。本批保留原单网格报告接口的行为，不将新增聚合接口混同其旧RGB RMSE定义。

持久化`delta_e[5]`为ΔE76乘1000后四舍五入；`scope=1`明确指模型。`clipped`统计目标或预测接口返回RGB越过0～1的样本，无法统计后端内部已经发生并被夹取的ISP裁剪，也不表示传感器动态范围。参数偏离initial后，原报告不再适用；保存/另存保留来源，不重新承诺旧精度。

24色非零误差用例独立计算sRGB传递、XYZ、Lab、P95、灰阶/肤色分组和裁剪，与C结果绝对差≤0.00015。合成耦合目标另证明四组件均接受改进，8个训练色与4个留出色分开；其零误差只是合成公式可表达性，不是本机成像精度。

## 事务与验证

候选计算和槽位提交分开：解析、后端失败、样本重合、预算不足和搜索/评估/封装取消均不发布候选；需要更换滤镜时必须显式传覆盖选项。没有修改12原厂身份或增加第21个用户槽。

重命名在双副本完整提交后只推进目录代号，保留未保存调参；导出明确选工作或保存值，不能隐式保存。输出、长度指针和名称不得与存储工作缓冲重叠；非法输入在后端读取前拒绝。发布或目录同步结果不确定时，写入冻结，只有显式恢复可解除，禁止自动重试。

真实普通临时目录验证：导入候选→C20→8项原生UI分流→重命名→两种导出→保存→另存C07→清空C20→关闭适配器→擦除源CUBE和源候选→新目录恢复C07完整四组件。另覆盖发布后不确定、导出容量不足/重叠、未来转换版本、载荷/模型损坏和取消。这里的“重启”是重新创建本地目录对象，未操作机身。

AArch64研究ELF实际执行2273项检查，工作区/配方字节数、候选取消、内存后端提交与代号5、重命名/工作值、双版本导出、恢复和不确定冻结均通过。内存后端不是物理介质；主机普通目录证据另行记录。相关230项回归与ASan/UBSan 20000次探测通过；回执见[本批交付](continuation-22.md)。
