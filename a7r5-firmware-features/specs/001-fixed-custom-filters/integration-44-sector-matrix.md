# 第44批：16色相区矩阵的软件接入

本批推进T08sector44：扩展文件、桌面模型、原AP发送／CP接收、持久化及原矩阵入口；原创意外观和分组发布机制保持。不操作相机、不执行目标或硬件模拟，不生成可安装固件；真实EVF/JPG与第二Gamma的生命周期关联仍未闭合。

## 端到端表示

旧`AfJointRecipe`、1943B AJR1/AJR2与converter1/2语义保持。内部`AfJointAsset`尾部增加`matrix_mode`与288项；显式新模式要求旧18项为零，避免两次叠加。旧格式解码会清零新尾部。AJR3/version3/flags15的body为2355B，总2483B：前516B沿用AJR2 seed/tone；516起576B为3×16×6矩阵；1092起48B为CC1；1140起1215B为grid。AFD1家族schema保持，converter3明确区分。仍是±1024增量，未冒用对方绝对14位系数范围。

`af_import_prepared/asset`、`af_repository_recipe`和`recipe_file.py`核对长度、converter、目标CP、模型及完整摘要。现有用户槽的导入／保存／导出／回导／新目录恢复复用原事务，不增加槽或另建保存通路。机内CUBE仍产生原AJR2；电脑默认保持AJR2，显式`--matrix-sectors 16`才导出AJR3。

`af_recipe_transport`使用事务固定总长；1943B仍28帧，2483B使用35帧。新事务需要原HELLO中的`SECTOR_MATRIX=0x100000`及本协议能力3，未知或缺能力不发送、不消耗AP输入版本。每帧总长和能力必须一致，混入旧长度的DATA/ACK不推进。原source/session/version/CRC/SHA、接收拥有权及原厂NATIVE退出保持。真实AP发送和CP原消息入口分别由宿主集成测试覆盖，不将软件ACK称为照片生效。

AP运行时、CP配置、UI能力掩码及真实loader启动期望均同步新能力，完整构建required为`0x1f1fff`。旧四页分支明确`LEGACY_ONLY`，只保留AJR1/28帧，不声明16区能力；不通过扩大旧四页掩盖容量失败。

## 原矩阵入口和容量

原`af_cp_components406_matrix`仍先调用原厂构造一次，取得本次worker的不可变银行与原sector，按`(endpoint*16+sector)*6`选18项、展开27项，再叠加于原结果；前后复核来源。范围错误、sector越界、身份改变或不适用profile都保留原厂结果，原FL2/FL3路线保持。

运行银行改为`AfCpRuntimeAsset406`，只保存消费者读取的base/model/tone/matrix/CC1/grid；完整接收器仍校验seed与最终Gamma后深复制，银行不再重复保留两份129点曲线。单副本1928B、双银行4200B，省896B。接收arena从16384B调整为17600B，全部仍位于原49152B RW预留，未增加页。

本批完整原生目标实测RX27508/32768B、静态RW48456/49152B，剩696B；原288B永久包装区、408B启动尾和18挂点合同保持。引用／银行满／未知提交策略与原分组发布不变，没有新增整配方原子publisher或图像帧租约。

## 同模型预测与误差选择

`af_edit_joint`新增逐区参数／构表API；`af_reference_joint`新增逐区准备／预测与独立模型SHA。缓存包含全部288项，新旧API切换重建正确模式。零区和旧18项逐区重复的数值结果一致；完整模型仍按原整数混合、14位打包、舍入、曲线准入与经验grid计算，没有绕过SKIP或伪装新照片域。

电脑16区模式搜索三tone／288矩阵／24 CC1／1215网格；257候选基线仍用旧模型求解，再按端点重复到16区。新模式优先搜索固定Q8权重实际选择的端点1；只有其中96个矩阵系数可辨识。训练512、选优25、最终测试18，三类区域隔离，最终测试不参与选优。

## 完整Gamma与成像边界

本轮保留三tone，未自动扩展任意129点Gamma。当前128↔129桥明确限制61440独有节点及两倍输出的18位范围；模型内试验不能替代未知域、原八值变化或第二域的来源证据。对照尚未证明新增完整Gamma能够可靠降低这些尾部误差，因此不以删除SKIP或覆盖所有原厂列来强行开放。

成像主线补齐原A池490对象容量、双构造、普通重建、五参数序列化恢复、逆格式化及释放的静态证据；`A+4`是引用数，不是版本。另完成[五门容量候选](../../../.local/implementation43-five-permanent-gates/README.md)：在原400B内保留五个独立入口、三处原BL、BEF9BB身份和活动栈，交叉链接及30008夹限／27040路由整数对照通过。但计算／间接入边未穷尽，候选未并入产品；8项约536B旁表也仅为预算。普通重建失效、真实授予/消费、并发及回收职责不能省略，mode1仍委派原厂。后续只在这些职责有实际挂点和生命周期证据后推进，最终EVF/JPG不因矩阵模型或主机测试自动通过。
