## 剩余关键缺口

1. **原旧消息与整组请求的顺序。** 旧九条单字段消息没有版本，仍走原委派，可能晚于新PRESET写回同一输入。完整九字段回退接口解决“只恢复base”，但没有解决异步覆盖；不靠丢弃原消息或改690绕过。研究UI绑定默认关闭，原厂／旧6仍正常委派。
2. **完整像素预测和LUT原生消费。** 两参考项目对非零网格的PC模型均保留临时假设；现有前端数值不定义当前CP网格轴／响应、显示sRGB桥或实际上传消费。Gamma／矩阵／CC1／网格联合搜索已存在，合格完整模型仍未绑定，不能用前端0码差或合成回调顶替。
3. **真实机内存储与旧6完整迁移。** 原挂载入口及门控已定位，但私有命名空间、容量、耐久和个人运行值未取得；普通目录副本不证明机内掉电。旧资产不包含生成AJR1所需的完整模型、最终条件Gamma、原LUT来源与误差，当前不得静默迁移。
4. **EVF／JPG和最后帧。** 输入准备、原资源标志、文件保存和宿主回归均不能确认图像已使用同一完整版本；仍需原消费者／缓存及帧寿命证据，设备验收仍需后续明确授权。

已完成的仅为上述有明确证据的软件子范围。M1～M4父任务、实际LUT成像和可刷写候选门禁继续保留。
