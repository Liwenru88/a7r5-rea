# 整合设计

- Feature ID: `002-native12-combined-firmware`
- Status: `implemented-offline`
- Updated: `2026-11-02`

独立模块为 `a7r5-firmware-features/native24-combined/dependencies/native12-combined/`；源码快照和派生产物进入新的 `.local/native12-combined-*` 目录。既有 001 工程、4.06／4.08／4.09、故障现场及上游原件不修改。

## 构建边界

1. 固定远端提交和 188 项源码锁，读取其构建入口。提供逐项摘要匹配的官方 4.00 输入；本项目签名身份与上游不同，组件复现和本地签名分开记录，禁止伪造上游完整 DAT 身份。
2. 先生成远端原版 AP／CP／参数模板基线，检查冻结输出。若工具链产生不同机器码，定位差异并明确记录，不能只删除目标摘要门槛。
3. 基于该基线合入局部补丁。FL2／FL3 检查是否已有等价实现；如需保持本地内嵌参数语义，只增加对应原生接入，不混入旧六款或旧加载器。NTSC 使用本地两处固定分支。声音使用同源限定 type1 选择器并分配有证据的可执行空间。照片标记迁移固定 28 支持位和三登记范围，重查 ELF 映射、RELA、空白及分支目标。
4. 保留远端原始静态图标资源方案，不导入旧 4.09 图像资源。派生 AP／CP 回写到上游布局已核对的分区；参数模板使用远端原有配方，更新校验清单。
5. 按用户最新版本要求，以本项目既有研究身份签名新4.10，并使用独立解包器核对完整产物。版本使用同一常量驱动BCD头、封包和回执；与已有4.37比较，TAR、AP／CP／分区、BIN及公钥必须相同，明文头仅版本字节及CRC变化。签名工具仅在封包时读取指定私钥，日志不记录密钥内容。原 updater、模型／地区／归档布局与原始输入合同保持。

## 文件计划

- `native12-combined/build.py`：输入准备、固定上游重建、整合及封包入口。
- `native12-combined/patches.py`：固定前像、补丁冲突、功能组合和逆向审计。
- `native12-combined/sound.S`：限定 type1 的同源声音选择器（仅按实际需要创建）。
- `native12-combined/tests/`：最小冲突拒绝、功能与封包合同回归。
- `native12-combined/README.md`：复现、交付及未验收边界。
- `.local/native12-combined-*/`：上游快照、原始输入、构建中间件、回执及最终新候选。

文件细节可随实际接口检查调整，行为和范围不变。源码锁／输入不匹配、映射或可执行空间无证据、无法保持签名或分区合同均停止对应阶段，保留失败回执。重新运行使用新输出目录，不覆盖既有结果。

实际落点补充：`selection.S`将原函数132字节窗口内的选择逻辑与十二项映射一起重编，修复远端旧保存基底0仍发送ST。`integration.S/.ld`将矩阵与声音放在已搬迁的原两条Gamma曲线RX范围；曲线原始1152字节与2304字节矩阵一起作为3456字节受校验载荷复制到BSS末尾空隙。复制器使用32＋92字节两个既有前缀间隙，远端76字节映射器保持，未新增RX页。源／目标完整性和重复调用均有CPU测试，页表根和栈布局保持。AP实际RX前像终点为`0x500fbb7`，活动PHDR位于`0x5ce0000`；标记包装器仍放在`0x500fc10..0x500fc70`的同页空白内。旧4.06地址约定不能原样套用。

## 验证与回退

V1 覆盖固定前像拒绝、重叠拒绝和声音条件；V2 对当前真实 AP／CP 检查 FL2／FL3、NTSC 和标记登记，确认上游逻辑未被覆盖；V3 为完整 DAT 签名／逐帧校验／独立解包／成员白名单及输入保持。AC-001～AC-006可共享集成回执。所有相机功能和安装验收另列 MANUAL_REQUIRED。

本次回退仅为停止使用新本地产物；旧工程及输入保持。相机刷写和相机恢复未获授权，也不由本地成功回执保证。
