# 自定义滤镜浏览预览与状态刷新

用户报告4.15不再重启，但上下浏览自定义滤镜时出现“等待切换／切换未完成”，停止操作后界面不自动更新；随后确认尚未按中键。因此“中键确认后也应用失败”不是已证实事实。原厂创意外观在列表移动时提交预览，当前附加项也沿用此行为。

本轮继续离线，不连接相机，不修改已交付4.15及此前包。范围为原E4参数发送完成判定、冻结八项微调的原生提交、UI值通知推进最后目标及重绘。保留Tab只浏览、中键确认、右键调参、最后目标合并、真实发送与E4门禁、失败回退和配方身份保存。

验收：实际AP原E4九次分派及逐项打包可完成八项微调；不能仅因缺少整包而失败，也不能跳过未发送参数后宣称成功；发送失败不发布新选择；迟到／错误对象不提交新参数；原生值通知可在无新按键下推进最后目标及请求重绘，无变化不重复提交。原厂路径及既有功能回归保持。CPU、QEMU和实机证据分别报告，不把收到模拟事件当作实机自动刷新已恢复。
