# 创意外观统一入口

Feature ID: 005-unified-creative-look
Status: IMPLEMENTING
Created: 2026-11-02

用户已确认实施；全程离线，不连接相机。以现有十二款后端及 E4 菜单修复派生 AP 为基础，不改冻结上游、32 槽工程或历史升级包。

| 需求 | 验收标准 | 验证方式 |
|---|---|---|
| REQ-001 统一入口 | AC-001 原创意外观 MID 0x1f2 保留原十九项，追加十二款；主菜单和 Fn 候选不再出现 0x635 | AP 指令测试、实际 QEMU 帧 |
| REQ-002 选择隔离 | AC-002 扩展编号不写入原厂 0x690 或有限参数数组；原厂、FL2／FL3、六槽的原路径保留 | AP 指令、写入观察及失败路径 |
| REQ-003 沿用事务 | AC-003 十二款沿用 SELECT→原 E4→SELECT→持久化门禁；切原厂先退出覆盖，失败保留旧应用结果 | 原后端回归、QEMU AP/CP/文件交叉核对 |
| REQ-004 界面与兼容 | AC-004 十二款名称可读，无独立关闭行；普通项目保留原生调参，自定义项目禁止写原厂微调 | QEMU 截图、原生回调测试 |
| REQ-005 可追溯交付 | AC-005 独立覆盖层严格校验前像、ELF 权限和逆还原；旧 DAT、CP、BIN、本地四项不变 | 构建收据与摘要、相关回归 |

完整拍摄初始化仍缺 0x2040 成像状态通知模型。菜单隔离结果不能解释为完整启动、图像效果或相机可刷验证；本次不发布替换旧 DAT。
