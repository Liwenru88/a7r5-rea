# R6 ST 色彩模板

从原厂 4.00 的十二份通用 GL 模板出发，更新 ST 的 CC1 与矩阵两个字段。清单锁定属性、偏移、长度及目标数据摘要，实际数据沿用已归档的色彩字段资源。

在构建配置的 `modules` 中加入 `color-r6-st`。与 AWB 同选时，三个字段交给同一次模板写入。内部 BK4 校验值和外部 `backup.sum` 由对应写入器重算。单选用 4.06 包头复现历史单项包，机内效果取决于原厂模板加载流程。
