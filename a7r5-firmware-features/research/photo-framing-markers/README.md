# 照片构图标记

选择 `photo-framing-markers` 后，照片构图标记菜单增加开关、透明度和包含 2.35:1 的比例选项。此功能用于构图辅助，实际 JPEG／HEIF 裁切由另一模块规划。

清单记录 37 处前像和结果。原厂 AP 单选与历史 4.07 对照。与 24 槽组合时，构建器按当前 ELF 的活动程序头定位 RX 长度字段，核对后续段，再与 NTSC 的 AP 修改一次合并。历史 QEMU 证据覆盖菜单和属性，实际照片页叠加仍待验证。
