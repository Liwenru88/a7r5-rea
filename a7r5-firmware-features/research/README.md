# 未实机验证模块与历史研究归档（`a7r5-firmware-features/research/`）

本目录集中存放 **未纳入当前稳定主线** 的实验性固件模块、早期研究原型、历史组合预设与设计文档。

> **重要提示：** 本目录下的模块与预设**尚未完成完整实机验收**（或已在历史版本中被排查剔除），**不应直接用于日常实机刷写**。如需构建当前最新稳定主线，请返回上级目录使用 **稳定版构建入口**（`./scripts/build_from_400.sh`）。
