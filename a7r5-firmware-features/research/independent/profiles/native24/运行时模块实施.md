# 24 槽运行时模块实施

这些模块共同组成 [24 槽封包单元](README.md)。从源码实施时先锁定相对偏移版 4.17 的基线和组件，按下列依赖顺序接入，最后用整对 AP／CP 和图标进行回放。各模块的测试可单独执行。

## 格式与成像传输

1. 由 `derive.py` 从冻结十二槽上游派生 24 槽，按 `layout.json` 同步位掩码、配方记录、堆占用和 AP／CP 选值。
2. 验证 v4 和 v5 文件结构、数量及配方编号。未配置槽从可用掩码中剔除。用同一份格式和真实用户文件构建 CP 银行。
3. 保留上游 AP 消息和 CP 色彩消费者。选择、Gamma、矩阵与色度可分别做指令回放。配方合成、训练和机身成像属于不同验证层。
4. 用原十二槽文件、部分 v5 库、满库和损坏文件回放。从 AP 选择一直检查到 CP 工作配方，再核对 ST／FL2／FL3 返回路径。

[格式派生](../../../firmware-runtime/derive.py) · [布局锁](../../../firmware-runtime/layout.json) · [上游 CP 色彩入口](../../../firmware-runtime/dependencies/native12-combined/upstream/firmware/r5/src/cp/native_color.c)

## 冷启动导入、机内存储与恢复

1. `r5_stage413_thread.c` 从已绑定的启动入口扫描卡和机内有效库，先验证完整数据再发布。双卡按现有优先级，短读、零字节和未知格式均验证失败路径。
2. `r5_stable_io425.c` 承载临时文件与发布，比较相同内容避免重复写。保留最近一次有效库，遇到 CP 封存失败和重启中断时按状态恢复。
3. 用 `r5_filter_selection_load`、`r5_filter_selection_save` 恢复最后成功选择。R5SEL6 绑定库身份。换库后的失效记录通过可用项判断回退。
4. 通过 [稳定性用例](../../../firmware-runtime/tests/test_stability.py)覆盖同库、换库、缺卡、空文件、短读和发布失败。回放的文件系统语义与实机掉电结果分别记录。

[启动线程](../../../firmware-runtime/runtime/r5_stage413_thread.c) · [事务存储](../../../firmware-runtime/runtime/r5_stable_io425.c) · [选择状态](../../../firmware-runtime/runtime/r5_filter_selection423.c)

## 切组、自动预览与后台恢复

1. `unified-look.c` 在原创意外观接入两个组。分组和按键方向使用当前画面方向，原厂条目在允许时由原厂回调执行。
2. `n12_select` 与 `n12_preview` 将可用的自定义项送入同一个选择服务。每组保存成功应用的项，失败或无效记录回到首个有效项。空组保持已确认的外观。
3. `r5_filter_service` 串行推进 CP 切换与 E4 完成，把后来的输入收敛为最后目标。预览成功后保存选择，超时或迟到回执交由后台同步和回退。
4. 原生空闲事件推动服务和重绘。用 [Tab 和确认](../../../firmware-runtime/tests/test_tabs.py)、[空闲刷新](../../../firmware-runtime/tests/test_preview_idle.py)及[界面同步](../../../firmware-runtime/tests/test_ui_sync.py)覆盖首项预览、竖屏方向、快拨、切组回忆、调参中键返回及迟到回执。

[菜单与分组实现](../../../firmware-runtime/runtime/unified-look.c) · [切换状态机](../../../firmware-runtime/runtime/r5_filter_runtime423.c)

## 八项相对偏移和名称资源

1. 自定义调参页读取 `r5_tune_offset` 并通过 `r5_tune_offset_edit` 修改单项偏移。原厂条目继续使用其原生工作值。
2. 发送时用当次原生值加偏移并限幅。保存只在成功完成后提交。同色彩配方改名或换槽仍使用相同身份，换配方时全部显示 0。
3. R5TUNE2 读取旧 R5TUNE1 时将绝对值映射为相对值，正常保存后迁移。原始 BIN 保持作为独立配方输入。
4. 保留 AP 标题、中文名称和图标的一致资源身份。图标的额外压缩块遵守 4 KiB 边界。使用[相对参数测试](../../../firmware-runtime/tests/test_relative_parameters.py)、[原生 E4 测试](../../../firmware-runtime/tests/test_native_e4_parameters.py)和[图标边界测试](../../../firmware-runtime/tests/test_icon_pages.py)。
