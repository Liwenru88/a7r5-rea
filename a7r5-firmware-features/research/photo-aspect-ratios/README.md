# 十档照片纵横比

模块 ID 为 `photo-aspect-ratios`，基线为 ILCE-7RM5 原厂 4.00，当前修订 5。原厂四档 3:2、4:3、16:9、1:1 之外，新增 17:6、65:24、5:4、7:6、1.91:1、2.35:1。确认后后台保存到机内独立文件，取消恢复进入菜单前的比例。 [模块清单](module.json) · [实施与复验](实施与复验.md) · [修订 4 修复记录](../specs/4.19-operation-fixes/实施与验证.md)

修订 4 增加临时读取失败后的限次补读、后台保存和原生菜单失败提示，保留原格式和成像组件。修订 5 修正机端 AArch64 的目录打开标志：`O_DIRECTORY=0x4000`，避免误用 `O_DIRECT=0x10000`。文件服务夹具同时检查目标 ABI，保存恢复用例覆盖此差异。原封存 `releases/4.19-full` 包仍为修订 3，新包须按构建锁和摘要区分。

| 环节 | 实施 |
| --- | --- |
| AP 菜单和取景 | 保留十档及原厂属性域。新增行委派原厂 3:2 的模式保护；取景只补静态型号列 16，保留其他原厂拒绝。实时取景保留完整源并绘制横竖遮罩。 |
| 取消与重启记忆 | 原生 Fn 捕获／恢复与私有状态成对处理，用新代次发布，过期回调不覆盖新选择。保留首次立即恢复，临时失败后台限次补读；确认排队保存，失败显示提示，成功恢复原标题。 |
| AP／CP 消息 | 私有比例编码为 `0xe0–0xe5`。CP 逐张锁存，返回原厂比例后清除私有比例；两张在途任务各用自己的比例。 |
| CP 任务复制 | 原生 Capture 任务复制时一并传递源任务已锁定的比例。普通 3:2 或无有效自定义比例的来源清除目标槽的旧记录。 |
| JPEG／HEIF／RAW 预览 | JPEG 请求副本裁切；HEIF 保留 CP 共享 YC 区，在 AVCAM 每格式局部区域裁切。RAW 原始像素和原厂裁切标签保留，内嵌 JPEG 按锁存比例生成并同步声明。 |
| 照片回放 | JPEG 实际 SOF、私有 Exif 和即时缓存一致；RAW 仅同步私有预览标签，HEIF 补辅助图分类。AP 为精确尺寸补图标、像素数及有资格的未知比例放大门，保留其他拒绝。 |
| 资源和归档 | 两份图标、68 份语言资源及 AP／CP／AVCAM／MPR。AVCAM 在原 FAT 簇链余量内增长，MPR 增加只读执行段；原有映射及非目标文件保持。WBI 仍沿用既有失效策略。 |
