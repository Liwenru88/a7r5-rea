# 原AP动态界面的隔离接入

这里包含锁定4.06的匿名指令验证，以及`guest/`内独立QEMU/Qt菜单实验；不提供相机安装入口。来源为已固定源CPIO中的原AP和同包C++库；所有被执行的原代码页来自实际ELF，只有合法BSS按ELF定义初始化为零。

`loader.py`装载`AF_AP_DYNAMIC`动态ELF，限定RELATIVE重定位、128KiB模块预算和RX/RW分离。当前57处原入口／调用点各只改一条B/BL，132处绑定前像；远目标使用范围内独立16字节跳板，保留原函数+4及完整后续指令。原首指令使用x16的入口不能直接套用该跳板，全部入口须从锁定AP逐条核对。新增入口隔离图标、父页面、调参、基底、定向名称、重置和管理键盘，禁止用全局旧索引替代新增身份。

`runtime.py`执行同包原注册器和C++红黑树函数。分配器、菜单资格回调、事务边界及128字节临时复制明确列为隔离服务，不声称执行完整系统初始化。未知访问仍失败，不能靠增加无来源零页通过。

运行定向验证：

```sh
.venv/bin/python -B -m pytest -q -p no:cacheprovider \
  a7r5-firmware-features/custom-filters/experiments/native-ui406/test_loader.py
```

`guest/`使用新的独立运行输入、原线程和预UI装载时序。新增C07～C20编号图标由两份00组image UXC的新增资源记录提供，通过原资源库和原呈现器绘制；原记录及原像素载荷保持。真实Qt已验证32项导航、C07十二基底/八项工作值、两页英文动态名称、同槽刷新与编号回退。原重置确认/取消另有UI线程全目录和原163个word保护回执。证据见主规格的[验证记录](../../../specs/001-fixed-custom-filters/verification.md)及`.local/fixed-custom-filters/names-mainline27/`；这些结果不等于CP成像或机内保存。

名称装载先核验原AP、同包libObj和模块完整摘要，取得原字符重载/资源重载/getString的同源基址；初始化唯一`af_ap_labels`并绑定，再安装入口。标题只由主页面`0x2208e8c`和参数页`0x220c8a0`产生私有标记，原文字呈现器`0x1885b38`调用原字符重载复制UTF-8；其他资源继续原函数。标记不作为原UXC资源加载。

注册前且名称从未启用时才可移除挂钩并回收模块。注册后原注册器持有新增行；名称一旦启用，原模型也可能保留标记。因此必须保持整组入口驻留，即便后来禁用也禁止恢复原sprite调用点。实际多线程/页面销毁未验证，不提供完整客体热卸载。

原确认对话框仍控制重置和取消。`0x263d558`仅将匹配快照的已安装用户槽恢复到`initial`，并经原`0x1700`属性事务刷新基底显示；原厂和未迁移旧六槽委派原函数。空、禁用、受限、陈旧或无法解析的私有身份拒绝，不从`0x690`猜槽位。完整客体的确认/取消与原数组保护另由当前回执验证。

`--names-fixture`只允许与`--attach --seed-c07`组合，用于本客体的显式名称文档内存夹具。名称请求在原UI线程发布并调用`af_ap_label_refresh`，不代表保存或恢复完成。默认环境不装入测试名称，也不把内存夹具写入产品源码。

当前英文locale对中文名显示缺字框，尚未实现跨语言字体fallback。客体setup的tmpfs会遮住源CPIO的`/tmp/images`中文字体，实验仅从同包原文件恢复并核验摘要；不改fontlist、语言资格或产品字体逻辑。中文字形仍须在有依据的原中文locale下单独验证，不能用UTF-8记录正确代替像素通过。
