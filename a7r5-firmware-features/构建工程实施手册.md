# 原厂 4.00 模块化构建

第一阶段提供四个根目录模块。

| 模块 ID | 效果 | 组件或资源 |
| --- | --- | --- |
| [video-ntsc-prompt](video-ntsc-prompt/README.md) | 关闭两处指定 NTSC 提示 | AP |
| [photo-electronic-shutter-sound](photo-electronic-shutter-sound/README.md) | 启用电子快门声音选择 | CP |
| [color-r6-st](color-r6-st/README.md) | 更新 ST 的 CC1 和矩阵模板 | 十二份 GL 地区模板 |
| [color-awb-priority](color-awb-priority/README.md) | 更新 AWB 白色／氛围优先模板 | 十二份 GL 地区模板 |

用户配置只声明原厂基线与模块 ID。程序核对 DAT 摘要，确定组件和归档写入范围。AP、CP 各生成一次，所选模板字段一次合并写入。DAT 工具随后更新 `part_image.sum` 与 `backup.sum`。第一阶段沿用四个历史单项包的原厂 WBI 镜像及更新器。

## 选择、构建和复验

在仓库根目录执行。复用 DAT 工具的 Python 环境、研究签名配置、OpenSSL 及 `e2fsck`。包含 AP 模块时使用 PATH 中的 `e2fsck` 或 Homebrew 的固定路径。每次构建使用 `.local` 下的新输出目录。建议给单次构建预留至少 10 GiB。 [DAT 工具准备](../a7r5-dat-tool/README.md)

~~~sh
set -e
root="$PWD/a7r5-firmware-features"
py="$PWD/a7r5-dat-tool/.venv/bin/python"
stock="$PWD/a7r5-firmware-images/官方升级包/BODYDATA.DAT"
mkdir -p "$PWD/.local"
out=$(mktemp -d "$PWD/.local/compose-example.XXXXXX")

# 此配置只启用 NTSC 提示模块。更改数组可选择多个模块。
printf '%s\n' '{"base":"ilce-7rm5-4.00","modules":["video-ntsc-prompt"]}' > "$out/selection.json"
"$py" -B "$root/compose.py" plan --config "$out/selection.json" --base "$stock"
"$py" -B "$root/compose.py" build --config "$out/selection.json" --base "$stock" \
  --version 4.06 --output "$out/ntsc"
"$py" -B "$root/compose.py" verify --base "$stock" --bundle "$out/ntsc"

# 四项全开示例。
"$py" -B "$root/compose.py" build --config "$root/presets/phase1-all.json" --base "$stock" \
  --version 4.20 --output "$out/all-four"
~~~

输出包含 `BODYDATA.DAT`、`lock.json` 与 `verification.json`。锁记录模块版本、原厂基线、构建源码摘要及期望归档成员。独立复验从原厂重新生成期望内容，再按全归档逐项比对，检查 ext2 与 OpenSSL 研究签名。若当前构建器源码已更新，复验仍要求模块计划和重建的期望内容与锁一致，并报告构建器更新。历史精确复现继续使用现有独立配置。 [原厂 4.00 基线](bases/ilce-7rm5-4.00.json) · [旧包复现](independent/README.md)

## 4.25 全功能组合

全功能预设从原厂 4.00 生成，使用 `look24` 一次启用整套 24 槽功能。使用 4.24 全组合做功能基线时，五项可各自加配，也可同时启用。单选沿用原厂前像和历史版本标记，构图标记为 4.07，其余四项为 4.06。新增组合标为 4.25，各包按 DAT 摘要区分。逐包回执仍记录当时使用的历史拆分 ID。 [全功能预设](presets/full-stock400.json) · [逐包回执](tests/full-stock400-verification.json)

| 加配项 | 组合写入 |
| --- | --- |
| 照片构图标记、NTSC 提示 | 在同一份最终 AP 上校验原指令再写入。构图标记按活动 ELF 程序头扩展主 RX，从 `0x500fc10` 到 `0x500fc70`，纵横比加载段和各语言资源保持 4.24 内容。 |
| 电子快门声音 | 单选使用原先的声音入口布局。含 FL2／FL3 的全组合中，旧位置已被色彩链使用，复用已编译验证的 4.17 声音路径，把入口放在 `0xbef700`，在 `0xbef720` 矩阵入口之前结束。镜头 AF 和纵横比启动入口保持各自原位。 |
| R6 ST、AWB 优先 | 先合并所选的三处字段，再对每份原厂 GL 模板写一次。生成十二份模板及 `backup.sum`，与第一阶段同时启用两项时的模板逐字节一致。 |

沿用手册开头的 `root`、`py`、`stock`、`out`。所有构建从同一份原厂 DAT 开始，各自输出到新目录。

~~~sh
all="$root/presets/full-stock400.json"
"$py" -B "$root/compose.py" plan --config "$all" --base "$stock"
~~~
