# 4.17 研究更新包

创意外观主列表按左键切组。两组各自记住运行期间上次成功应用的滤镜，切回时自动定位并请求预览。无记录或记忆项不可用时，选择第一款有效滤镜。自定义配方库更换后从首款有效配方开始，空库时保留当前外观。

预览成功后沿用原有选择保存流程。两组的独立记忆在相机本次开机期间有效，退出菜单再打开仍可恢复。相机重启后，原有机制恢复最后保存的当前选择。右键进入八项调参，中键确认返回创意外观上一级。

随包提供十二款正式配方 R5NATIVE.BIN。使用与 4.16 相同的研究签名公钥和原厂更新器。离线封装校验见 verification.json。

同一候选通过 28 项 CPU 回归和 39 组 QEMU 原帧核对。QEMU 验证了原厂 PT 恢复定位、调参工作值和中键返回。QEMU 的 E4 初始化仍阻塞，自定义滤镜成功应用后的恢复、取景和自动保存待实机复验。

实机复验时，先应用一款原厂滤镜，再切到自定义组并成功应用一款非首项滤镜。左键往返后，检查两边是否恢复各自那一款。等最后一款自定义滤镜应用成功后直接退出菜单，再重启相机，检查当前选择是否恢复。
