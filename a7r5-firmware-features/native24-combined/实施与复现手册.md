# A7R5 4.17 整合版实施与复现

从锁定的原厂 4.00 DAT 和冻结的上游 4.36 源码重建 AP、CP 和两份界面图标，再用项目研究签名生成 4.17 DAT。已发布文件及适用范围见 [4.17 交付说明](releases/4.17/README.md)。

## 功能与代码落点

| 功能 | 行为和代码 |
|---|---|
| 创意外观 | 原厂外观和自定义滤镜共用入口。主列表按左键切组并预览，优先恢复本次开机期间该组上次应用成功的项，其次选择首款有效项。空库保留当前外观。中键确认，右键调参，调参页按中键返回上一级。原厂行委派原厂逻辑。见 [菜单、调参和重绘](runtime/unified-look.c) |
| 预览和成像 | 沿用原十二款的 AP／CP 配方传输、原厂色彩和 Gamma 路径。快速连续选择只保留最后目标；原生空闲事件推进状态与重绘。成功后自动保存；失败由后台恢复，必要时回退到已确认状态。见 [状态机](runtime/r5_filter_runtime423.c)、[CP 色彩消费者](dependencies/native12-combined/upstream/firmware/r5/src/cp/native_color.c) |
| 冷启动导入 | 将 R5NATIVE.BIN 放在 SD 卡根目录，关机后再开机触发扫描。相同内容逐字节比对后跳过重写；无卡、缺文件或零字节文件时使用有效机内库。新库发布或 CP 封存失败时按条件回退上一份有效库。见 [启动工作线程](runtime/r5_stage413_thread.c)、[机内事务](runtime/r5_stable_io425.c) |
| 24 槽与启动恢复 | 兼容十二槽 v4 配方，运行时可读取 24 槽 v5。未导入槽位不参与应用。R5FILTER.BIN 保存最后成功选择，当前格式 R5SEL6 绑定库身份。重启恢复最后有效选择；两组独立记忆只在一次开机期间有效。换库后过期的自定义记忆失效。见 [格式派生](derive.py)、[选择持久化](runtime/r5_filter_selection423.c) |
| 八项调参 | 按色彩配方 SHA-256 保存微调，同配方改名、换槽或重导入可复用。新配方读取原厂 ST 默认字段，照片模式为 0／0／0／0／0／4／3／1。微调存于机内 R5TUNE.BIN，原配方 BIN 保持原样。见 [微调和恢复](runtime/r5_tune425.c)、[调参交付说明](八项调参交付说明.md) |
| FL2／FL3、NTSC、电子快门声音、照片 2.35:1 | 构建按固定前像合入本地 AP／CP 补丁。NTSC 补丁针对指定提示，照片标记用于构图。见 [四项补丁](dependencies/native12-combined/patches.py)、[照片标记方案](../aspect-guide406/patch-plan.json) |
| 字体和图标 | 中文字体适配和两份界面图标随 AP／CP 构建。新增图标按原厂边界分块。见 [资源编解码](icon_codec.py)、[构建与校验](build.py) |

随包提供 [正式十二款配方 R5NATIVE.BIN](releases/4.17/R5NATIVE.BIN)。容量原型的合成槽仅供测试。涉及配方、共享内存或 AP／CP 协议时，同时核对 [布局约束](layout.json)、[派生匹配约束](derive-matches.json)和[运行时前像](runtime-inputs.json)。

## 准备

- 从仓库根目录执行命令，保留[目录归并清单](目录归并清单.md)中的依赖。原厂输入默认使用 `a7r5-firmware-images/官方升级包/BODYDATA.DAT`，共 754525608 字节，SHA-256 为 `51e1176a255a9a4b4782dfbcfa6c5f332b71173bdfe9ed2bcf4fca6bcbc6c2e2`。构建器按[上游输入锁](dependencies/native12-combined/upstream/firmware/r5/inputs.lock.json)验证。
- 已验证 macOS、Python 3.14.0、Apple clang 21.0.0、Homebrew LLVM／lld 23.1.3，封包使用 `/opt/homebrew/opt/e2fsprogs/sbin/e2fsck` 和 `/usr/bin/openssl`。根目录 `.venv` 提供 pyelftools、Capstone、pytest 和 CPU 回归依赖，`a7r5-dat-tool/.venv` 提供 Cryptodome 和封包回归依赖。预留至少 10 GiB。
- 本机重签名需要 `a7r5-dat-tool/keys/research-signing-private.pem`，对应公钥 SHA-256 为 `7f65b296987df665da217de514e785f75238e686ddd18952fa425fc47e8c858a`。发布仅携带公钥。基线和运行时构建无需私钥。

## 重建基线及四个组件

```sh
set -e
feature="$PWD/a7r5-firmware-features"
out="$PWD/.local/native24-handoff-$(date +%Y%m%d-%H%M%S)"
mkdir -p "$PWD/.local"
mkdir "$out"

elftools_parent=$(.venv/bin/python -B -c 'from pathlib import Path; import elftools; print(Path(elftools.__file__).parent.parent)')
PYTHONPATH="$elftools_parent" a7r5-dat-tool/.venv/bin/python -B \
  "$feature/native24-combined/dependencies/native12-combined/build.py" --phase baseline \
  --original "$PWD/a7r5-firmware-images/官方升级包/BODYDATA.DAT" \
  --output "$out/baseline"

.venv/bin/python -B "$feature/native24-combined/build.py" \
  --baseline "$out/baseline" --output "$out/runtime"
.venv/bin/python -B "$feature/native24-combined/build.py" \
  --baseline "$out/baseline" --output "$out/rebuild"

for file in appFw.so cpapp-b.bin image_00_23_IPSX.uxc image_00_32_IPSX.uxc; do
  cmp "$out/runtime/$file" "$out/rebuild/$file"
done
```

基线解包并重编冻结上游，产生 `baseline.json`、分区基线和 `work/inputs`。主线派生 24 槽运行时、应用本地补丁、接上创意外观并生成图标。两次构建的 `build.json` 记录工具链、派生改动和组件摘要，预期值见[候选身份](current-candidate.json)。

## 定向验证

在同一个终端继续执行。覆盖两组记忆、首款回退、自动保存、预览刷新和 E4 八项逐条发送。CPU 测试执行候选 AP／CP 机器码，外部 E4、文件系统和原厂界面由夹具驱动。

```sh
tests="$feature/native24-combined/tests"
A7R5_NATIVE24_BUILD="$out/runtime" A7R5_NATIVE24_EVIDENCE="$out/runtime/evidence" \
  .venv/bin/python -B -m pytest -q -p no:cacheprovider \
  --junitxml="$out/runtime/tab-memory-regression.xml" \
  "$tests/test_tabs.py" "$tests/test_preview_idle.py" \
  "$tests/test_native_e4_parameters.py::test_native_e4_individual_messages_apply_all_eight_values_without_full_packet" \
  "$tests/test_native_e4_parameters.py::test_native_parameter_send_failure_rolls_back_and_idle_does_not_retry" \
  "$tests/test_background_interaction.py::test_delayed_e4_background_recovery_keeps_only_last_ui_target"
```

改动导入、回退或图标编码时，按影响补跑 [导入与回退回归](tests/test_stability.py)、[图标边界回归](tests/test_icon_pages.py)。部分旧 CP 兼容用例仍需历史基底，见[目录归并清单](目录归并清单.md)。

## 重签名并独立回读

封包会核对发布时的固定回执、历史源码快照和 QEMU 清单，并要求上一步在当前路径生成的 28 项 CPU 回归回执及 XML。新构建和回归证据另以 `reproduced-` 前缀保存。运行时组件身份变化时，应建立新的候选及验证回执。

```sh
release="$feature/native24-combined/releases/4.17"
a7r5-dat-tool/.venv/bin/python -B "$feature/native24-combined/release417/build.py" \
  --baseline "$out/baseline" --runtime "$out/runtime" --rebuild "$out/rebuild" \
  --evidence-dir "$release/evidence" --output "$out/package"

(cd "$out/package/delivery" && shasum -a 256 -c "$release/SHA256SUMS")
```

交付在 `$out/package/delivery/`，含 DAT、正式配方、研究公钥、回执和构建源码快照。预期 DAT SHA-256 为 `7e68638274e778333bb08cf33c4454c816220fe951ed40a0a1972201d22f81ef`。发布回执应记录 51 项封装回归、736841 帧、完整明文一致、独立解包和 OpenSSL 验签。若构建目录出现 `INCOMPLETE.json`，按失败步骤检查并使用新目录重跑。

- 2026-11-05 在迁移后的路径按本手册从原厂 4.00 重建两次，四组件逐字节一致，定向 CPU 回归 28 项通过。重新封包通过 51 项测试、736841 帧、独立解包和 OpenSSL 验签，DAT、正式配方及公钥均通过原发布校验清单。复现工作目录为 `.local/native24-consolidation-20261105-113601/`。
