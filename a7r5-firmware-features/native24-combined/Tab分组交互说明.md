# 原厂外观／自定义滤镜Tab

## 左键一键切组候选

在创意外观列表的任意一行按左键即可在两组之间切换。两组分别记住上次成功应用的外观，切回时自动定位并预览。首次进入目标组、记忆项已隐藏或不可用时，按目标组顺序选择第一款有效外观。切到空库时保留当前外观，左键可返回原厂组，MENU 可退出。左键的重复及释放事件不再触发第二次切组。

两组记忆存于运行时，退出菜单再打开仍然有效。相机重启后的选择继续沿用原有保存机制。预览成功后继续保存当前应用结果。自定义记忆绑定本次应用的配方库身份，换库时重新选择第一款有效配方，避免同一槽位指向另一款配方。

切组只在创意外观主列表接管左键。上下键沿组内列表移动，右键进入原厂八项调参，调参页中键沿原厂确认路径回到创意外观上一级。左键替换原厂在主列表中的另一调参入口。

两组记忆候选通过 28 项离线回归，覆盖退出菜单后恢复、隐藏槽及换库回退、失败高亮、离组后迟到的成功或失败、原生参数发送与保存回退。两次独立构建的四个组件摘要一致。构建和测试回执位于仓库 `.local/native24-tab-memory-20261105-02/`。

同一候选用 QEMU 复验了 39 次 Qt 操作和 39 组客体原帧／PNG。先高亮原厂 PT，再切到自定义首款，移到第二款，切回时恢复 PT。再次进入自定义组时定位首款，右键打开调参页，上键将对比度调至 +1，中键返回创意外观上一级，四轮顶层 MENU 往返通过。QEMU 自定义应用仍停在 E4 初始化，已应用编号为 0，因此自定义成功记忆、自动保存和取景效果未在本次 QEMU 跑通。[本次复验收据](../../a7r5-qemu/runs/native-native12-410-vjfcts40/tab-memory-proof.json)

原一键切组候选曾固定定位目标组首项，32 项离线测试通过，回执位于仓库 `.local/native24-left-switch-20261105-03/`。

以下为此前 Tab 焦点交互及历史验证记录。

本文记录013的离线交互实现；随后按用户要求已将同一套组件封装为[研究版4.13更新包](releases/4.13/README.md)，独立封装验证见[014记录](../specs/014-native24-update413/verification.md)。

2026-11-05 实机反馈确认 4.16 可以应用自定义滤镜。切到自定义 Tab 后，第一次按下进入首款时没有预览，再按下到第二款后可应用，返回首款也可应用。源码候选已让首次按下预览当前高亮的有效自定义滤镜，包含恢复到上次浏览位置的情况。左右切 Tab 仍只改变浏览位置，Tab 上的中键仍用于移入列表。回归在 4.16 的实际 AP 二进制上复现首次按下没有请求，重建后 Tab 和空闲刷新共 15 项通过。该修复待实机复验。

013候选在创意外观顶部区分“原厂外观”和“自定义滤镜”。原厂原19条注册项（包含原有自定义位置）保持原编号和资格；本工程附加配方最多24槽，未导入的槽隐藏。方括号表示当前组，`>`表示顶部Tab获得焦点。原厂名称、参数界面和八项调参沿原接线保留。

## 按键与选择

| 当前焦点 | 操作 | 结果 |
|---|---|---|
| 列表 | 首个有效项按上 | 将焦点移到顶部Tab |
| 顶部Tab | 左／右 | 浏览原厂／自定义组，恢复该组最近浏览位置 |
| 顶部Tab | 下／中键 | 进入当前组列表，不应用滤镜；空组停在Tab |
| 列表 | 上／下 | 在本组移动，沿原后台预览／应用逻辑选择目标 |
| 列表 | 中键 | 沿原确认返回；后台在途保护保持 |
| 列表 | 右键 | 进入当前外观的原调参页 |
| 调参页 | 左右、上下、中键、C4 | 原切项、调节、确认和重置弹窗保持 |
| 浏览另一组时 | MENU | 返回已应用项及原上级菜单，不应用尚未选择的浏览项 |

**切Tab及从Tab进入列表都只浏览。** 它们不发出新滤镜请求，不保存新选择，也不取消已被后台接收的事务。随后在列表实际移动、确认或主动调参，才沿原选择逻辑处理。后台同步、失败回退和最后目标合并保持，不要求手动选择ST恢复。

两组浏览位置只在当前运行期间存于RAM。关闭后重新进入，按已应用项定位所属组；这与机内保存的滤镜选择、配方身份微调相互独立。没有新增持久化文件或改变BIN、CP协议、冷启动导入和八项默认值。相同配方重导入仍沿012的身份保存规则。

## 验收边界

013实现阶段未连接相机、未签名或封DAT；后续4.13已单独封包并核对。QEMU原E4初始化缺口保留：菜单、工作值和原CP消费回放不能替代真实成像、保存、介质掉电和机身验收，整体仍为`NOT_VERIFIED`，机身安装资格未确认。切Tab不应用的证据与实际滤镜应用是否成功分开报告。

长列表滚动的AP抓帧中，偶有顶部标题部分或全部缺失。本轮`research-064-DOWN.png`与旧012的`research-032-UP.png`均可观察到；取得Tab焦点及重新入页时两组文字可见。当前模拟器没有完整CP合成／面板，不能据此断言实机同样缺字，也不能声称滚动显示已完成实机验收。本轮不通过修改截图或猜测控件字段掩盖该现象。

新增13～24号只使用合成配方验证容量，不是新增十二款成品滤镜。旧012归档、原十二槽工程及旧4.10／4.11包保持。
