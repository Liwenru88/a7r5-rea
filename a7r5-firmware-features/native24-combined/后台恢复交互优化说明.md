# 创意外观正常界面与后台回退

本次按已确认方案移除“选择ST重新同步”的操作要求。ST／PT／NT／FL2／FL3等原有外观保留原厂标题、参数区及正常编辑路径；后台处理同步、失败回退和最后目标合并。状态未确认时仍保护参数写入，不把显示正常解释为已经应用成功。

本候选仅为独立研究组件，不封新DAT，不连接相机，不改变旧4.10／4.11包。规格及过程见[011验证记录](../specs/011-background-look-recovery/verification.md)。

## 行为变化

| 场景 | 当前行为 |
|---|---|
| 原有外观页面 | 始终读取原厂名称与参数显示，取消全局恢复提示对标题和参数区的覆盖 |
| 正常调参 | 沿用原厂读取、默认值和八项编辑委派；附加槽仍隔离原有限数组 |
| 切换失败 | 后台恢复最后已提交选择，确认CP、原E4、资源和保存后结束，不自动重试失败的新配方 |
| 原E4迟到 | 等原对象真正返回再协调，不因超时反复构造新对象；错误对象不能解除在途保护 |
| 连续拨动 | 恢复期间只保留最后目标，恢复完成后处理；选择任一原有外观均可退出附加覆盖 |
| 恢复持续失败 | 保留30次／60秒总体限制及未知状态写保护，不无限重试，不要求用户选择ST |
| 损坏恢复日志 | 后台受控解除覆盖、保存并清理；不再等待用户进入ST |
| 结果反馈 | 附加滤镜在本次目标处显示“切换中／等待切换／切换未完成”等一处结果，不新增弹窗，离开该目标后退休反馈；原厂标题不显示内部恢复状态 |

冷启动导入、相同库跳过写入、零字节保护、库身份与选择绑定、R5SEL6和24槽协议保持。本轮未调整外观配方、R6 ST、白平衡或本地四项。
