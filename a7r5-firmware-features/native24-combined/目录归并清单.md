# 4.17 目录归并清单

[实施与复现手册](实施与复现手册.md)是当前入口。三个研究目录已归并到 `a7r5-firmware-features/native24-combined/`。

| 现位置 | 内容与用途 |
|---|---|
| `runtime/`、`tests/`、`build.py` | 24 槽现行运行时、AP／CP 构建和离线验证。 |
| [dependencies/native12-combined](dependencies/native12-combined/README.md) | 原十二槽基线构建器、整棵固定上游与许可证、正式配方、本地补丁、两份 IPSX 基底、旧 CP 样本和回放夹具。旧工具所需的 4.10／4.11 历史交付与验证保留在该依赖的 `releases/`、`verification/` 中。 |
| [dependencies/native24-format](dependencies/native24-format/README.md) | 4.17 使用的格式派生和冻结比对副本、合成测试 BIN，以及可独立运行的容量原型和回执。 |

| `verification/` 与旧发布目录 | 保留图标边界和故障夹具、4.16 发布包。4.13～4.15 在当前工作区保留规格、封包记录和离线证据。 |
