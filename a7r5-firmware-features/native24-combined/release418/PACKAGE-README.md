# ILCE-7RM5 4.18 研究升级包

创意外观原厂组的 C1–C6 提供 Classic Neg.、Classic Chrome、Nostalgic Neg.、Astia、GR Positive Film 和 GR Negative Film。左键可在原厂组和独立的 24 槽导入组之间切换。随包 `R5NATIVE.BIN` 是既有十二款示例库，六款内置配方无需此文件。

照片纵横比菜单共十档，新增 17:6、65:24、5:4、7:6、1.91:1 和 2.35:1。新增比例可显示构图边界。离线指令回放覆盖 JPEG／HEIF 裁切请求和 RAW 完整幅面。直接回到 3:2 时，菜单会先清除上一个私有比例，避免沿用旧裁切。

封包含 AP、CP、AVCAM、两套图标及 68 份文字资源。打包器校验所有归档成员、版本头、分区校验表和研究签名，独立解包逐一回读目标组件。完整记录见 `verification.json` 与 `evidence/`。

机身升级准入、LCD／EVF 实时取景、JPEG／HEIF／RAW 实际成片、长时间开机和视频效果待实机验收。新增比例的选择仅保留在当前开机期间。
