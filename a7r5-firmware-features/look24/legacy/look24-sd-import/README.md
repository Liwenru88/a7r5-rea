# 24 槽冷启动导入

选择 `look24-sd-import` 时，从 SD 卡根目录读取 `R5NATIVE.BIN`。卡槽选择、合法性校验、同库去重及旧库回退沿用 4.19。此模块随包提供十二款正式配方，运行时最多接受 24 个有效槽位。

省略该模块时，冷启动和暖恢复都使用已提交的机内库。配方读取和回退保护由基础模块提供。实机 SD 卡和掉电耐久性仍需独立验证。
