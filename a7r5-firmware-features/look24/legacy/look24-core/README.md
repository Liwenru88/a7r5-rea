# 24 槽基础运行时

基于原厂 4.00，在创意外观中接入 24 槽、原厂组和自定义组。基础模块读取已提交的机内配方库，保留 AP／CP 协议、有效槽位检查、E4 应用与失败回退。只选择基础时，可切组浏览并用中键应用已有配方。空库时自定义组无可选项。

在构建配置中选择 `look24-core`。其他五项能力通过各自模块开启。全开预设按 4.19 重建并校验历史组件摘要。此运行时沿用 4.19 的 WBI 首扇区失效处理和原厂更新器。
