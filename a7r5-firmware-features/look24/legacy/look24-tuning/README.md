# 24 槽八项相对调参

选择 `look24-tuning` 后，八项调参以原生值为基准，默认偏移为零，微调按配方身份保存在机内。关闭跨开机选择恢复时，微调仍通过单文件原子发布保存。恢复微调不要求重写配方 BIN。

省略本模块时，自定义项的调参入口关闭，原厂项仍走原调参路径。旧微调文件保留，自定义的原生参数消息沿用原始值。
