# 24 槽自定义滤镜

在原厂 4.00 的构建配置中选择 `look24`，一次启用 24 槽运行时、SD 卡冷启动导入、切组和浏览预览、两组记忆、八项相对偏移调参及跨开机选择恢复。创意外观入口、机内配方库、中键应用和失败回退沿用已验证的实现。

当前修订 3：修复 CP 失败传输、取消暂存并回到已发布库时的未发布缓冲遗弃；只复用从未发布的暂存区，已发布的不可变库和 16 代上限保留。多库测试夹具按实际分配长度推进，避免 947,000 字节库互相重叠。单项目标摘要锁在 [runtime-components.json](runtime-components.json)，历史独立包及其摘要不覆盖。[本轮实施与验证](../specs/longrun-resources-raw/实施与验证.md)

修订 2 的后台恢复、中键重试、E4 在途对象和保存保护继续保留。[此前修复](../specs/4.19-operation-fixes/实施与验证.md)
