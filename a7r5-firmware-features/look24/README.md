# 24 槽自定义滤镜

在原厂 4.00 的构建配置中选择 `look24`，一次启用 24 槽运行时、SD 卡冷启动导入、切组和浏览预览、两组记忆、八项相对偏移调参及跨开机选择恢复。创意外观入口、机内配方库、中键应用和失败回退沿用已验证的实现。

当前修订 2：后台恢复耗尽后，中键可先重新恢复已提交结果，再应用最后目标，保留 E4 在途对象和保存保护。单项目标摘要锁在 [runtime-components.json](runtime-components.json)，历史独立包及其摘要不覆盖。本次未重新封升级包。[修复与离线复验](../specs/4.19-operation-fixes/实施与验证.md)

只选 `look24` 时，使用单项预设和 4.19 版本标记。4.25 全功能预设也使用此模块。包含 `look24` 的包附带 `R5NATIVE.BIN`。 [单项预设](../presets/look24.json) · [4.25 全功能预设](../presets/full-stock400.json)

~~~json
{
  "base": "ilce-7rm5-4.00",
  "modules": ["look24"]
}
~~~

历史六项 ID 和说明归入 `legacy/`，继续用于旧锁和研究预设。配置中选 `look24` 时，构建计划会拒绝同时填写旧 ID，避免重复占用同一运行时。 [构建与复现](../构建工程实施手册.md#第二阶段的-24-槽和照片标记) · [计划等价检查](../tests/test_compose_look24.py)
