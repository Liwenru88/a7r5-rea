# AWB 优先参数模板

从原厂 4.00 的十二份通用 GL 模板出发，将白色优先、氛围优先的现有移植值写入指定 AWB 字段。清单锁定属性、偏移、长度及目标数据摘要。

在构建配置的 `modules` 中加入 `color-awb-priority`。与 R6 ST 同选时，模板写入器统一生成三个字段及相关 BK4 校验值。单选用 4.06 包头复现历史单项包。机内验收区分现有设置保留和原厂初始化模板生效。
