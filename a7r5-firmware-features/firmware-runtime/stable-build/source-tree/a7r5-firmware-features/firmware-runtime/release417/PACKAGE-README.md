# 4.17 相对偏移调参研究更新包

创意外观主列表按左键切组。两组各自记住运行期间上次成功应用的滤镜，切回时自动定位并请求预览。无记录或记忆项不可用时，选择第一款有效滤镜。自定义配方库更换后从首款有效配方开始，空库时保留当前外观。

预览成功后沿用原有选择保存流程。两组的独立记忆在相机本次开机期间有效，退出菜单再打开仍可恢复。相机重启后，原有机制恢复最后保存的当前选择。右键进入八项调参，中键确认返回创意外观上一级。

自定义滤镜八项改为相对原生基准的偏移，新配方默认和重置均显示全 0。实际发送为本次原生值加偏移，并限制在原厂范围。偏移为 0 时保留上游原生消息，不把八个显示零直接当作八个原生零。原厂外观继续使用原厂参数逻辑。

微调仍按配方色彩 SHA-256 独立保存；同配方改名、换槽或重新导入保留，新配方从 0 开始，不修改 R5NATIVE.BIN。旧 R5TUNE1 按“保存绝对值减旧初始值”转换偏移，成功提交后写为 R5TUNE2。旧固件不能直接读取 R5TUNE2，降级前需处理微调兼容并保留旧记录备份。

随包提供十二款正式配方 R5NATIVE.BIN，24 个槽位中未导入的槽位不可选；未提供另外十二款合成测试配方。原有 FL2／FL3、NTSC 提示处理、电子快门声音和照片 2.35:1 构图标记保留。使用既有研究签名公钥，原厂更新器保持原字节，离线封装校验见 verification.json。

本包绑定当前相对偏移 AP 的 31 项相关 CPU 回归、独立四组件重建，以及上游四种状态下十二款共 48 次 E4／432 条消息的逐字节比对。回归证据复用同一源码与组件身份的已完成结果；不宣称重新执行 CPU 回归，也不引用旧 AP 的 QEMU 截图证明本包界面。封装层回归、完整逐帧验证、独立解包、四组件回读及 OpenSSL 验签在本次构建中执行。

本轮全程离线，没有连接相机、写卡或运行 QEMU。版本号仍为 4.17，内容与此前 4.17 不同，应按 verification.json 中的 SHA-256 区分。已装相同 4.17 版本的机身能否接受同版更新尚未核验，本包不修改版本准入策略。机身信任、安装准入、LCD／EVF／JPG 像素和实际介质耐久性尚未在本轮验收。

实机复验时，先应用一款原厂滤镜，再切到自定义组并成功应用一款非首项滤镜。左键往返后，检查两边是否恢复各自那一款。等最后一款自定义滤镜应用成功后直接退出菜单，再重启相机，检查当前选择是否恢复。
