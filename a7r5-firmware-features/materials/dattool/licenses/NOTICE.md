# 来源与范围

本工具定向冻结并整理了当前工程已有的 DAT 容器解析、批量加密、FAT12 和 ext2 定向替换辅助。本次附带文件的摘要见交付根目录 `SHA256SUMS`；既有研究脚本许可证保留在 `reference-LICENSE`。

原参考项目为 `Hearts-Ace/sony-a7r5-custom-firmware`；本工具没有下载或重新声称该项目当前状态。格式常量由本地已有解析器提取，不包含索尼签名私钥。Python 依赖沿用各自许可证，安装后可在对应发行包元数据内查看。

本次四项功能材料只附配对公钥，不附研究签名私钥。完成签名必须另行提供匹配的私钥；本材料不是完整签名身份的公开交付。工具不附带原厂或研究版固件二进制。
