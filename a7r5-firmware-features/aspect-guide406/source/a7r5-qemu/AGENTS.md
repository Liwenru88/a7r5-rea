# 项目边界

- 本项目仅用于 macOS 原生 QEMU 模拟。不得连接或操作相机、USB 存储、SD 卡或原始分区镜像；需要改变此边界时先向用户说明并取得授权。
- 开发命令在本项目目录执行，Python 使用 `.venv/bin/python`；自包含应用包可从任意工作目录启动。不得依赖旧研究工程的 Python 环境、绝对路径或容器。
- 运行输入由 `runtime/manifest.json` 固定。摘要不符必须停止，不得绕过校验或退化为无沙箱启动。
- 构建使用本机工具和 `source/`、`sdk/` 内的材料；不要引入 Docker 后端。源码变更应记录来源、摘要与对应构建收据。
- 菜单画面必须来自原厂应用的真实客体快照。不得用预制 PNG、网页绘制菜单或硬编码像素替代验收。
- 菜单改动验证真实 Qt 按键、原始帧与 PNG 一致性、顶层 MENU 反复开关及工作进程/QMP 正常退出；网页回退验证 HTTP 契约与一帧退出冒烟。固定输入、沙箱或构建改动还需运行相应失败路径测试。
- 只修改模拟环境和模拟库；重建客体时必须核对其他归档条目未变。原厂内核、应用与库的适配更改须单独说明，不能隐去。
- `evidence/history/` 是历史证据，保留其中原路径和原结果文字，不将旧结论当作本次验收结果。最新结果写入 `logs/` 和对应 `runs/`。
- 取景视频、拍摄、录像和完整 CP/电源管理尚未实现；不得将菜单验收表述为整机硬件仿真完成或证明相机回刷安全。

- 桌面代码使用 PySide6；只有 macOS arm64 后端已验收。未知实体输入保持禁用，C4 仅开放已验证的菜单帮助、首次设置中“在相机上设置”及拍摄信息页的触摸操作开关；开关不代表触摸坐标/手势实现。Fn、DISP、C1/C2/C3、模式拨盘、空介质回放须有原厂首次设置完成状态，不直接写接受字段。不要把事件送达、空卡提示或信息布局表述为完整硬件功能成功。
- 拨轮只发送固定的一格，摇杆只开放已验证的菜单五向；原厂输入处理完成回执之后才采集新帧。模式选择须等到真实模式标志匹配；未知显示布局禁用模式选择。镜头限制提示不等于实际对焦成功。
- 应用包不依赖开发 `.venv` 或 Homebrew；冻结 worker 必须使用包内明确的 `A7R5Emulator` 入口，不使用 Nuitka 的 `sys.executable` Python 占位路径。
