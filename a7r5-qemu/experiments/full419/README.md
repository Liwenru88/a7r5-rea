# 4.19 全功能客体复验

从最终 DAT 和独立解包结果派生客体，不改包内 AP／CP 字节。入口、依赖与复现命令见[固件实施记录](../../../a7r5-firmware-features/specs/4.19-full-integration/实施与复验.md)。

`build_guest.py` 锁定最终包、十个模块和声音变体；替换全部文字资源、图标、MPR 与随包配方。`environment.py` 在启动前核对构建锁、组件和模拟器材料。`interactive.py` 逐步驱动真实 Qt 按钮，`run_validation.py` 覆盖声音保存与新客体无卡恢复。`serial_store.py` 校验异步串口导出的完整性。

初始自动模式限制创意外观是正常行为。`MODE_M` 通过现有模式事件切换，并会退出菜单，需要再按 MENU。不要为进入菜单解除生产模式保护。

原生 E4 的 `0x2040` 通知在当前模拟环境中仍缺失。滤镜列表、中文、参数页、画幅与声音菜单可截图，滤镜成功应用及参数提交以 CPU 指令回归为证据。声音使用明确音频服务替身；不证明真实出声、ISP 成片、eMMC 断电或机身启动。本实验不连接相机。
