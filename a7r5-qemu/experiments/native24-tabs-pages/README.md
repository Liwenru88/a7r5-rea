# 图标4KiB分块离线复验

固定与4.14相同的AP／CP、两份新分块图标及正式十二款BIN。复用实际Qt导航路线，覆盖十二款、原厂／自定义Tab、只浏览不应用、右键八项调参、重置及四轮MENU。

新观察器显式调用`sony_lz77_decode_pages`：每个压缩块输出最多4096字节，非末块必须为4096，字典独立。该规则由原厂资源全集支持，用于阻断旧4.13／4.14超长块；它不是完整LDEC硬件仿真，也不能证明机身修复成功。E4初始化和成像限制保持。

从本项目目录执行，使用现有`.venv`和沙箱；固定摘要不符必须拒绝。运行输入见`build/native24-tabs-pages-20261104-01/manifest.json`，验证入口为`run_validation.py`，结束后使用`verify_receipt.py`核对实际CPIO组件、原帧／PNG、源码及Qt／AP／CP正常退出。本实验不得与其他AP虚拟器并发。
