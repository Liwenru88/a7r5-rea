# 虚拟介质与成像实施边界

目标顺序：原厂 Fsys 文件后端 → 原厂媒体状态及订阅 → 原厂照片回放 → 虚拟预览、成像。

本批只操作模拟器、新建的普通虚拟文件和测试图像。原始镜像、相机、SD 卡均不访问。现有交付应用和默认运行清单保留，候选通过后再接入桌面入口。

1. **M001 原厂 Fsys**：从固定客体中取链接库；构建独立 AArch64 测试。4 MiB FAT 卡只放测试标记。原厂库完成写入、刷新、关闭、卸载；另一进程挂载读回；QMP 导出后主机独立检查目录、内容、文件系统。所有原条目内容及元数据逐项不变。
2. **M002 媒体通知**：核对 A7R5 的 MediaRM、配置、查询、订阅 ABI 和插入/移除事件。只在真实接口边界建立虚拟状态，记录哪些来自原厂、哪些由模拟器提供。以应用查询及订阅收据、可重复插拔状态为准，不直接改 UI 的就绪字段。
3. **M003 照片回放**：给虚拟卡加入注明虚拟来源的 JPEG/DCIM 夹具。原厂扫描、解码和回放，验证上一张/下一张/退出，以及客体原始帧。不得把主机绘图当原厂回放。
4. **M004 预览成像**：先闭合 DMM/stream2 缓冲区格式、生命周期和通知，再注入已知图像；分别验证原厂消费者实际读取、画面更新、原厂写图输出。虚拟预览不等同 RAW 传感器、拍摄或录像成功，缺少证据则明确保留未完成。

失败条件：输入摘要不符、归档额外改动、原厂调用错误、传输/导出短读、内容或文件系统校验失败、原厂进程异常，立即结束本次实例并保存日志、QMP 退出收据。禁止自动切换成伪造界面。

回退：研究候选不修改默认 manifest；关闭本次 QEMU 即结束 RAM 状态，现有应用可继续使用。原厂库仅链接/调用，不修改其指令。

参考来源：a7c2-re `433737ae5a8a241ae86eb307a12bb6a2c33600c7` 的独立 Fsys 测试。参数、内存范围与服务编号仍须按 A7R5 验证，不沿用未经核对的偏移。
