# 按键与设置扩展（2026-10-20）

本轮只修改 macOS 原生模拟环境。控制注册表从 10 项有条件开放扩展为 19 项，36 项清单中另有 17 项仍未开放。这个数字统计逻辑控制，不把拨轮的两个方向或模式拨盘的五个位置分别算成已实现的机身功能。

## 新增可操作范围

| 控制 | 原厂界面结果 | 限制 |
| --- | --- | --- |
| 前拨轮 | 单格正反向切换菜单页，恢复原页 | 不开放拍摄曝光调整 |
| 后拨轮 L / R | 两个独立固件分配事件切页 | 返回时保留“页选择”焦点，控制轮或方向键恢复条目焦点；不证明实体电路来源 |
| 控制轮旋转 | 单格选择菜单行、改变固定选项，反向恢复 | 只开放验收过的菜单上下文 |
| 模式拨盘 | 自动、P、A、S、M 的原厂模式标志切换 | 必须完成首次设置，并显示已识别的拍摄信息布局；不证明曝光/成像链 |
| 摇杆五向 | 独立摇杆事件导航分类、条目、确认选项 | 不用六键别名冒充摇杆事件；未开放八向、保持和拍摄对焦点控制 |
| C1 | P 模式下白平衡“自动→日光→确认→重进读回→恢复自动” | 自动模式可能显示原厂不可用提示；不证明实际颜色处理 |
| C2 | P 模式下对焦区域“广域→区→确认→重进读回→恢复广域” | 不证明实际对焦 |
| C3 | 原厂对焦模式面板、上下选择、取消和镜头限制提示返回 | 部分确认被原厂镜头状态拒绝，未伪造成功 |
| C4 追加用途 | 拍摄信息页“触摸操作：关/开”往返 | 开关不等于触点、坐标或手势已经实现；菜单帮助和首次设置入口继续保留 |

原有 MENU、方向键、确认、Fn、五种 DISP 布局及空介质回放继续保留。回放仍只显示原厂无卡提示，尚不能显示测试照片。

## 使用步骤

1. 先关闭旧窗口，使用项目的 `启动A7R5原厂菜单.command` 启动新版独立客户端。脚本直接启动包内程序且忽略终端挂断信号，启动终端可以关闭；客户端仍须通过退出按钮正常关闭。旧应用保留作回退。
2. 初始 My Menu / Add Item 页面点击“首次设置（启用功能键）…”。阅读原厂说明并确认；Creators’ App 页面选择 C4“在相机上设置”，通过区域、日期与后续原厂页面。
3. 首次设置完成后按 MENU 返回菜单，再按 MENU 进入拍摄信息页。设置和接受状态仅保存在本次客体 RAM，下次启动需要重新完成。
4. 菜单页可在“全部机身控制”页操作四组拨轮和摇杆。后拨轮切页后若条目没有橙色填充，这是原厂页选择焦点；控制轮转动后恢复条目选择。
5. 拍摄信息页可选择虚拟模式 P，再按 C1 调整白平衡、C2 调整对焦区域。用上下选择、确认应用，再按相同自定义键读回；MENU 取消面板。
6. C3 部分选项会显示“Invalid with this lens”。确认关闭提示，再按 MENU 返回。C4 可切换触摸操作开关，画面会显示原厂短暂提示；触摸输入本身仍不可用。
7. 模式选择灰色时，先退出 Fn/弹层或菜单；必要时按 DISP 循环回带模式标志的拍摄信息布局。未知布局不发送模式事件。
8. 使用“退出本次模拟器”，等待 worker 与本实例 QMP 正常退出回执。任何协议、传输或固件异常停止本次会话，不自动重发按键。

## 实现依据

`controls-map-20261020.json` 交叉核对原厂名称表、正反向键表和 Backup 输入配置。键表按原始代码排序，有保留项，不能把 UI ID 当作数组下标。首次静态候选因该检查失败而停止，随后按记录身份查找，未放宽一致性门槛。

四组拨轮分别使用 `0x1000001c / 0x10000013 / 0x10000016 / 0x1000001d`，原厂转换函数的一格单位分别为 `30 / 1024 / 30 / 24`。公开接口只接受 `-1` 或 `1`，不接收任意增量。摇杆使用 `0x70f7`，五向固定位置 `1 / 2 / 4 / 8 / 16` 后成对回到 `0`。模式拨盘 `0x7025` 的自动/P/S/A/M 固定位置为 `2 / 3 / 4 / 5 / 6`，顺序由原厂画面确认。

新增轻量完成回执只包装已核对指纹的原厂 `appFw+0x1ec7704` 输入处理函数，原函数照常调用，参数与返回值保持。函数返回后读取当前快照头的序号，宿主等待精确的完成回执与该序号之后的新帧；“发出事件”“消费端收到”“原厂处理返回”“显示新帧”不再混为一个阶段。正式客户端不开详细输入跟踪。

模式切换另等待真实模式标志区域匹配，期间只采集新帧，不重发模式事件。未知标志不当成成功。关闭提示框时，拍摄页稳定签名只排除顶部闪烁区，以及已经定位的 C4 固定提示框 `(71,365)-(569,419)`，包括其透明通道；不是只排除可见文字。完整快照的长度、身份、序列、FNV、SHA 与 PNG 逐像素校验均保留。真实 Off/On 与干净拍摄页的像素已压缩为 40 KiB 回归夹具，避免假数据遗漏透明通道问题。

客体从 `menu-daf0f137f7a3230d.cpio` 更新为 `menu-a95b001d61b77b98.cpio`，1226 项中只改变 `simulation/menu-observe-a7r5-baseline.so`，其他条目内容与元数据相同。原厂应用、库、资源和内核文件未改；观察库在模拟器内存中安装透明输入完成钩子，不能表述为完全没有运行时适配。虚拟介质研究候选没有并入默认客体。

## 仍未实现

快门两段与实际拍照、录像/编码、AF-ON/AEL 完整保持语义、传感器预览、照片解码与浏览、真实镜头和光学机械控制仍未完成。模式拨盘、白平衡与对焦区域的界面闭环不能替代这些链路。

当前媒体研究停在通知模式开启后的参数通知契约，原厂应用媒体挂载和测试照片回放没有成功证据，详见 `../003-virtual-media-and-imaging/notification-mode-analysis.md`。本轮没有通过假成功回执、预制照片画面或直接写原厂接受字段绕过缺口。
