# 恢复 A7R5 普通 USB

Mac 终端运行，或在 Finder 双击 `restore-usb.command`：

```sh
./scripts/restore-usb.command
```

如提示 Password，在终端输入 Mac 管理员密码。不要在任务或传输进行时运行；退出服务模式可能中断任务，并使尚未取回的结果无法继续读取。

只查看状态，不提权、不发送相机协议请求：

```sh
./scripts/restore-usb.command --check
```

脚本每次自动识别当前唯一 Sony 设备及物理端口，无需指定历史会话、端口或分区容量。同一次恢复期间不要换端口或拔线。0336 服务身份和已适配接口匹配后，只发送一次 STOP；普通 USB（0e0a）和过渡身份（096f）仅观察，不发送 STOP。没有设备、多设备、未知身份、接口不符、端口变化或已知设备任务持锁时停止。

STOP 返回 Pipe error 等错误也不补发；之后最多观察45秒，连续两次确认同端口的 ILCE-7RM5 普通 USB、存储驱动和当前媒体列表稳定，才记为恢复。日志保留原始错误。没有存储卡时可确认 USB 身份和驱动，但会明确提示未检测到媒体；没有操作前基线，因此不声称恢复了原来的全部卡、卷或拍摄功能。

脚本不认证、不 START、不上传、不修改预加载、不触发 libJit、不清理相机文件，也不停止 SSH 服务。它不会解析或消除失败任务的未完成状态；服务态名称不足以确认机型，接口检查只覆盖本项目已适配的0336形态，所以仅用于你明确知道连接的是 A7R5、且当前任务已停止的场景。

日志保存在工程 `.local/usb-recovery-<UTC时间>-<随机号>/`。返回码0表示只读检查完成，或执行时普通 USB 恢复已确认；2表示参数/环境错误，3表示恢复未确认或被拒绝。STOP报错后若主机恢复通过，返回0并保留错误字段，不能把它解读成STOP正常返回。

依赖本工程 `.venv`、自带 PyUSB 和本机 libusb，不自动安装依赖。可通过 `A7R5_PYTHON` 指定解释器，通过 `A7R5_LIBUSB` 指定本机 libusb dylib；通过 sudo 运行时如需自定义后者，请在管理员环境中显式设置。脚本不依赖 LLVM、目标固件分区镜像或工作区文件。

本次只完成离线测试，未执行实机恢复。
