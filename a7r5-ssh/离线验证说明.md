# 离线验证与证据范围

最终机器可读结果为 `verification/summary.json`。失败日志不删除、不覆盖，也不算作通过。

## 验证分层

1. 普通文件/主机进程：配置注入、监听范围、材料篡改、无批准拒绝、触发argv、精确预加载、超时、输出上限、子进程回收和外部进程不受影响。
2. 实际协议解析器＋内存驱动：原始响应头、固定读写、载荷回读、旧会话、非root、输出长度、中和及重复状态、不重发DEBUG、通道失败后停止。
3. AArch64：真实交叉构建、ELF机器类型、动态依赖与GLIBC版本上界、符号解析检查。
4. QEMU：原厂 sshd 配置解析，客体内回环 SSH，主机公钥匹配、认证结果、固定身份命令与有限寿命停止。此处使用虚拟账户夹具，结果不能替代实机账户审查。

## 隔离方式

QEMU 使用现有固定内核/归档/设备树和原沙箱，`-nic none` 不变，不增加主机共享目录、USB、物理盘或网络监听。测试程序通过小段八进制 printf 送入客体RAM。SSH协议经既有串口转交本机内存中的测试客户端，TCP连接只存在于客体 `127.0.0.1:2222`。

测试只在RAM建立账户与配置夹具，未修改固件归档或相机账户。测试私钥不写入客体或材料包；客体主机公钥由串口取得后匹配，不设置“忽略指纹”。源码、包、运行输入摘要在验收时重新核对。

## 已发现并处理的兼容问题

- 固件 BusyBox 缺少 base64、awk、id、df、sha256sum；不以通用Linux工具全集作为前提。固定脚本改用 shell 内建、原厂 openssl、ifconfig 与小型 statvfs 查询。
- 串口长命令可能被截断；测试传输改为短行 printf，并逐条等待完成回执。失败会停止本次VM，不在失步串口继续发送命令。
- macOS `/var` 临时目录可能经过链接；测试夹具先选取真实路径，生产路径保护保持拒绝链接。
- `ld.lld` 是按调用名选驱动的链接；命令保留 `ld.lld` 名称，不以解析后的 `lld` 文件名调用。
- 目标服务实测拒绝在其他用户可写的父目录中读取授权密钥；保留 `StrictModes yes`，测试使用明确权限的RAM夹具，实机候选只检查、不修改原父目录权限。
- 串口字节适配器不能以本机socket关闭模拟TCP FIN；测试改为先发SSH协议断开，再等待串口归还。未归还时禁止继续发shell诊断，直接通过QMP结束本次VM。

## 不应由本轮推出的结论

- 不能证明相机当前账户、挂载、空间、IP或SSH进程现状。
- 不能证明服务USB会话与实机Wi-Fi共存、正常拍摄、休眠唤醒或模式切换后可用。
- 不提供实机SSH部署成功、持久账户恢复、SFTP、任意root shell或损坏固件救援保证。
- QMP正常退出只说明本次模拟器回收，不说明相机正常关机或固件恢复。
