# 快速开启 A7R5 SSH

在工程根目录执行。默认采用已验证的 libJit 方案：原始挂载视图、正常终端和默认 SCP/SFTP，监听 `0.0.0.0:2222`，不限时、手动启动、没有开机自启。不写预加载、不 DEBUG、不修改原厂账户、不操作 SD 卡。

## 常用命令

```sh
# 仅查看本机记录和可信登录命令，不连接相机或探测网络。
./a7r5-ssh/quick-ssh.sh --ip 10.10.10.177

# 查看启动计划，仍不连接相机。
./a7r5-ssh/quick-ssh.sh start

# 实际启动：自动准备新包，依次载入和启动。
./a7r5-ssh/quick-ssh.sh start --execute --ip 10.10.10.177
```

也可双击同目录的 `快速开启SSH.command`。它进入实际启动流程，仍要求在终端批准，不会在打开窗口时立即写相机。

`--ip` 只用于打印登录命令，不修改相机网络或自动连接。以机身当前网络信息为准；不传时输出 `CAMERA_IPV4` 占位符，手动替换后才能使用。SSH 密码沿用本机受限口令文件，脚本不接受明文口令参数、不把明文复制进包或日志。

## 执行过程

1. 先检查本机活动、待恢复记录和共享锁。存在记录时立即停止，不把连接超时当作服务已退出。
2. 本机构建新会话包，或验证用户用 `--package` 指定的新包。显示固定写入范围及本次会话，输入 `START-本次会话前8位` 批准一次载入与启动。此步之前没有相机请求。
3. 在系统终端的 sudo 提示中输入 Mac 密码。不要将密码发到聊天，也不要把脚本整体用 sudo 启动。
4. 原工具执行一次 `load-once`：上传三个随机前缀程序、回读校验、条件满足后一次 USB STOP，核对 USB 和媒体恢复。
5. 查看屏幕，正常输入 `NORMAL`，才会记录本地屏幕回执并进入下一阶段。
6. 执行一次 `start-once`：检查材料和精确 512 换行基线，上传票据及 `/tmp/jiritsu/libJit.so`，启动监督器，核对 root、原始视图证明、RAM 主机公钥和心跳；满足条件后一次 USB STOP，核对恢复。
7. 再次查看屏幕并输入 `NORMAL`。输出绑定本次可信公钥的 SSH 命令；复制到终端登录即可。

相机应稳定独立供电、以海量存储连接原 USB 端口，固件和媒体符合原包固定基线。过程中不拔插、不移动卡、不重启。固定 `/tmp/jiritsu/libJit.so` 仍存在潜在覆盖、持久残留和恢复受限风险；快捷入口没有消除这些风险。

快捷入口只串联已经验证的 USB 载入/启动操作器，不自动认证 SSH、测试终端或传文件。输出启动成功代表 READY、USB/媒体和人工屏幕门槛通过，网络登录仍需使用打印的命令验证。

## 先离线封包

```sh
./a7r5-ssh/quick-ssh.sh prepare
# 将输出的绝对目录传给实际启动命令。
./a7r5-ssh/quick-ssh.sh start --execute --package '/输出的新包目录' --ip 10.10.10.177
```

每个包仅载入一次、启动一次；已有阶段尝试记录的包不能重跑。取消批准只保留本机新包，不会连接相机。没有 `--force`、自动重试或自动删除记录选项。新包构建需要工程现有 `.venv`、LLVM/LLD、OpenSSL 和 libusb；缺少依赖时在设备操作前停止，不自动安装。

## 当前已有服务记录怎么办

本机当前保留会话 `f3d50ff871064c3d8cd67d332062357e` 的活动记录。运行快捷启动会拒绝重复启动；查看状态可以取得该会话的可信登录命令。本机记录不证明当前监听仍存在。

需要结束服务时，先退出用户终端和传输，再按状态输出所指原包的 `实机执行与恢复清单.md`，审阅并执行一次 `stop-once.command` 和屏幕确认。本快捷工具不自动停服，也不替用户执行恢复。

即使相机已经重启，也不自动清空旧活动记录或假设旧 RAM 回执仍存在；应先核对旧会话收口/恢复状态，再另行解除准确匹配的本机门槛。不要手动删锁来强行重跑。若流程在屏幕确认前中断，原工具保留待确认记录；只在已核实对应成功结果且屏幕正常时，按原包清单完成该阶段确认，不重新执行 USB 阶段。

## 日志与停止条件

- 会话包：`a7r5-ssh/libjit-ssh-on-demand/packages/quick-*`。
- 快捷调度：`a7r5-ssh/libjit-ssh-on-demand/quick-runs/会话号/`，包括批准、子程序日志、计时及结果。
- 原始 USB 证据：本包 `.state/load-once/`、`.state/start-once/`。

任一批准、传输、回读、协议、READY、恢复或屏幕门槛失败，立即停止；保留包、锁、日志及待恢复状态。不换端点、不重试、不重发 libJit、不自动 STOP、不自动断电。屏幕异常时保持供电和连接，按原会话证据准备受限恢复方案。正常路径中每阶段的一次 USB STOP 仍由原操作器按门槛执行。

退出 Mac 终端不会停止不限时服务；本工具不自动清理机内材料，也不保证无限期稳定性。关机/重启不属于本工具执行步骤。

## 离线回归

```sh
.venv/bin/python -B -m pytest -q a7r5-ssh/quick-tests a7r5-ssh/libjit-ssh-on-demand/tests
/bin/zsh -n a7r5-ssh/quick-ssh.sh
/bin/zsh -n a7r5-ssh/快速开启SSH.command
```

快捷调度的离线测试覆盖默认无设备请求、活动/恢复门槛、并发锁、取消、阶段失败即停止、异常屏幕、回执绑定、旧包拒绝和公钥固定。它们不替代新快捷入口的实机验收；底层 libJit 原始视图终端及双向 SCP 已有独立实机记录。
