# A7R5 网络进程触发自启：待实机批准

## 目标和当前证据

本包通过已存在的SSH安装一个新的自启候选，主触发仅为`/usr/bin/wpa_supplicant`；不再依赖早期bootin进程重新加载。继续使用原厂sshd、既有私有RAM账户、0600运行时密钥副本、正常PTY、internal-sftp及无超时后台服务。

此前只读实机证据显示WARMBOOT、镜像恢复；bootin没有自启库映射，而wpa_supplicant及dhcpcd均以root运行且映射现有库。网络入口的选择据此提出，不等于已验证开机自启。

本轮仅离线实现、测试和封包。不连接相机，不创建执行批准，不打开安装Terminal，不写相机或SD卡，不修改原始镜像，不重启相机。旧包、旧锁及失败证据保留。

## 最小变更

新候选使用独立`/etc/a7r5-netstart-<本包ID>`目录，包含：

| 文件 | 用途 |
|---|---|
| network.so | 仅匹配root、系统父挂载视图和精确wpa_supplicant路径的触发库 |
| control.static | 不依赖动态加载器的安装、只读检查、回滚和中和工具 |
| enabled | 本包ID加换行的启用标记 |
| preload.previous | 精确保存原有旧预加载指针 |

仅把`/etc/ld.so.preload`从已知旧boot.so指针原子切换为新network.so指针。原`/etc/a7r5-autostart-8e94bdaf0bd44e5c82c801ad74a34929`整个目录、启用标记、主机密钥及启动器都不修改，新候选复用其中已验证的启动器；**不要删除这个旧设备目录**。

RAM中新增固定暂存目录及本包claim目录。安装时先写`claim/suppressed-active-service`，再启用新指针，所以当前开机不启动第二个实例、不停止原服务。本包不读取或复制私钥、不修改原厂账户、NSS或sshd_config；新启动器仍只在私有RAM视图改变账户。

## 触发与拒绝条件

只有新执行的wpa_supplicant，其argv[0]与exe均精确匹配、UID/EUID为0、挂载命名空间与PID1相同，且enabled内容/所有者/权限正确，才可能派生worker。调用程序不等待worker，也不依赖Wi-Fi已经取得指定IP。

worker只接受已就绪的/tmp_network tmpfs及已知权限，不等待挂载，不轮询重试。它以原子mkdir取得本包claim后，核对：

1. 旧服务RAM目录确实不存在；健康实例、空目录、陈旧PID、失败结果、符号链接或无法确认的错误都拒绝，不删除旧现场。
2. IPv4 TCP表可完整解析，2222没有监听者；外部抢占端口仍由启动器bind失败保护，不接管监听。
3. 旧启动器是root所有、不可被组/其他用户写入、可执行且长度和SHA-256匹配的普通文件；从验证过的文件描述符execveat执行。
4. 执行前再次核对启用标记、命名空间和RAM目录。

claim即使失败也不清除；并发、Wi-Fi重连或重复执行不会再次启动。PID复用不通过杀进程解决：只要旧RAM证据存在就拒绝启动。RAM门槛未就绪或fork尚未成功时还没有claim，未来另一次网络程序执行可能重新检查；这不是后台循环重试，不能宣称所有早期失败都已被全局记录。

worker只重置自己的SIGCHLD，避免继承网络宿主的忽略策略影响启动器waitpid。原网络进程的信号策略不修改。一次成功派生若宿主不回收子进程，仍可能留下短命worker的僵尸记录，机身实际回收行为未验证。

## 一次性安装清单

执行前确认相机地址仍为10.10.10.177、2222原SSH可用，屏幕、Wi-Fi及独立供电正常。本次安装不用USB协议，不需要换USB状态或操作卡。

1. 本机核对封印、依赖、独立批准与一次性锁；精确主机密钥校验，不采用信任首次连接或连接池自动重试。
2. SSH只读预检：root、已知私有挂载栈、精确当前READY、公钥、前进心跳、原预加载指针及PID1视图中的账户/NSS/配置摘要。当前实例发生变化即停止，不沿用旧PID强行安装。
3. 创建一个新的RAM暂存目录，分别上传network.so和control.static；回读控制器摘要后才执行静态安装。控制器再核对旧材料、暂存来源、当前实例及空间。
4. 新建独立持久目录，写回滚指针和静态工具，预占本次开机claim，写enabled及临时预加载文件，核对后rename+syncfs提交。同步失败即报告失败，不能把rename后的错误谎称为已回滚。
5. 用一次SSH固定读取确认新指针、旧READY及新enabled；不调用--launch，不做网络重连，不重启。最多6次SSH/SCP连接、2个载荷上传，无USB认证/START、DEBUG或STOP。
6. 保存原始输出、摘要和安装回执，再核对屏幕。只有本阶段通过后，另行确认实际开关机/WARMBOOT/静态IP/网络重连验收。

安装中任何异常立即停止，不自动重试、回滚、清理或断电。固定目录、claim、锁和临时文件可能残留。再次安装必须分析现场后制作新包，不能删锁重跑。

## 禁用、回滚与恢复

各入口均要求自身的独立批准和一次性锁，本轮只生成未批准模板。

- **回滚旧入口**：`control.static rollback`。验证旧库、旧启动器及标记仍完好后，禁用新标记并原子恢复旧预加载指针。保留现有SSH。旧入口的热恢复问题仍然存在；回滚不是修复旧自启。
- **中和全部已知预加载**：`control.static neutralize`。仅接受新指针、已知旧指针或精确512换行，原子恢复512个换行。即使新库、旧helper或新目录损坏也不依赖它们执行。对未知第三方指针拒绝覆盖；不停止已运行的SSH。
- **SSH登录还能建立**：使用包内对应恢复入口；执行前校验部署的静态控制器摘要，一次调用，不自动重试。
- **新SSH登录失败但已有root终端仍可用**：可在该终端使用shell内建`exec`直接执行已验证的`/etc/a7r5-netstart-<本包ID>/control.static neutralize`，不先运行外部cat/chmod等动态命令。具体固定命令见包内恢复清单，动作仍需单独确认。执行器退出会关闭该终端。
- **已有终端也不可用**：本包不承诺可独立救回。保持现场，不删除库、不擅自断电；结合当前USB身份另行准备已批准的受限恢复。静态ELF能独立运行不代表存在一个必然能取得root并交付它的通道。

禁用可以阻止尚未通过最终门槛的worker，不能承诺取消已经越过最终门槛并开始exec的启动，也不主动杀掉它。损坏目录时中和只能恢复全局指针；已映射在旧进程中的库不会因此被卸载，后续再次加载的风险与恢复范围必须区别。

## 风险与尚未验证项

- 全局preload仍会让每个动态程序先尝试加载新库；严格触发条件不能消除库损坏、ABI变化或挂载时序问题的影响，存在启动和恢复受限风险。
- 固定root密码、通配监听和无超时后台运行继续保留；私有挂载视图不是强安全沙箱。
- 本候选依赖Wi-Fi station路径实际新执行wpa_supplicant。Wi-Fi关闭、AP/其他联网模式或仅恢复既有网络进程时不保证触发。此包不增加dhcpcd第二入口，避免同时扩展范围。
- 若恢复镜像保留了旧claim或服务RAM残留，候选会拒绝，不自动重置快照或修改ssboot控制节点。
- 原厂网络管理器按进程名停止sshd的潜在冲突、休眠耗电、关机清理、实机僵尸回收、冷启动和真实WARMBOOT均待单独验收。

## 离线验证的含义

本机C测试覆盖并发、权限、残留/PID复用、端口占用、被禁用、文件损坏、存储和恢复失败；假传输测试验证全部SSH失败阶段停止且不重试、批准/锁、凭据脱敏及当前实例校验。

断网QEMU使用相同核心C源码和独立RAM夹具，实际执行AArch64触发器及静态工具，复现旧bootin条件漏掉网络程序，验证新入口、重复拒绝、陈旧RAM拒绝和损坏后静态中和；精确生产ELF仅测试安全的非目标加载/inspect拒绝。没有运行真正wpa_supplicant或sshd，没有真实重启/休眠；重建夹具RAM代表生命周期场景，不等同于机身恢复内核验收。

所有实机安装、原厂Wi-Fi重连、相机关开机和恢复动作，均待用户另行确认。
