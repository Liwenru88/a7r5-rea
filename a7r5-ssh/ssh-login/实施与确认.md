# A7R5 限时 SSH：Mac 密钥登录实机方案

日期：2026-10-20。对象：ILCE-7RM5 / 4.00。**仅离线准备，等待实机确认；本轮没有查询或连接相机。**

## 本次目标和材料

上次已证明真实相机能启动 `0.0.0.0:2222`，随后回收并恢复普通 USB；没有证明 Mac 到相机可达或能登录。本次沿用已验证私有挂载命名空间，增加 Mac 一次指定密钥登录和固定只读命令验收。

- 包：[login-600s-20261020-01](packages/login-600s-20261020-01/)。会话：`1c7c3975a4b74153b26c32d5a2a18ecf`。
- [第一阶段入口](packages/login-600s-20261020-01/run-deploy.command)：固定部署、启动、条件 STOP、主机恢复、一次 SSH 登录。
- [第二阶段入口](packages/login-600s-20261020-01/run-collect.command)：等待清理后另行确认，仅 USB 固定结果回读和条件 STOP。
- 源码、载荷、客户端私钥、依赖摘要、两个未接受的批准模板均在新材料下。旧包和旧尝试锁保留，不复用、不删锁。

| 项目 | 固定范围 |
|---|---|
| 监听 | `0.0.0.0:2222`，仅 IPv4，不等待固定 LAN IP |
| 相机寿命 | 从 sshd 启动起最多 **600 秒（10 分钟）** 后进入清理；TERM/KILL/wait 最多约 6 秒，外层另有监督预算 |
| Mac 目标 | **仅 `10.10.10.117:2222`**，TCP 一次，不先探测 22/2222，不扫描、ping、DNS 或换地址 |
| 客户端 | 仅本包 Ed25519 密钥；不读取用户 SSH 配置，不用密码、agent 或其他密钥；不建立复用连接 |
| 主机身份 | USB 固定回读本次 RAM 主机公钥，核对 nonce 绑定的摘要；网络握手公钥原字节匹配后才提交客户端凭据 |
| 固定命令 | 服务端 `ForceCommand /bin/busybox cat /proc/self/status`；客户端只请求同一条命令 |
| 验收 | 命令退出码 0；唯一 Uid 行和唯一 Gid 行各四项均为 0；保存原始 stdout/stderr |
| 网络上限 | 从建连起总预算 30 秒，单项最多 8 秒；关闭连接的独立计时器；stdout 最多 4096 字节、stderr 最多 1024 字节且必须为空 |
| 禁止范围 | 无 PTY、任意交互 shell、SFTP、端口/agent/X11 转发、用户 rc、用户环境、密码、PAM；不改 Wi-Fi/路由/防火墙 |
| 最终清理 | 第一阶段报告产生后至少 610 秒再允许第二阶段，并要求该阶段独立批准和先前屏幕正常确认 |

600 秒为运行时配置上限，不是保证所有情况下都能存活满 600 秒；原厂进程干预、休眠或网络状态仍可能使其提前退出。主动连接结束不会提前取消相机端计时。私有视图只隔离挂载与账户副本，保留原网络命名空间以使用相机 Wi-Fi。

## 执行前检查（获批后进行）

1. 相机稳定电池或独立供电，屏幕正常，无初始化/格式化/修复提示；Mac 接电且保持唤醒。相机、USB、卡均不变动，不重启。
2. 人工确认相机正常菜单仍显示 `10.10.10.117`、掩码 `255.255.255.0`，Wi-Fi 已连路由器，Mac 有到该地址的网络路径。该地址来自此前机身界面，本轮未刷新；若地址已变，停止并离线重制绑定，不能现场扫描或改目标。
3. 包绑定已确认 USB 位置 `0x00100000`，普通身份 `054c:0e0a`。位置、型号、媒体或接口指纹不符即停止，不自动重新绑定。
4. 明确接受下述固定写入、通配暴露及残留风险后，生成仅绑定本包第一阶段的实际批准；两个模板当前均为 `accepted=false`。**本轮不生成实际批准、不打开实机 Terminal。**

## 第一阶段：启动、恢复 USB、Mac 一次登录

1. Terminal 在 sudo 前核对批准、源码/载荷/运行时摘要和未使用状态；密码只在本机输入。先创建一次性尝试锁，再查询主机并进入 USB 流程。
2. 核对普通 USB 和原驱动/媒体基线，正常卸载相机卷，认证/START。协议原始响应头、端点选择和操作状态按原引擎保存。
3. 核对固件版本；`/etc/ld.so.preload` 必须精确为 512 个换行，其他内容一律拒绝。上传并完整回读固定 helper 和 so，武装本次路径，仅一次 DEBUG。
4. helper 核对原 passwd、Sony NSS、原 SSH 配置和 RAM 条件。子挂载视图私有化，将 `/var` 覆盖为 4 MiB tmpfs；唯一 root 行 shell 只在 RAM 副本改为 `/bin/sh`，只读绑定给子视图；不写回原账户。
5. RAM 生成临时主机密钥、指定公钥和受限配置；现有 2222 监听必须为空。只启动一次原厂 sshd；核对通配监听、进程存活和相机回环标识后产生 READY。
6. USB 读回 DONE、READY、主机公钥、started/banner、推进心跳；复读状态并核对中和，保留 STOP/主机恢复时间。全部通过才尝试一次 STOP；Pipe error 按原样保存，不重发。
7. 仅观察主机 IORegistry，最长 45 秒；同端口已知 `096f` + `USB Bus-powered Device` 只视作等待中的过渡身份，不能当恢复成功。普通 `0e0a` 必须回到真实 `ILCE-7RM5` 型号，原驱动和原媒体连续两次匹配。
8. 仅在 USB 协议门槛、一次 STOP、主机恢复均通过且无会话错误后，Mac 才连接 `10.10.10.117:2222` **一次**。匹配本次主机公钥后指定密钥认证 root，执行固定只读命令；保存原始输出、退出码及 UID/GID 判断，随后关闭连接。
9. 最后仅请用户查看相机屏幕。报告分别记录 USB 启动、网络尝试、认证、root 命令、主机恢复与屏幕，不把部分通过合并成全成功。

即使端口能建立 TCP，仍可能握手/认证失败。任一网络失败立即关闭连接，不重连、不重发命令、不追加 USB 请求；相机限时监督继续运行，后续清理必须按下一阶段验证。

## 第二阶段：另行确认的只读回收

第一阶段结束并确认屏幕正常，等待报告中的 `collect_not_before_unix`（生成报告前计算的保守门槛，至少再等 610 秒）后，再单独批准一次 readback。

仅认证/START → 版本及精确中和 → 本会话父结果和子结果 → 重复父终态 → 中和。要求父视图原账户/NSS/配置/挂载未变、后代回收、子终态已见、监听消失；成功清理父子code0，或已知提前退出父87/子116或117且全部清理字段通过，才允许一次 STOP。提前退出即实验失败，不能标为正常运行完成。

之后仍按普通 USB/原驱动/原媒体连续两次核对，并请用户仅看屏幕。第二阶段不写相机文件、不 DEBUG、不连接 SSH。网络验收失败不阻止清理结果被单独回读，但 USB 恢复/状态不明需要另行准备受限恢复，不能盲进第二阶段。

## 停止和失败恢复

- 未知预加载、版本/主机身份/接口不符、协议失步、传输失败、状态不一致：立即停止，不换端点、不认证重试、不重发 DEBUG。
- DEBUG 前仅在通道完整并读到本次精确预加载条目时允许既有一次中和；失步或 DEBUG 之后不盲写恢复。
- STOP 最多一次；仍为已知服务/过渡身份只保存元数据，观察截止仍未恢复即停止。没有自动拔插、断电或重新运行。
- 网络错误或主机密钥不符：关闭唯一连接并记录失败，不扫描/换端口/换IP，不调整账户、网络或防火墙；等待限时清理并另行确认回收。
- 回收缺失、未知失败码、原件变化、监听未消失、子树未回收：不放行 STOP，保留现场，提出新的受限恢复方案再确认。
