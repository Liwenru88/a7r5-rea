# 来源与范围

本工具定向冻结并整理了当前工程已有的 DAT 容器解析、批量加密、FAT12 和 ext2 定向替换辅助。来源文件及摘要见根目录 `SOURCE_FILES.json`；既有研究脚本许可证保留在 `reference-LICENSE`。

原参考项目为 `Hearts-Ace/sony-a7r5-custom-firmware`；本工具没有下载或重新声称该项目当前状态。格式常量由本地已有解析器提取，不包含索尼签名私钥。Python 依赖沿用各自许可证，安装后可在对应发行包元数据内查看。

研究签名私钥和配对公钥属于本地签名身份，作为用户明确要求的私有交付材料附带，不应因本目录含脚本许可证而被当作可以公开分发的密钥。工具不附带原厂或研究版固件二进制。
