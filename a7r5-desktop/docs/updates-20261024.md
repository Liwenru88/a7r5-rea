## 最新43错误的定位与修复

此前一次获批的只读诊断测得可用内存 `52820 KiB`（约51.6MiB），低于旧固定64MiB门槛，导致写入前返回43。该诊断未打开或写入更新器分区；唯一STOP后，电脑及用户均确认MSC恢复。这是一次测量值，不能当作相机永久内存状态。

9块模式虽减少了导出文件，原资源准入仍按完整分区导出计算。本次修复为该模式独立设置：

| 项目 | 新9块强制模式 |
| --- | --- |
| 最低可用内存 | 32768KiB，即32MiB |
| tmpfs可用容量 | 大于8684544字节：132096扇区数据＋131072日志上限＋32768控制/输出预算＋8MiB余量 |
| 进程单文件大小限制 | 至少131072字节 |
| 资源策略 | `planned-sectors-32m-v1` |
| 载荷标记 | `A7R5_TRUST_FORCE_V3_RESOURCE_BUDGET` |

新策略拒绝错误内存单位、格式、重复字段及数值和容量乘积溢出；配置、载荷或终态要求值混用时停止。32MiB不是实机峰值测量得出的绝对安全下限，并发活动仍可能造成后续内存不足。

电脑只核对计划扇区，不再独立下载核验未写扇区；未写区域依赖机内完整摘要与重开校验。9块回读文件不等于完整备份。强制安装可能覆盖已有修改，未知前像兼容性没有保证，写入不是原子操作，没有自动回滚。

## 使用方式

1. 正常退出旧客户端，解压本批次 ZIP，从新目录打开 `A7R5 Studio.app`；不要通过删除任务、备份或锁文件切换版本。
2. 备份时可先选保存目录。未选择则保存到原任务目录；选择后新建独立备份文件夹，原记录保留。
3. 普通信任更新选择完整原厂备份的外层 `result.json`，或另存备份目录中的 `result.json`。强制模式是独立动作，请按确认提示判断覆盖风险。
4. 设备动作继续后，在自动打开的终端按 `Password` 提示输入 Mac 登录密码；输入时不显示字符。管理员密码与相机 SSH 密码不同。
5. 若任务失败，查看原始错误和具体阶段，保留连接与供电；“机内写入完成、电脑核验未完成”不能通过再次强制安装处理。历史记录不锁住按钮，也不表示重复写入安全。
