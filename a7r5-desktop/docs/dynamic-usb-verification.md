# 历史记录不阻塞与每次实时USB定位：离线验证

本次按用户要求取消历史待恢复标记和跨次端口绑定。仅修改客户端并做离线测试、构建和自检，不连接或枚举真实相机，不执行已有任务恢复，不清除任务记录或旧安装包。

## 当前行为

- 新设备任务不再读取、创建或清除全局`pending.json`。历史文件原样保留，界面不再显示阻塞横幅，也不因历史标记禁用按钮。
- 每次新任务、停止SSH和独立MSC检查均识别当前唯一A7R5，按本次位置、媒体和驱动建立连接基线。独立MSC检查把新基线另存为`recovery_baseline`，原任务基线及失败结论不变。
- 同一次正在执行的会话及同一次恢复检查仍绑定本次端口；中途位置变化时停止，不自动切换设备、重发认证或重复STOP。未知机型、未适配USB模式、错误前像及协议失步继续拒绝。
- 屏幕确认只补充本任务记录，不影响新任务启动。SSH成功启动后立即登记活动实例；成功停止后保留结束实例回执。确认旧任务不会删除后来启动的实例。停止SSH可以换端口，仍须核对原会话号及保存的主机公钥。
- 当前进程互斥、管理员设备锁和活动SSH冲突检查保留。新任务不会自动重试历史失败操作。

## 复现与回归

修复前，两个Python用例分别复现恢复检查绑定旧端口、停止SSH绑定启动端口；Rust用例复现历史待恢复文件阻止新任务；界面用例复现历史标记使横幅持续显示并禁用按钮。
