# 独立测试客户端范围

用户于2026-10-23确认实施：Mac Apple Silicon，Rust + Tauri主程序，随包携带所需引擎、运行库及现有研究签名身份；用户无需安装Python、Node、Homebrew或编译器，运行不依赖QEMU及开发工程。

- 备份和更新为独立入口。更新复用完整核验的备份，机内仍重新验证完整前像并完整回读。
- SSH的三个程序上传和一次libJit触发合为一个USB服务会话，全部回执通过后才允许一次STOP。
- 支持指定A7R5 4.00前像；点击功能后自动检查唯一设备、当前端口、接口、版本和加载库。界面无离线模式或检测按钮。
- SSH密码支持8至128个非控制字符，默认不保存明文。管理员密码只交由macOS系统授权窗口接收，取消授权不启动设备操作。
- 每次USB操作显示MSC指引。只有尚未开始或任务已安全完成，才允许提示重新拔插。执行中和状态未知时保留连接与失败记录。
- 原有四项固件功能分别选择，支持16种组合；封包保留验签与独立解密核对，输出旁附卡刷说明。说明区分官方4.00参考行为和自定义包未验证项。
- 成功退出后检查USB及媒体恢复，再人工确认屏幕。活动记录、失败现场和永久锁不自动删除；不自动重试、重启或恢复。
- 交付本地测试版，使用临时签名。Developer ID签名、公证和实机验收为正式发布门槛。研究私钥随包仅获本地测试授权，不公开上传。
- 本轮不连接相机、不枚举真实USB、不执行sudo或设备操作，不改变原模块和历史记录。
