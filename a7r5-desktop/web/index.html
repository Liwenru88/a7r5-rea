BEFORE YOU BEGIN

关键提示，放在操作发生之前。

01 · USB / MSC

开机、使用可靠数据线直连 Mac，在相机选择「海量存储器 / MSC」。未出现模式选项时，仅在尚未开始或任务已核实完成时重新拔插。

USB 执行中或结果未知时，不拔插、不切模式、不关机。备份和信任更新各自执行一次，SSH 上传和启动合并一次。

02 · 管理员授权

接管 USB 需要管理员权限。继续设备操作后，macOS 会显示系统授权窗口，请输入这台 Mac 的登录密码。

不要把 Mac 密码填到 SSH 密码框。取消系统授权不会启动设备操作；封装固件无需管理员密码。

03 · SD 卡升级

保存卡内数据，充足电量，移除电池手柄。将生成文件命名为 BODYDATA.DAT，放在 SD 卡根目录，插入 SLOT1。

进入 菜单 → 设置 → 设置选项 → 版本 → 软件更新，按机身提示执行。具体步骤以生成的说明为准。

04 · 黑屏与读写灯

索尼官方 4.00 参考：更新时屏幕黑屏，读写灯按 1、3、5 次分组闪烁，约 6 分钟后自动重启。时间不能单独证明成功。

5 慢 + 6 快、7 慢 + 7 快属于官方所述错误模式。自定义包尚未实机验证；异常时记录状态，不盲目拔电或重复卡刷。

此包为本地临时签名测试版，包含研究私钥。正式发布仍需 Developer ID 签名、公证与实机验收。不会自动连接相机或在启动时枚举设备。

操作前准备

请先在相机选择「MSC / 海量存储器」

连接 USB 并开机。未显示模式选项时，确认当前没有正在执行的任务，再重新拔插数据线。

继续后，macOS 会弹出管理员授权窗口，请输入这台 Mac 的登录密码。它不是相机 SSH 密码。取消授权不会启动设备操作。

执行中请保持供电和 USB 连接；结果不明时不要重试、拔插或关机。
