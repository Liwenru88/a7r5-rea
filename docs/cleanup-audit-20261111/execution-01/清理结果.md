## 归档内容与恢复边界

ZIP 按内容摘要保存所有非容器文件，包括源码快照、对象文件、AP／CP 二进制、资源、日志、回执和脚本。归档中的 `manifest.json` 保存原路径、权限、时间、文件摘要和对象位置；重复内容只保存一份 `objects/<sha256>`。

**36 份可再生 DAT／CPIO／大型 IMG／分区容器没有逐份备份其完整载荷**，其路径、长度、SHA-256 及来源元数据已保存。因而这个 ZIP 是证据和组件归档，不是可一键还原全部旧运行目录的完整备份。需要旧客体或旧包时，使用保留的原厂输入、种子、组件、脚本和记录重建，并核对容器摘要。小型 `.dat` 配置不作为固件容器跳过。

恢复非容器文件时，应在新的隔离目录读取 `manifest.json`，只从归档对应的 `objects/<sha256>` 提取数据并校验摘要，不覆盖当前源码和发布包。符号链接仅保存链接元数据，归档没有跟随工程外链接复制内容。

ZIP 被项目的 `*.zip` 规则忽略；备份该证据时需要同时带上 ZIP 和执行回执，不能只克隆 Git 仓库。证据仍保存在当前磁盘，未自动上传或写入外部设备。
