## 历史故障文件恢复

归档以 `objects/<SHA256>` 保存普通文件，原路径和文件权限在 `manifest.json` 中。恢复脚本默认只列出匹配项，提供 `--dest` 才提取；目标必须是不存在的新目录，不覆盖工程。

在工程根目录执行以下示例，可将 WBI 工作区恢复到新建的临时目录中：

```sh
.venv/bin/python -B docs/cleanup-audit-20261111/restore_deep_archive.py \
  --prefix a7r5-fastboot/private/cases/4.18-wbi-verify/workspace \
  --dest /tmp/r5-history-restore
```

输出保留完整的工程相对路径。恢复后逐项复核，再按具体历史脚本准备输入；脚本不会自动回填原目录或操作设备。历史 `private/migration.json` 保持原样，记录的是之前迁移时的状态。
