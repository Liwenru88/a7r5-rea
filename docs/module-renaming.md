# 顶层模块英文命名迁移

2026-10-23 经确认，统一顶层模块目录为小写英文、`a7r5-` 前缀和连字符分词。

| 原目录 | 当前目录 |
|---|---|
| `A7R5-四项功能实施/` | `a7r5-firmware-features/` |
| `A7R5-固件镜像/` | `a7r5-firmware-images/` |

其余八个模块名称已符合约定，继续保留。内部中文文档名和镜像分类目录未改名。

## 迁移内容

- 两个目录在同一文件系统内重命名，没有复制或改写固件原件，没有创建旧名软链接。
- 更新客户端材料构建、功能配方加载、分区测试、独立验证、静态分析和 QEMU 原件定位中的有效路径。
- 同步根目录 Git 忽略规则、发布检查、本地输入清单、测试和当前文档。
- 旧包、冻结依赖快照、历史来源和验收回执中的旧路径保留历史原文；它们不是当前运行入口。本地 `.local/` 中此前的清理清单也保留原路径。
- 当前研究签名身份未替换。最终 `.app` 和 ZIP 的内容、签名和来源记录不因开发目录改名而改写。

目录内共有 145 个常规文件参与迁移核对。只有当前功能说明中的有效路径文字需要更新，其他文件按清理前后 SHA-256 核对一致，固件原件内容不变。

## 验证

| 范围 | 结果 |
|---|---|
| 发布边界回归 | 6 项通过，当前研究私钥的精确例外继续有效 |
| 功能配方合成测试 | 9 项通过 |

| 新路径下的功能补丁重建 | 16 组均与迁移前回执一致，未改写原有 prepared 或最终包 |
| 客户端构建输入 | 新目录下的官方 DAT、分区前像、SDK、密钥和 SFTP 输入检查通过 |
| 发布候选扫描 | 通过；新固件目录仍排除，源代码中的当前入口已使用新名称 |

本次验证合计 36 项定向测试。QEMU 的既有 initrd / DTB 缺失问题仍按原输入门槛停止，没有用迁移放宽校验。

## 兼容性与回退

外部脚本若引用旧目录名，需要改成表中的当前名称。历史回执的路径仅用于追溯；不要为了继续使用旧批准而重写其封印或路径。

确需回退时，在停止相关本地任务、保护现有改动后反向重命名目录，并恢复对应源码、配置、忽略规则和文档引用。仅恢复目录名而不恢复引用会造成不一致。本次没有执行相机连接、USB 枚举、sudo 或 GitHub 上传。

详细迁移清单、改动文件和验证日志保存在本地忽略目录 `.local/module-renaming/`。
