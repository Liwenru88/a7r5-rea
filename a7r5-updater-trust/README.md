# A7R5更新器信任环境独立模块

> GitHub 源码发布说明：当前研究签名公私钥经授权随源码保留；完整固件、其他私钥、SDK 二进制、真实操作包和历史验证现场仅留本地；旧链接可能指向未入库材料。环境与输入要求以 [根目录构建说明](../docs/build-inputs.md) 为准，本轮验证见 [验证记录](../docs/verification.md)。

入口文档：[05_机内更新器信任环境修改与部署实施细节.md](05_机内更新器信任环境修改与部署实施细节.md)。

本模块与前四项功能材料分开存放。`trust_tool.py`提供纯离线inspect、build和classify；新增`deploy/`提供可独立运行的libJit专用部署工具。默认只prepare/check，实机必须另行取得本次批准、macOS管理员权限及显式设备开关。固定原像、258扇区、全量回读和异常停止均保留；不自动换节点、重试或放宽摘要。

部署入口与完整步骤：[deploy/运行与实机确认清单.md](deploy/运行与实机确认清单.md)。本轮39项检查、两项AArch64 QEMU及独立复制验证通过，**没有连接相机或创建实机批准**。历史profile模板不是当前机身状态，不能直接当作本轮实机绑定。

最新验收：[交付结果](deploy/verification/final-v2/delivery.json)。本机示例包位置见deploy/LATEST.json；轻量ZIP只提供源码、依赖快照和审阅证据，复制到新位置后须从自己的精确原件重新prepare，不分发完整分区镜像。

目录：

- `src/`：从保留材料恢复并定向适配的FAT、SquashFS、库补丁和逻辑扇区算法。
- `deploy/`：独立的准备、封存、原生载荷、传输、Terminal和失败门槛；vendor在本模块内，实机不依赖旧analysis或a7r5-exec代码。
- `historical/`：七份按历史补丁序列恢复的源码文本、部署／双读说明；不可作为现成安装包执行。
- `evidence/`：四库地址／字节／摘要、恢复来源、历史失败和人工回执、原厂更新脚本文本。
- `verification/`：本轮重建结果、测试日志和离线验收；本地rebuild-01保留生成的候选，轻量ZIP排除该镜像。
- `public-key.pem`：既有研究签名身份的公钥，不含私钥。
- `requirements.txt`：pyelftools0.33、capstone5.0.9；只安装到专用虚拟环境。

独立复制此模块后按正文重建，不需恢复旧analysis目录。需要自行提供精确原始一号明文镜像。后续DAT签名私钥仍由所有者另行保管。

当前部署器还通过了无网QEMU加载与原生任务验证，真实块设备及恢复仍未验收。旧说明、旧轻量ZIP和失败证据保留；历史上机回执与当前设备状态分开记录。不要把历史模板直接交给通用libjit.sh执行。
