# 单款C方案损失与学习率200步筛查

仅用于离线实验，不更改正式工作台、固件、原配方或R5NATIVE.BIN格式，不连接相机。

## 固定条件

- 暖金日光原配方起点，逐值复用完整C试验的1448个敏感度尺度。
- 每组MPS float32整批200步，每50步量化并回读评分；余弦调度跨度固定2000步，保持与完整训练前200步相同的调度阶段。
- 初始学习率0.003，末端学习率为初始值的2%；学习率对照使用0.0015、0.003、0.006。
- 相同v4.5 TRAIN/VALID、256个TRAIN灰阶锚点和冻结保护容差；仅报告六张开发照片，不评TEST和四张留出照片。
- 最大归一化位移与单步上限保持0.25和0.003，BIN刻度与合法性校验保持不变。

## 损失分项

首先在原配置的起点、锁定检查点和末步检查点测量各分项对同一归一化坐标的梯度范数和方向余弦。

四组损失只调整真实目标渐变项：原起点比例0.1、关闭该项、降至0.02、保留起点比例0.1并把渐变梯度限制到颜色加平滑梯度范数的20%。其他颜色项、原生/网格平滑、灰阶/P95保护及其50%预算不变。

梯度限幅系数只作为本步固定权重，不对权重本身求导。它保留颜色和平滑梯度，缩小辅助渐变梯度；不修改验收阈值，也不保证CPU真实离散损失每步下降。

`LossObjective`默认配置与原`ReviewedObjective`的值和梯度有定向一致性测试。控制组直接使用原`ReviewedObjective`。

## 分阶段选择

四组都完成200步后，按原有VALID数值资格和RGB/平均ΔE00归一化综合评分选择损失方向，再比较该配置的三档学习率，总共六次200步试验。开发照片和过渡诊断如实报告，不依据留出数据修改选择。

200步排名只说明短程优化方向，不能证明完整收敛、两千步结果或机内效果。所有候选均标为筛查产物，不自动采用。

```sh
.venv/bin/python -B scripts/benchmark_native_loss.py \
  --bin /absolute/path/to/original/R5NATIVE.BIN \
  --manifest /absolute/path/to/frozen/manifest.json \
  --normalization /absolute/path/to/C/normalization.json \
  --output /absolute/path/to/new-study
```

输出含冻结协议、源码快照、原库、六组候选/优化器检查点/损失日志、开发照片区域结果和筛查报告。实验入口没有启动2000步长跑的选项。

## 固定20%限幅的三档学习率

追加 `--study cap_lr` 可固定起点渐变损失比例0.1、归一化辅助梯度上限0.2，分别从同一原配方起步测试0.0015、0.003和0.006，每组严格200步。默认的六组消融流程保持不变。

此模式在各候选按VALID锁定后，另外报告 `.17/.53/.87` 三相位、`1/2/4` 三跨度的双域过渡，并保留独立相位的原始P95/最大曲率。开发照片区域和过渡待复核项不能被较低颜色均值抵消；不使用TEST或四张留出照片调参，不自动采用候选。

默认 `--arm C` 使用直接参数优化；追加 `--arm D` 可用相同损失、尺度和预算训练共享主干与四个神经参数头。20%梯度上限在归一化配方坐标计算，不声称网络权重空间的梯度范数也保持同一比例。神经网络权重保留在离线检查点，导出BIN仍为原生整数配方。

## C方案扩展损失对照

`--study objective_plus --arm C` 预先固定七组200步实验。各组学习率均为0.003，渐变起点比例0.1、渐变梯度上限20%、原配方起点和1448个敏感度尺度保持相同。

| 组别 | 变化 |
|---|---|
| `research_control` | 现有20%渐变梯度限幅基线 |
| `de_half` | 感知色差项权重减半 |
| `de_double` | 感知色差项权重加倍 |
| `transition10` | 加入过渡超限惩罚，值与归一化梯度预算均为主目标的10% |
| `photo05` | 照片辅助项起点比例5% |
| `photo20` | 照片辅助项起点比例20% |
| `photo10_transition10` | 照片辅助项起点比例10%，同时加入10%过渡惩罚 |

照片辅助项只从六张开发照片的固定3×3区域各采样64点，共3456点。所有区域等量、固定种子42，不为特定滤镜或失败位置单独加权；使用真实九点照片邻域，显式启用非平坦前向。CPU原生计算修正GPU前向值，连续GPU模型提供代理梯度。默认平坦入口仍拒绝非平坦输入。

照片损失为RGB均方误差、平均ΔE00及区域内最差5%色差的组合，值和归一化配方坐标梯度均限制在主目标的25%以内。开发照片中含辅助训练样本，其结果只能用于开发诊断，不再宣称这六张照片提供独立泛化验收。四张留出照片继续不参与训练、候选选择和本轮评分。

过渡惩罚只使用`.17`训练相位，比较各轴、1/2/4跨度的色度二阶差分P95和最大值是否超出原配方冻结的量化区间；不逐点追踪旧曲线转折位置，也不把合成渐变当作具有真实目标标签的照片。`.53`继续用于验证诊断，`.87`只在候选锁定后报告。原有灰阶、P95和照片保护容差不变，所有候选仍不自动采用。

输出额外保留照片采样索引、冻结输入/目标/参考、每步照片与过渡梯度比例。默认`ResearchObjective`与现有`LossObjective`有值和梯度一致性测试，完整非平坦照片路径另有CPU/GPU及反向传播测试。200步重跑会受MPS浮点累计与整数边界影响，应以同轮基线比较，微小收益需要复跑确认。

2026-11-13已完成七组对照，追加2%照片权重及基线/5%复跑，共十次200步。5%照片辅助两次都将开发照片超限项降至1项，基线两次为7–8项；色卡RGB RMSE与平均ΔE00仍略逊于基线，色相过渡仍待复核，未替换默认配方。原库与冻结输入摘要、全部检查点和最终BIN均已独立复核。详见[本轮研究报告](/Users/wenruli/Desktop/索尼/暖金日光-C扩展损失-200步-20261113/研究结论.md)。

## 照片区域门限保护

用户接受前一轮小幅色卡误差取舍后，`--study photo_guard --arm C` 继续比较四组：5%照片辅助对照、单独25%门限预算、5%照片辅助加10%或25%门限预算。每组仍从原配方起步，固定200步、学习率0.003、原尺度与采样索引，不自动替换正式配方。

`PhotoProtection`对54个采样区域分别冻结原配方RGB RMSE、平均ΔE00和P95的8位舍入区间上界。区域指标未超界时门限损失及其梯度均为零；超界后，对按该区域量化容差归一化的正向超量使用线性加二次惩罚。无全照片目标损失的组别只保护退步，不要求改善已经合格的区域。零量化容差的归一化分母使用1e-6数值保护；GPU色差开方稳定项在零点扣除其常数偏移，最终CPU验收定义保持不变。

门限项的值和归一化配方坐标梯度都受独立预算限制。日志增加激活区域数、最大超量、门限梯度比例及其与主损失梯度的方向余弦；负余弦用于诊断冲突，本轮不执行梯度投影。协议保存区域校准表，最终仍在完整开发照片和所有区域上使用既有容差复核。采样区域合格不能替代完整照片验收。

新门限触发/不触发、区域梯度隔离和MPS限幅均有可执行测试。默认损失的值与梯度等价性在CPU双精度检查，GPU路径另有集成测试，避免把MPS浮点归约的微小差异当作数学行为变化。

2026-11-13四组研究已完成。5%照片＋25%门限将六张开发照片超限项降至0；锁定后四张历史留出照片仍有1项RGB超限，普通域饱和度密集复核尚有退步。用户接受小幅色卡误差取舍，继续保留该组合为研究候选，不以RGB/ΔE微增一票否决。51项测试及47个子测试通过，四组独立回读复算通过。详见[照片门限研究报告](/Users/wenruli/Desktop/索尼/暖金日光-C照片门限保护-200步-20261113/研究结论.md)。
