# 完整129点Gamma的离线计算与验证

本次只补齐桌面训练、预览和验收中的Gamma表示，不修改固件或BIN格式，不连接相机，不覆盖已有配方。标准B端点的离线模型与真实机内成像仍需区分。

## 参数与坐标

固定CP基线SHA256为`8e9e26bf2e4b93fa5142e961dcf21cb0f43f8871283814be2dcfb0a694cb5a32`，原始576字节ST记录摘要为`f4e9f31bce38b4c705721a501c7597705852e671bc39baf60b02dac8b88f95ac`。`scripts/native_gamma.py`固定并复核非均匀横坐标摘要。

| 零起索引 | CP横坐标 | Edit横坐标 | RAW128对应节点 |
|---|---:|---:|---|
| 126 | 57344 | 1835008 | 126 |
| 127 | 61440 | 1966080 | 无 |
| 128 | 65535 | 2097120 | 127 |

Edit坐标等于CP坐标乘32；Edit纵坐标等于BIN纵坐标乘2。BIN为129个0至131071的uint32，要求零起点和单调。新训练直接使用完整129点，内部`gamma_y`仍采用Edit单位；完整曲线不会伪装成129点RAW标签。

新JSON通过`gamma_native_129`和`gamma_domain`保存真实数据。`gamma_7806_y`保留RAW128投影，读取时校验投影一致性，实际模型使用完整曲线。旧JSON可继续读取；旧RAW128转换到BIN时，终点映射到CP128，单独插值补CP127。旧BIN和工程保持原字节，不进行自动迁移。

新曲线的终点是训练所得真实值，编译器不再以旧的单独追加终点参数覆盖它。旧RAW配方的显式终点选项保留兼容行为，并需按最终完整BIN复验。

## 计算链路

- `ParameterContext.build`负责主Gamma表、反查表和运行时关联数据；模型对象携带完整曲线，不能仅从RAW投影恢复。
- `core.slot_native_parameters`、叠加训练回读、网格后的整数验收与槽位照片预览共用完整解码。
- `SmoothNative`和`SmoothGPU`共享真实129点横坐标；连续模型用于梯度，CPU整数模型决定采用结果。
- `tensor_table`在MPS上构造完整65536项整数Gamma表，与CPU及原版Edit指令逐项比较。此项不是完整RAW/GPU色彩流水线的证明。
- 旧照片缓存版本失效，需要重新生成。RAW128无法无损表达独立尾节点时，ARW参数导出拒绝，不影响BIN导出。

## 原版Edit指令复验

`scripts/verify_edit_gamma129.py`不启动Edit应用，只在Unicorn匿名内存中回放已绑定摘要的原始ARM64函数`0x1000c82d4`。保留输入、堆栈及输出边界校验，比较完整65536项。覆盖原厂ST、三款新增滤镜、线性曲线及两个尾节点独立变化，分别带中性对比度表或无附加对比度，共14组。

运行环境需要已有的Unicorn和Capstone；数值对照子进程使用ColorLab现有虚拟环境中的NumPy和PyTorch/MPS，不自动安装依赖。

```sh
<replay-python> scripts/verify_edit_gamma129.py \
  --edit <Edit可执行文件> --cp <绑定摘要的原始CP镜像> \
  --bin <保留的R5NATIVE.BIN> --output <新的结果JSON>
```

缺少完整CP镜像时，可用`--record <原始576字节记录>`替代`--cp`。工具仍严格核对记录摘要和横坐标，但报告会明确标记本次没有验证完整CP文件，不能用此项宣称CP运行链验证。

## 固定配方复评

```sh
PYTHONPATH=web:scripts R5_GPU_TRAINING=1 .venv/bin/python scripts/benchmark_gamma129.py \
  --bin <原有BIN> --manifest <冻结验证数据manifest.json> --output <全新目录>
```

复评保持三款滤镜的全部参数不变，使用同一v4.5色卡、训练/验证/测试划分、当前Hybrid网格响应和既有十张照片。六张开发照片用于分别重校准容差，四张留出照片只复评；渐变相位保持`.17/.53/.87`。输出RGB RMSE、平均及P95 ΔE00、训练灰阶、双域渐变各轴统计和三图对照。

旧128点前向只保留在该对照工具内，不能回到正常训练或预览入口。跨模型超限用于暴露历史评分遗漏，不等同于新配方采用失败；后续训练必须与完整前向下重新评分的旧BIN比较，不复用旧模型的门槛数值，也不能利用本次留出结果反复挑选候选。

## 尚未覆盖的范围

原指令复验覆盖已绑定版本及中性对比度/高光/阴影设置。非中性构造分支、CP记录尾部元数据、ISP像素插值及完整RAW空间处理不由本次证明。机内JPEG、取景和其他光源端点没有新增实机验收结论。
