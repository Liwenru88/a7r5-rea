# 原配方可行起点的 C/D 离线对照

这是四组实验的第二轮独立入口。只验证暖金日光，保留原完整库、原单槽配方与上一轮结果，不更新工作台或固件，不连接相机。

当前入口默认使用分级新规则 `reviewed`，详见 [保护规则说明](NATIVE_GUARD_POLICY.md)。下述零退步规则与参数记录保留第二轮历史方案；复现该方案必须显式指定 `--protection-policy legacy`。历史报告和源码快照不改写。

## 历史第二轮变化（legacy）

- C/D 都从原单槽 BIN 逐字节起步，不再投影成凹 Gamma。Gamma 仍采用原生横坐标上的单调参数化；保留负矩阵编码的低位，避免无成像变化的配方身份改变。
- C 使用独立参数坐标，D 使用原有共享主干、四参数头和独立残差。两组使用相同初始 BIN、相同敏感度尺度、损失、步数和候选筛选。
- 数据损失沿用 8 位 RGB 均方误差、平均 ΔE00 和最差 5% 颜色均值。固定参数与网格平滑项保留。
- 灰阶误差、颜色 P95、双域各轴 P95/最大值、同位置尖峰与连续三点异常全部参与训练。各项先相对基准归一化，再取平均，避免约束数量直接放大惩罚。
- 每步动态权重同时满足：约束损失不超过数据损失的 50%；约束梯度范数不超过拟合加平滑梯度范数的 50%。梯度在同一敏感度归一化坐标下比较。取消上一轮只增不减的乘子，不改变最终验收门槛。
- Adam 学习率从 0.003 余弦下降到 0.00006，默认 2000 步。归一化位移用 `0.25*tanh(u/0.25)` 限制，每步实际最大位移上限为 0.003（浮点判定容差 `1e-7`）；D 的网络权重更新也按输出参数位移缩步。优化器动量仍按本次梯度更新，实际应用比例写入日志。

全部反向传播使用 MPS float32 整批：64,562 个训练样本加 21,170 个独立渐变样本。每步 CPU 同参数整数前向校正数值，GPU 代理提供梯度，不是精确整数导数。对于九点完全相同的输入，CPU 改用合法的五像素宽度计算；启动时在整个训练集与探针上和原九点参考逐值核对。照片最终评分继续走原参考入口。

## 量化候选与保护

每 50 步保存原始量化候选，并以原配方为锚点，按 BIN 整数单位生成 `1/2` 至 `1/65536` 的固定缩步候选。每个候选都重新打包、解析、渲染。

缩步只看训练集及 `.17` 相位渐变：RGB RMSE、平均 ΔE00、灰阶和颜色 P95 不升，双域各轴 P95/最大值不升，同时通过校准后的逐位置尖峰和连续异常保护。所有训练可行的档位都保留，再用原 `.53` 相位验证门槛筛选。原始候选可以作为失败对照保留，训练保护失败时不能取得采用资格。

所有候选锁定后才使用测试集、`.87` 相位独立渐变和四张历史留出照片。采用标准保持不变：

- 色卡 RGB RMSE、平均 ΔE00 同时降低，颜色 P95 和灰阶 RMSE 不升。
- 双域每一轴的 P95 和最大跳变不升；局部尖峰及连续异常保护仍可否决。
- 四张照片按场景等权的 RGB RMSE、平均 ΔE00 改善，场景 P95 均值不升。
- 最终失败即保留原配方，不再根据测试集挑另一个候选。

原始候选、缩步候选、选中步数和比例都记录在候选池中。缩步可能使改善非常小，不能把舍入前浮点收益冒充最终 BIN 收益。历史留出集已经被研究使用，不是全新盲测；单款结果也不能证明跨滤镜通用性。

## 复现

```sh
.venv/bin/python -B scripts/benchmark_native_feasible.py \
  --bin /absolute/path/to/original/R5NATIVE.BIN \
  --manifest /absolute/path/to/frozen/manifest.json \
  --previous /absolute/path/to/previous/result.json \
  --output /absolute/path/to/new-output-directory \
  --steps 2000 --checkpoint 50 --seed 42 --protection-policy legacy
```

`--pilot --steps 80 --checkpoint 40` 只运行训练与验证，不评分测试集和留出照片。输出目录必须尚不存在，不覆盖旧研究结果。

输出含原库、原配方、源码摘要、冻结协议、尺度向量、逐步损失与梯度比例、优化器/神经模型检查点、完整候选池、锁定 BIN、最终色差和照片对照图。`proposal.BIN` 是实验候选；`accepted.BIN` 在验收失败时为原配方，都是单槽审计文件，未合并正式库。

BIN v4/v5 的字段与刻度均不改变：129 点 Gamma、CC1、16 色相矩阵、5×9×9 整数网格。原输入与源码在正式运行前后核对 SHA256。
