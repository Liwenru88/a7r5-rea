高级设置

色组权重

权重按整组分配，五组默认都是 1，范围为 0.05–64。比如灰阶设为 2、其余保持 1，拟合就会更重视灰阶，其他颜色的误差可能增加。

覆盖色卡中的大量普通颜色。调高会更重视整体颜色分布的拟合精度。

对应红、黄、绿、蓝四个高饱和锚点。调高会优先让这四种颜色贴近目标。

对应从黑到白的 256 级灰阶。调高会更重视灰阶的明暗和色调。目标中的暖灰或冷灰也会参与拟合。

对应 ColorChecker 的 24 个标准色块，包括肤色和常见物体色。调高会优先贴近这些代表色。

用 64 个训练样本覆盖原生色相矩阵的 16 个方向及相邻过渡。调高会让这些方向和交界在拟合中占更大比重。

平滑与色差

默认 30，范围 0–100。约束 Gamma、CC1、色相矩阵和网格参数的局部起伏。调高有助于抑制过拟合，也可能削弱目标中较强的局部色彩变化。

默认 30，范围 0–100。检查相邻输入的输出颜色是否突然跳变。调高会更重视两个输入域中的暗部、曝光、色相和饱和度过渡。

默认 0.35，范围 0–2。浮点拟合使用 Lab 色差近似，候选评分使用 ΔE00。调高会更重视人眼感知的色差，RGB RMSE 可能上升。

GPU 预优化

默认 0.015，范围 0.0001–0.1。控制每步更新的幅度。调高通常走得更快，也更容易震荡，调低则可能需要更多步。

默认 2000，范围 1–2000，仅接受整数。控制 GPU 起点预优化的更新次数，影响起点和耗时。后续矩阵求解和整数网格微调各有自己的预算。

MPS 按所设学习率和步数进行一次 Adam 预优化。量化后的候选仍须通过灰阶、双域过渡和验证集色差验收。

实验与求解

实验设置

默认关闭。开启后会同时搜索色温和色调偏移，并重新拟合原生参数。偏移只用于电脑预览，BIN 不保存它。拟合出非零偏移时会跳过默认的整数网格微调，批量训练始终关闭此项。

求解与导出参数

默认 2000，范围 1–2000。控制原生浮点求解单阶段最多评估多少次。求解收敛时可提前结束，部分阶段还有更低的独立上限。MPS Adam 步数在高级设置中单独设置。

默认 12，范围 2–12。标准模式用不同的初始参数搜索候选。起点越多，越有机会找到更好的解，耗时也可能增加。快速模式取得 GPU 起点后会跳过额外的多起点搜索。

默认 3，范围 0–12。每轮先固定色彩参数拟合 Gamma，再固定 Gamma 拟合 CC1 与 16 色相矩阵。设为 0 会跳过这段交替求解。

默认 8，范围 0–8。每轮根据训练集上各色组的残差调整组权重，再拟合原生参数。设为 0 会跳过这段色组补训。

默认 3，范围 0–3。对量化后的原生配方做邻域搜索，尝试弥补取整带来的误差。设为 0 会跳过这段搜索。最终 5×9×9 网格的整数微调有独立流程。

默认 131071，范围 0–131071。指定导出时 Gamma 曲线的最亮端点，须大于或等于拟合后的第 128 点。单项训练留空沿用 ST 端点，批量训练留空使用 131071。

选择目标色卡文件夹，自动筛选 JPG／TIFF。提交前可以调整每张图对应的槽号。名称和简称均为不带扩展名的文件名；重复名或超过 24 张时拒绝整批，不会漏项。批量使用当前训练设置，开启完整补偿与压缩、关闭不写入 BIN 的实验白平衡。第 129 点留空时批量采用 131071，避免截断拟合曲线；手填值仍严格校验。
