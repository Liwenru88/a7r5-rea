# 单款滤镜四组离线实验

这是独立研究入口，不接入正式工作台，不修改工程、原配方或固件。先固定暖金日光（原完整库第5槽）验证方法，不能由单款结果推断其他滤镜的效果。

| 组别 | 参数化与前向 | 目标与约束 |
|---|---|---|
| A | 完整129点、凹Gamma、原固定缩放、固定初始前向偏移 | RGB均方误差与平方ΔE00、固定保护权重 |
| B | A加训练输入敏感度缩放、动态派生表阈值、逐步整数前向校正 | 与A相同 |
| C | B改为单调Gamma，允许非凹曲线 | 8位目标一致的平均ΔE00与尾部损失，自适应保护权重 |
| D | C加共享主干与Gamma、CC1、色相矩阵、网格四头 | 与C相同；保留独立参数残差 |

A只是在同一个整批联合框架内复现现有机制，**不是正式训练器的多起点、网格精修等完整流程重跑**。C同时改变Gamma约束与损失，不能把变化单独归因于某一项。D不是照片到照片的网络，也不导出神经网络；固定潜变量与坐标参数头输出一款滤镜的原生参数。

## 固定参数与前向

搜索坐标共1448个：8个CC1有效整数刻度、96个色相矩阵有效系数、129个Gamma形状坐标、1215个网格系数。照明三个矩阵端点保持共享，CC1只优化B端点，其他端点保持原格式的零增量。

归一化只改变优化器坐标的步幅，不改变BIN量化单位。B至D用训练输入的6次固定种子随机VJP估计敏感度，各类缩放有预先固定的上下限；C和D复用同一缩放。CC1保留低位余数，矩阵按实际解码刻度量化，Gamma保留零起点与单调性，网格限制在−64至63。

全部梯度在MPS上整批计算，不使用小批次。由于尚无经过完整验证的全链路GPU整数内核，B至D每步用CPU计算当前参数的真实整数前向，再用直通估计器保留GPU代理梯度。**前向数值精确不等于梯度精确**；硬舍入、分支边界与平台区仍是研究限制。完整129点Gamma、主逆表及其派生色度阈值会重建；其他未验证的机内环节不作承诺。

旧配方可能不满足凹性。四组都从同一个稳定凹性投影BIN起步，起点字节必须一致；原配方另行保留。报告记录投影损失，最终采用标准始终与原配方比较。

## 训练与最终评分

- 固定v4.5色卡的64,562训练样本、17,467验证样本、17,343测试样本。256个灰阶锚点只位于训练集。
- 训练、筛选、最终复验分别使用相位`.17`、`.53`、`.87`的双域渐变。灰阶比较目标灰阶，保留滤镜有意染色。
- 默认四组各2000次Adam更新，学习率从0.015余弦下降至0.0003，每50步按回读BIN筛选；比较的是相同步数，另列真实耗时。
- C/D使用RGB均方误差、平均ΔE00、最差5%颜色均值；灰阶、训练颜色P95、双域渐变P95/最大值、同位置尖峰及连续三点异常约束先于验收参与每步损失。各组使用相同参数/网格平滑项，C/D每25步提高超限项权重。
- 候选只按验证集筛选；所有候选锁定后才评分测试集与照片。历史留出集已被先前研究使用，不是全新盲测。
- 最终以BIN重新解析后的CPU完整链路和固定Hybrid网格响应评分。RGB输出先量化为8位，再比较RGB RMSE、平均ΔE00、颜色P95。
- 采用需同时改善RGB RMSE和平均ΔE00，灰阶RMSE、颜色P95及双域各轴P95/最大值不得升高；局部尖峰/连续三点异常也可否决。额外要求四张历史留出照片的等场景平均RGB RMSE、平均ΔE00改善，平均场景P95不升。
- 不通过则`accepted.BIN`回退原配方，不依据测试结果选择其他候选；`proposal.BIN`仍保留失败实验以便分析。

## 运行

使用项目`.venv/bin/python`，不启动Web服务，不连接相机：

```sh
.venv/bin/python -B scripts/benchmark_native_four.py \
  --bin /absolute/path/to/original/R5NATIVE.BIN \
  --manifest /absolute/path/to/frozen/manifest.json \
  --output /absolute/path/to/new-experiment-directory \
  --steps 2000 --checkpoint 50 --seed 42
```

输出目录必须尚不存在，禁止覆盖。`--pilot --steps 6 --checkpoint 3`可先做整批GPU联调，此模式不评分测试集或留出照片。

保留完整原库与单槽原配方、共同起点、冻结协议/源码摘要、缩放向量、逐步日志、候选池、最佳/最终优化器与网络检查点、锁定记录、最终指标和四张留出照片对比。所有原始输入在实验前后核对SHA256。输出单槽v5文件保持既有128字节头和2452字节记录，实验文件不自动合并正式库。

日志的`loss`使用归一化RGB平方单位，`rgb_rmse`、`gray_rmse`使用8位码值。C/D的约束权重会变化，跨权重阶段的`best_loss`仅是历史标量记录，不能用于判断收敛或选配方；应分别看`data`、`constraint`、`violations`、`multipliers`及候选回读指标。若最终选中第0步，说明已评分的更新检查点没有改善验证颜色排序，不能把该起点的分数当成神经网络的实际训练收益。
