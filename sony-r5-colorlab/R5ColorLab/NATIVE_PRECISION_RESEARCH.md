# C方案精度与稳定性联合研究

独立离线入口为`scripts/benchmark_native_precision.py`，不改正式工作台默认、不操作相机。沿用现有Gamma129、CC1、16色相矩阵及5×9×9整数网格和原BIN编码。

## 数据与梯度

- TRAIN色卡整批64562点，原VALID划分、灰阶锚点和1448个敏感度尺度保持。
- 六张开发照片每个3×3区域256点，共13824点，固定种子42；不为滤镜名称或已知错误区域设置特例。照片损失起点比例5%、门限值及梯度预算25%。
- 双域全部饱和度射线共96条。每条原始输入16倍补采样，从中取24个均匀三点窗口和原配方高曲率8个窗口，共9216点；加入原21170个探针后训练探针共30386点。窗口允许重叠，元数据保留位置，不能当作独立随机样本。
- 窗口只依训练相位及原配方选择，不用目标留出或候选在独立相位的错误选点。密集项约束每条射线局部曲率分布的P95和最大值，不逐点固定旧转折位置。
- CPU整数参考提供前向修正，连续MPS模型提供代理梯度。零起点的CPU/MPS数值差异通过同后端原配方参考校准，最终验收仍使用独立CPU真实数值。
- 可选投影只移除辅助梯度与主梯度相反的分量，不改变前向损失。它在归一化配方坐标、Adam之前处理，不能保证带动量和自适应缩放的真实整数更新每步都改善；必须复算BIN。

## 固定对照与长预算

`--steps 200`默认跑四组：`coverage256`无密集项、`dense10`、`dense25`、`project_dense25`。各组相同起点、学习率0.003、最低0.00006、余弦跨度2000和步幅上限，默认无密集项用于单独检查扩大照片覆盖的作用。

短程开发评分后，使用`--steps 2000 --configs coverage256,<选定密集配置>`从同一起点确认。每组只有一次训练轨迹，保留200/400/600等检查点；研究对照不等于正式训练要重复两轮。最佳检查点依最终量化后的质量选择，末步不自动视为最优。

```sh
.venv/bin/python -B scripts/benchmark_native_precision.py \
  --steps 200 \
  --bin /absolute/path/to/original/R5NATIVE.BIN \
  --manifest /absolute/path/to/frozen/manifest.json \
  --normalization /absolute/path/to/C/normalization.json \
  --output /absolute/path/to/new-screen-directory
```

`--steps`支持200、600、2000；`--configs`只接受上述固定配置名。输入必须保持冻结，输出必须为新实验目录。实验协议、源码快照、窗口索引、输入NPZ、照片采样索引、原库、原配方、损失和优化器状态均保留。

## 独立质量选择

整体密集统计和逐射线风险分开保存，局部尖峰不能因整体最大值下降被隐藏。`native_dense_audit.dense_report`同时输出全域原始指标、逐线原始变化和8位舍入区间超界。量化区间不是视觉可见阈值；原始退步不能称为严格不退步。

保留既有合法性、灰阶、P95和完整照片门槛。用户接受此前约1%的色卡取舍，不再以相对C对照的RGB/ΔE小幅增加一票否决。开发范围选择完成并锁定摘要后才评分TEST和历史留出照片，不依据本轮留出结果改权重。这些数据历史上已使用，不称首次盲测。

## 2026-11-13研究结论

四组200步、两组2000步、42个检查点及72项整数复选完成后，推荐`coverage256`在同一2000步调度下的第1200步：每区域256点、5%照片辅助、25%照片门限，不加密集训练损失、梯度投影或整数平滑；密集过渡继续作为验收。

锁定后色卡TEST RGB RMSE为3.947487、平均ΔE00为1.577727；四张历史留出照片等权平均RGB为7.257684、平均ΔE00为2.543215。开发照片超限0项，历史留出仍有1项局部RGB超限。灰阶2.510136优于原配方2.634655，但高于前轮候选2.235777；独立相位原生饱和度P95约增2.6%，仍在校准量化区间内。因此这是综合最优推荐，不称每项指标单独最优或原始统计全部不退步。

59项测试及47个子测试、六组训练独立复核均通过。新十五款导出只替换暖金日光，其他十四项字段及原库保持；工作台默认没有切换。详见[最终研究结论与图](/Users/wenruli/Desktop/索尼/暖金日光-C精度收敛-20261113/最终研究结论.md)和[导出BIN](/Users/wenruli/Desktop/索尼/暖金日光-C精度收敛-20261113/final-export/R5NATIVE.BIN)。

## 2026-11-14：边界与整数后续研究

已修复`native_integer_polish.polish_delta`的平滑轴错误：网格存储为`3×5×9×9`，应平滑空间轴1/2/3，原轴0/1/2会串入颜色通道并漏平滑末轴。新增三通道脉冲回归先复现失败、再验证修复。上轮最终配方未采用平滑，原BIN不受影响；旧72项复选不能单独证明正确空间平滑无收益。本轮已补做正确轴和更小平滑步幅复验，仍未选中平滑配方。

离线研究训练函数支持可选`research_radius`、`adaptive_radius`和`start_vector/start_bin`，默认行为保持。`native_search_radius.SearchRadius`在训练可行、拟合改善且组内坐标接近边界时，将CC1、色相、Gamma或网格半径由0.25扩大至0.375、最高0.5；同时重表达坐标和Adam矩估计，单步更新上限0.003仍保留。MPS实测扩大半径本身不改变BIN。

同一起点先完成固定／自适应半径各200步GPU整批对照，再独立延长自适应方向至600步，并枚举真实原生整数邻域。候选只在TRAIN/VALID、六张开发照片和开发密集射线选择。开发池去重89项后，锁定“200步自适应候选向上轮最优缩步75%”，再一次复算TEST、四张历史留出照片及独立相位。

TEST RGB RMSE为3.780272、平均ΔE00为1.508146，较上轮最优分别降低4.236%和4.410%；颜色P95为3.552274、灰阶为2.310247。历史留出照片平均RGB为7.022861、平均ΔE00为2.422191，区域门限超限1→0。但独立相位原生饱和度P95和部分最大跳变回升，逐射线量化区间均未超限；不能称所有原始过渡统计严格不退步，因此只保留研究候选，不自动替换工作台或原库。

独立MPS重跑的整数轨迹存在分岔，600步不属于前200步的严格续跑，不能声称600步同预算领先。现有回归63项、50个子测试通过，14个检查点BIN逐字节重放。具体入口、源码补充快照、有限候选、损失日志与限制见[本轮研究结论](/Users/wenruli/Desktop/索尼/暖金日光-C边界与整数研究-20261113/研究结论.md)。

## 2026-11-14：逐步过渡保护与三次重复

离线实验增加可选`step_guard`：每次更新后检查真实整数过渡，按1、1/2、1/4、1/8缩步，全部失败则恢复参数和Adam状态。`SearchRadius`增加可选`confirmations`，默认仍为1；本轮`radius_confirmations=2`、`radius_min_relative_improvement=0.001`，扩展若改变BIN字节则撤销扩展。正式工作台默认未切换。

相同coverage256/1200向量、尺度、种子42及学习率0.003，各做200步MPS整批三次重复。步后检查0.17相位全部96条饱和度射线，每条1153点；整体P95/max冻结为原始配方与起点逐项较小值，局部校准区间保持。三次均只接受1次更新、回退199次，无半径扩展，开发选择均回退起点，未获得更优配方。末步BIN虽一致，但停滞路径的一致不能证明有效优化时的稳定性已经解决。

拒绝主要来自原生饱和度P95：第2步缩至1/8仍较上限高约0.329%。当前四档缩步与逐步零增长门槛限制住了这条搜索路径；不能由此推断所有约束优化不可行。后续应研究软过渡引导、阶段可行性恢复或改变参数块方向，并保留原最终验收，不能把回退当成拟合改进。

三次先独立锁定，再复算TEST、四张历史照片与预留新相位0.29/0.71。上轮75%缩步色差候选在两个新相位的四轴整体原始统计和逐射线量化区间均通过，既有0.87相位回升仍保留；本轮没有据此重选或重训。65项测试、50个子测试通过，15个检查点BIN逐字节重放，拒绝更新的Adam状态恢复计数通过。详见[三次重复研究结论](/Users/wenruli/Desktop/索尼/暖金日光-C过渡稳定性-200步三重复-20261114/研究结论.md)。
