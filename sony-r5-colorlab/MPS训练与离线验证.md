# Metal／MPS训练与离线验证

2026-11-03，已在 `R5ColorLab/.venv` 安装 Python 3.12.11、PyTorch 2.15.0及现有训练依赖，并实际验证本机Apple Silicon的MPS前向计算和反向传播。正常启动入口默认请求MPS，显式CPU模式继续保留。根开发环境和此前24槽验证环境没有修改。

## 使用

双击 [启动R5色彩工作台.command](R5ColorLab/启动R5色彩工作台.command)，或在仓库根目录执行：

```sh
sony-r5-colorlab/R5ColorLab/.venv/bin/python \
  sony-r5-colorlab/R5ColorLab/launcher.py
```

浏览器访问 `http://127.0.0.1:4180`。启动脚本优先使用工具自己的虚拟环境，也允许通过 `R5_COLORLAB_PYTHON` 指定解释器。PyTorch固定为本次验收的2.15.0，见 [GPU依赖](R5ColorLab/requirements-gpu.txt)。

需要CPU模式时追加 `--cpu`；环境变量 `R5_GPU_TRAINING=0` 也继续有效。已有训练子进程维持启动时的模式，不会被其他作业的CPU数值验收切换后端。

```sh
sony-r5-colorlab/R5ColorLab/.venv/bin/python \
  sony-r5-colorlab/R5ColorLab/launcher.py --cpu
```

## 实际计算边界

浮点拟合、自动求导、Gamma／色彩交替、颜色网格优化及相关色差计算使用现有MPS实现。原生整数验收目前使用CPU参考实现：上游快照引用的 `native_color.metal` 没有随源码提供，本次未编造替代着色器，也不将CPU整数计算标为Metal计算。界面和后端状态均明确显示这一边界。

CPU与MPS浮点计算采用不同精度，优化器也不同，不承诺所有训练都会产生逐字节相同的参数。验证分别约束相同参数的前向值、损失和梯度，以及实际求解结果的独立CPU验收；最终配方仍按原整数范围生成。相机继续读取v4／v5配方，不依赖电脑上的torch。

默认模式在GPU阶段失败时显式记录回退，CPU参考结果仍作为验收依据。离线测试关闭PyTorch算子自动CPU回退，并用 `R5_GPU_STRICT=1` 验证实际训练阶段，避免把阶段失败误算成GPU成功。

## 修复内容

1. 双击脚本改用专用环境，启动器默认请求MPS；`--cpu`和原环境变量都可明确关闭。
2. 缺少原生Metal着色器时，整数验收保留CPU路径，状态如实报告；存在着色器时仍保留原有逐值校验。
3. GPU起点初始化器遵守CPU模式，关闭GPU后不再额外运行MPS。
4. GPU阶段前后及交替／连续性约束验收使用独立CPU调用上下文，防止CPU参考函数再次分派到GPU。上下文可嵌套，退出或异常后恢复，不改变并发线程的模式。

训练目标、默认无专家共享C1响应模型、整数配方格式和机内八项微调逻辑不变。

## 验证结果

相关回归 **163项通过、44项子测试通过、1项跳过**；跳过项为未随源码分发的历史数值样本。包含13项本地真实MPS验收、既有GPU／CPU数学对照，以及24槽与原十二槽格式回归。原始结果和复现命令见 [MPS验证收据](MPS_VERIFICATION.json)。

| 验证 | 实测结果 |
|---|---|
| 实际MPS张量／反向传播 | `mps:0`，梯度有限，无算子自动CPU回退 |
| 四类原生阶段 | Gamma、灰阶、色彩、联合阶段的损失和方向梯度符合CPU容差 |
| 默认共享C1前向 | 577组随机／灰阶／边界颜色，最大归一化误差约 `9.83e-8` |
| 默认共享C1网格求解 | CPU／MPS输出RMSE约 `0.0001636`，即 `0.042` 个8位码值 |
| 两套完整色卡的整数验收 | 各99,372块×9探针，CPU参考路径与原结果通道差异为0 |
| 实际MPS优化 | 20次评估内独立CPU目标从约3.242降至2.547 |
| CPU参考与并发隔离 | 验收不回到GPU，嵌套和其他线程模式保持，失败回退与严格停止均通过 |
| 真实网页服务 | 本机回环启动，24槽、12种原厂基线及MPS状态正确，检查后正常退出 |

另外使用1,436个明确选取的色卡样本和合成目标，实际执行了预算限制为每阶段1次评估的完整拟合脚本：CPU、MPS均完成并转换为第24槽v5配方；MPS记录6个GPU阶段，无阶段回退。该小预算对照最终选择同一候选，预览和原生配方一致。另运行开启PC补偿的MPS实际拟合，记录8个GPU阶段并完成，无阶段回退。这些用于验证训练链路，不是完整高精度成品训练，也不能据此推导普遍加速倍数。

本次保留了修复前失败现场：缺少着色器、CPU模式仍调用初始化器，以及CPU验收重新分派到GPU的回归均先复现后修复。测试自身在黑白边界上做中心差分越界的问题已修正，边界前向样本仍完整保留，没有修改模型来迎合错误测试。
