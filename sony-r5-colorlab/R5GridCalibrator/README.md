## 实际流程

1. 上传有效 R5NATIVE.BIN（只接受v4），选择源配置、探针幅度（默认12），生成探针包。ZIP含一份新的R5NATIVE.BIN、清单、散列及拍摄顺序。
2. 新BIN用源配置的CC1、block13、Gamma复制出12项，原有网格只放在11号；其他探针表新建。编号/名称改变，其他非网格参数逐项相同。**这份BIN会完整替换原自定义配置集，请保留原文件，拍完重新导入恢复。**
3. 已有支持BIN v4的固件无需反复刷固件。按现有关机/开机导入流程加载一次，在自定义滤镜菜单切换1–12拍摄。原厂创意外观固定，1 ZERO是基准；不能关闭自定义滤镜替代基准。
4. 固定机位、光线、手动曝光、ISO、WB及右侧调节，按1–12顺序各拍一张JPG，可在最后补拍一次1 ZERO。
5. 下方直接选择拍摄文件夹。忽略ARW、隐藏文件及其他格式，按文件名自然排序（DSC9在DSC10之前）对应1–12；第13张作为重复ZERO。即便11原表为零也保留该照片，防止顺序错位。先核对页面文件对应表，文件夹不要混入其他场景或多余JPG。
6. 点击“上传文件夹并训练”，自动保存ZERO、逐张上传对应探针并开始拟合。失败显示文件名与具体原因，已上传项保留可重试。原厂外观可选，拍摄条件可选填，无需单独建立批次。
7. 完成后下载响应模型及误差报告。旧采集资料仍保留在workspace，不删除。

| 编号 | 网格 | 用途 |

| 1 | 全零 | 基准、重复拍摄漂移检查 |
| 2–7 | 三个系数通道的正/负常量偏移 | 训练通道响应 |

## 计算方法与边界

输入须同尺寸、方向归一化的sRGB RGB JPG、PNG或8/16位TIFF。Sony含MPF的JPG（Pillow识别MPO）读取全尺寸主帧。JPG/PNG按EXIF归一化方向，有效ICC自动转换为sRGB；无ICC按sRGB。16位TIFF仍要求sRGB与归一化方向，以保留精度。每图最多96MiB/8000万像素。按最多64×64块采样中央60%均值，剔除高纹理或剪切块；不按颜色差剔除，不自动配准、曝光或白平衡修正。均匀色卡优于自然纹理照片。JPG噪声、光线变化、错位和空间处理可能混入结果。

模型使用5×9×9三线性网格偏移（系数/256）。比较暂定BT.601坐标下的3×3通道响应、带基准RGB交互项的平滑响应，以及有界仿射坐标局部微调。坐标搜索只用训练数据、每对默认1000训练块用于搜索（可配置）；最终响应用全部训练块。验证误差选择模型，测试不参与调参。相邻4×4采样块采用共同空间划分；11/12整张照片全部留出。共享同一基准的同图空间留出不等于独立场景验收。

零网格预测恒等于基准。单通道探针不能识别完整响应，恒定表不能识别坐标；少量探针也不保证恢复所有节点非线性。报告显示覆盖/激励诊断、漂移及未优于对照的提示。不会自动把低误差当作唯一恢复原厂算法。当前模型未实现任意非线性ISP/TPS反演，需根据实测残差继续改进。

导出的模型为PC预测参数，**不是新固件，也不是新的颜色BIN**，不会自动替换R5ColorLab的固定模型。Python：

```python
import json, numpy as np
from model import predict
calibration = json.load(open('model.json'))
# rgb: Nx3 编码sRGB 0–1；grid: 405x3有符号系数，节点按Y/U/V展平
predicted = predict(rgb, grid, calibration)
```

反推结果只约束本次参数、原厂外观与拍摄条件，不能默认跨ISO、WB或外观通用。未来可增加新的场景与更丰富探针，用未见过的图验证。

## 2026-10-24 反推优化更新

坐标微调支持多起点、明暗/色相/饱和度训练分层抽样、响应系数与坐标交替优化。默认4起点、每轮150次函数评估、3交替轮、每对480搜索块，页面可修改（上限分别8、1000、6、2000）。每轮评估上限不是实际迭代次数，数值导数会增加残差调用；矩阵/颜色相关响应分别搜索。固定坐标基线始终参与验证选模，每个候选最终响应使用完整训练集求解；测试样本不参与抽样、坐标可辨识判断或优化。模型格式和预测公式保持兼容。

## 2026-11-02：借鉴正式训练的质量优化

新拟合默认启用颜色分层损失均衡、鲁棒RGB损失及高误差训练样本补入。已有模型/原照片不改写，预测公式与schema兼容。页面新增：

- `color_balance`：每对图总质量相同；按基准明暗×色相×饱和度分层密度平方根反比加权。近灰单独分组，稀有色单点权重封顶为该对中位数4倍。训练/验证/测试各自独立计算权重，训练不读取留出颜色。
- `robust_scale`：默认3个8位RGB级，0–20，0关闭。响应采用与运行时相同的浮点剪切预测和soft-L1 IRLS；坐标残差在物理RGB单位鲁棒化后再加权，保留二次ridge正则。阈值软降低异常影响，不按拟合误差删样本。0保留原线性ridge响应求解，可用作兼容对照。
- `adaptive`：自第二交替轮起，每对每轮补入最多初始搜索预算1/4的高误差训练块，原分层块保留；每个起点/响应分支独立扩展，最终响应用全部训练样本。验证/测试不参与补样。最大累计搜索预算为初始的1+(交替数−1)/4倍。

固定坐标候选保留。验证以相同加权鲁棒目标选模，测试不参与选择；同时报告未加权RMSE/MAE、通道绝对误差P95、逐块RMSE P95、最大通道误差。RGB误差不是Delta E，通道P95与逐块P95区别列明。固定空间划分保持，独立留出探针不能被同图空间留出代替。

新增留出分组：中性灰、彩色和12个色相区，各列样本数和误差；空组不记作0误差，近灰不按不稳定的色相分类。报告另列浮点输出和8位四舍五入输出误差；后者仅是PC量化验收，**不是原生ISP整数验证**。探针采用实际BIN整数表直接计算，没有虚拟压缩网格。

新增405节点三线性支持质量、完整3/12列响应特征秩/条件数；通道激励秩3不代表12列响应可辨识，节点被触及也不代表所有系数可独立恢复。记录各轮实际搜索数、求解状态、评估调用和预算用尽情况。

标定要测量真实响应，不制造富士风格。因此没有照搬滤镜训练的色相单调化/强制平滑，它可能掩盖实际非线性。当前保留低阶响应和正则化，更复杂模型应由独立实拍残差证明必要性。

图像采样仍为原规则图块中央60%均值，基准/目标同位置、相同几何；**尚未接入新三张色卡的透视定位与逐编号中心5点采样**。本次优化作用于采样后的反推拟合，不能把规则图块中心当作印刷色块中心。实拍应先完成几何/编号对齐，并使采样和评估一致，再验证收益。16位sRGB精度保持，不加预量化。

独立导出同时包含`model.py`和新增`quality.py`。回归覆盖已知响应、训练异常点、测试颜色/目标污染隔离、高误差补样、零网格恒等、剪切响应和导出依赖。合成通过不等于实机精度已提升。

## 连续分段响应与原04回归（2026-11-02）

## 可选色相残差（3／24组）

`hue_experts=true` 需 `structured_response=true, response_degree=2`。`hue_expert_count`仅接受整数3或24，默认3，页面开关默认关闭。结构阶段选中C1后冻结其响应/坐标，再单独拟合残差；若结构未胜出则跳过，不强行增加模型。`coordinate_device="mps"` 使用Apple GPU，需要requirements-gpu.txt；CPU可用同一Torch求解器。推理仍只需NumPy/SciPy。
