# Hybrid 训练更新与离线验证

更新日期：2026-11-12。训练核心锁定上游提交 [`06c3557`](https://github.com/Hearts-Ace/sony-r5-colorlab/commit/06c35577255eddef641c695d179b0e6f699ffe62)。这是针对本地工作台的选择性整合，不是覆盖整个上游目录；原始导入清单继续保留，新增源码散列见 `HYBRID_UPDATE.json`。

## 更新后的训练入口

正常启动方式保持不变：在 `R5ColorLab` 目录使用项目虚拟环境运行 `.venv/bin/python launcher.py`。本次只更新文件，没有把服务留在后台运行。

| 页面模式 | 执行内容 | 参数设置 |
| --- | --- | --- |
| 标准 · 上游正式方案 | v4.5 色卡：原生 12 起点 → 目标网格共 5 轮 → 原生／网格／舍入交替 3 轮 | 固定使用 `web/formal_profile.json`；高级参数只读 |
| 自定义预算 | 新版原生拟合和 Hybrid 网格；保留本地色卡留出保护 | 高级参数可调，不执行正式方案的五轮接续与三轮叠加 |
| 快速 | 缩减原生搜索，然后拟合最终网格 | 可调预算，适合先检查数据及流程 |
| LUT 目标 | 新版原生与网格训练 | 使用自定义路径，不套用色卡专用叠加 |

正式色卡流程必须实际启用 Apple Metal／MPS；原生浮点求解使用严格 GPU 模式，失败时保留日志并停止，不以 CPU 训练冒充 GPU 成功。整数候选验收、最终 BIN 解码与独立重放仍保留 CPU 参考实现。没有 GPU 时可以明确选择自定义预算及 CPU。

正式参数包括：每阶段原生评估上限 2000、12 起点、动态权重 8 轮、Gamma／色彩交替 3 轮、原生量化微调 3 轮。Adam 起点仍采用学习率 0.015，步数为 `min(600, 每阶段评估上限)`；2000 不是 Adam 步数。叠加阶段为 3 轮，每轮原生评估 120、网格评估 180、舍入 80 步、联合整数搜索预算 64。

标准流程使用单调凹 Gamma、整体 Gamma 校正和色彩恢复；叠加阶段冻结已确定的 Gamma，联合优化 CC1、16 色相矩阵和网格。精确 ΔE00、色相方向强度 30、目标导数强度 0.02 进入叠加目标。旧参数平滑和旧输出连续性强度在正式方案中设为 0，避免重复施加约束；自定义路径仍可使用原有设置及留出保护。

## 模型与兼容性

新任务默认使用 `r5-paired-20261107-nonlinear-he3`，SHA256：

`936af0b27f3c5f1ff422c20dd7c1436f92458407d1dd492a4edca2e5ef45e677`

Hybrid 采用非线性基底和三组色相残差专家。专家门控在严格 RGB 中性轴上为零；这不表示整套网格不会改变灰阶。它是离线响应预测模型，不写进 BIN。

- PT 色相边界采用上游的中间精度处理，修复半索引附近选到相邻扇区的问题。
- 保留五种历史 R5 模型的注册入口和原有推理指纹，历史任务不改用 Hybrid 重新解释。缺失的固定资源按已有摘要从锁定上游恢复，未改写摘要。
- 保留 24 槽工程、草稿、`.r5proj`、BIN 导入编辑和 v4／v5 自动选择，Gamma／CC1／矩阵／网格的 BIN 字段和整数单位不变。
- 保留 RAW、JPG、PNG、TIFF 预览，原 RAW／校准 RAW／机内 JPEG 对比及框选色差统计。
- 保留标准导出、ST 共享增量、原厂多外观通用偏差导出。未替换原十二款或已经交付的其他滤镜。
- 正式任务转发父任务的进度与完整日志行，叠加阶段记录当前和最佳 Loss。任务下载包含叠加审计、对比和父任务日志。

## 验收口径

正式流程沿用上游的候选选择规则：训练提案须通过实际整数输出的目标检查，验证集按固定 RGB MSE 与 ΔE00 平方的加权损失选优，父配方始终参与回退。最终 BIN 还要通过解码、重新打包和 CPU 原生参数重放。

这个加权目标不等于“RGB RMSE、平均 ΔE00、灰阶、P95、所有照片和双域过渡分别都不能退步”。P95、灰阶和独立照片仍需查看报告与预览；不能把一次加权损失下降直接说成所有指标改善。自定义模式保留本地原有的灰阶、尾部色差及已启用双域连续性留出门槛。
