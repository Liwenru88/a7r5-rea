## 已有 JSON 生成 BIN

以下命令在 `a7r5-rea` 根目录执行，只使用已有根虚拟环境和 Python 标准库。输入必须是已经拟合好的 `r5-custom-filter-config/4` 或 `/5` 配方 JSON，不能直接传入图片或 cube。

```sh
.venv/bin/python sony-r5-colorlab/R5ColorLab/compilers/custom_filter_v4.py \
  /path/to/native_config.json --output /path/to/R5NATIVE.BIN
```

输出文件必须不存在，编译器采用独占创建，避免覆盖已有 BIN。该命令只打包配方，不进行色彩拟合。

编译输入严格只允许 `schema`、`model`、`baseline_ap_sha256`、`baseline_cp_sha256`、`entries` 五个顶层字段。历史成品目录的 `native_config.json` 还带有 `export_sources` 审计信息，不能直接作为命令行输入；应保留原文件，另存仅含上述五个字段的配方副本后编译。本次验证使用这种独立副本，没有删改原始审计。
